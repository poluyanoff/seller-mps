# Анимации

Пересказ Figma-гайда «Гайд по анимации» (v1.0.0). Токены длительностей и кривых — в README ДС (раздел «Анимация») и в `tokens.json`. Анимации конкретных компонентов описаны в их README, правила загрузок — в разделе «Загрузки».

## Параметры анимации
Любая анимация описывается четырьмя атрибутами:
1. **Триггер** — действие, которое её запускает: наведение, нажатие, свайп и т. д.
2. **Анимируемые свойства** — любые, чаще всего расположение, прозрачность, размер.
3. **Длительность.**
4. **Кривая.**

### Длительность
Два правила:
- появление медленнее исчезновения;
- маленькие объекты меняются быстрее больших.

| Токен | Значение | Когда |
|---|---|---|
| `duration-slowest` | 700 мс | модальные окна, затемнение фона, большие объекты |
| `duration-slow` | 500 мс | модальные окна, большие объекты |
| `duration-moderate` | 300 мс | нотификации, появление компонентов, перемещение объектов |
| `duration-fast` | 150 мс | микроанимации, фейды |
| `duration-fastest` | 75 мс | микроанимации в тогглах, чекбоксах и т. п. |

### Кривые
Две группы — **Productive** и **Expressive** — задают характер движения. В каждой три типа:
- **standard** — симметрично замедляется в начале и в конце;
- **entrance** — замедляется в конце;
- **exit** — ускоряется в конце.

| Токен | Значение |
|---|---|
| `easing-productive-standard` | cubic-bezier(0.2, 0, 0.4, 0.9) |
| `easing-productive-entrance` | cubic-bezier(0, 0, 0.4, 0.9) |
| `easing-productive-exit` | cubic-bezier(0.2, 0, 1, 1) |
| `easing-expressive-standard` | cubic-bezier(0.4, 0.1, 0.2, 1) |
| `easing-expressive-entrance` | cubic-bezier(0.35, 1.3, 0.25, 1) |
| `easing-expressive-exit` | cubic-bezier(0.4, 0, 1, 1) |

- **Productive** — сглаженные кривые с равномерным изменением скорости.
- **Expressive** — резкое изменение скорости, динамичное движение с отскоком и перерастяжением.
- Для быстрых анимаций (`fast`, `fastest`) — только Productive.

## Шаблоны
Шаблон выбираем по действию. Часть шаблонов делится на два типа:
- **micro** — для небольших компонентов и контента внутри компонентов;
- **macro** — для крупных компонентов (карточки), длиннее.

В коде TUI шаблонов нет, есть только токены. Шаблоны собираются из токенов (см. «В коде»).

### Появление и исчезновение
| Шаблон | macro | micro |
|---|---|---|
| **fade-in** — появление из прозрачности, opacity 0 → 1 | `moderate`, `productive-standard`. Контент из скелетона, контент в карточках | `fast`, `productive-standard`. Заголовок в аппбаре при скролле |
| **fade-out** — уход в прозрачность, opacity 1 → 0 | `moderate`, `productive-standard`. Исчезновение контента в карточках | `fast`, `productive-standard`. Элементы аппбара при скролле |
| **slide-in** — въезд на экран | `slow`, `expressive-entrance`. Ботомшит, флоатинг-контейнер | `moderate`, `productive-entrance`. Всплывающее уведомление |
| **slide-out** — выезд с экрана | `moderate`, `expressive-exit`. Ботомшит | 200 мс, `productive-exit`. Флоатинг-контейнер, тост |

### Трансформация
| Шаблон | macro | micro |
|---|---|---|
| **expand** — увеличение высоты или ширины | `slow`, `expressive-standard`. Высота ботомшита | `moderate`, `productive-standard`. Высота карточки, разворачивание списка, каунтер |
| **collapse** — уменьшение высоты | `moderate`, `expressive-exit`. Сворачивание больших элементов | `fast`, `productive-exit`. Сворачивание списка |

### Комбинированные
| Шаблон | macro | micro |
|---|---|---|
| **fade-in-scale** — появление с увеличением | opacity 0 → 1, scale 0.8 → 1, `moderate`, `productive-standard`. Карточка в списке | opacity 0 → 1, scale 0.9 → 1, `fast`, `productive-entrance`. Чипы |
| **fade-out-scale** — исчезновение с уменьшением | opacity 1 → 0, scale 1 → 0.8, `moderate`, `productive-standard`. Карточка в списке | opacity 1 → 0, scale 1 → 0.9, `fast`, `productive-standard`. Чипы |

## Комбинации шаблонов
Шаблоны комбинируются для сложных анимаций с несколькими объектами. Этапы идут друг за другом, по 300 мс каждый.

| Сценарий | Таймлайн |
|---|---|
| Замена контента без изменения размера контейнера | fade-out 0–300 → fade-in 300–600 |
| Замена контента с изменением размера | fade-out 0–300 → expand / collapse 300–600 → fade-in 600–900 |
| Появление дополнительного контента | expand 0–300 → fade-in 300–600 |
| Исчезновение дополнительного контента | fade-out 0–300 → collapse 300–600 |

## Как передать в разработку
1. Описать триггер.
2. Описать значения свойств в начальной и конечной точке.
3. Подобрать токены длительности и кривой или подходящий шаблон.
4. Сделать прототип в Figma или LottieLab и приложить ссылку.
5. Сложные трансформации формы — добавить раскадровку с ключевыми моментами.
6. Несколько анимаций с разной длительностью или асинхронным запуском — добавить схему с таймлайном. Элементы для неё — в библиотеке TUI Helpers.

## В коде
- **Токены** — CSS-переменные `--duration-*` и `--easing-*` (в бандле ДС). В продуктовом коде — токены анимаций из TUI: в React — Playground, в iOS — документация для разработчиков.
- **Шаблоны в бандле ДС** — для макетов и прототипов:
  - CSS-классы `tui-anim-fade-in`, `tui-anim-fade-out`, `tui-anim-slide-in`, `tui-anim-slide-out`, `tui-anim-fade-in-scale`, `tui-anim-fade-out-scale`. По умолчанию macro, с `tui-anim--micro` — micro. Направление slide задают `--tui-anim-from` / `--tui-anim-to` (по умолчанию снизу, `0 100%`);
  - `TaigaUI.motion('expand', 'micro')` → `{ duration, durationVar, easingVar, scale }`; вся таблица — `TaigaUI.MOTION`;
  - `TaigaUI.animateHeight(el, change, { template, kind })` — expand / collapse вокруг изменения содержимого;
  - `TaigaUI.animateSwap(el, change, { resize })` — замена контента по комбинациям: fade-out → (expand / collapse) → fade-in.
- При `prefers-reduced-motion` шаблоны в бандле срабатывают мгновенно. Это наша трактовка: в гайде уменьшенное движение не описано.

```js
// Появление дополнительного контента: expand → fade-in
TaigaUI.animateHeight(box, () => setOpen(true), { kind: 'micro' })
// Замена контента с изменением размера
TaigaUI.animateSwap(card, () => setState('moved'))
```
