# tui-logo-siteheader

Логотипы для шапки сайта и личного кабинета: высота 34–36.

- `t-bank` (94×34) и `t-bank-eng` — основной логотип Т-Банка, русская и английская версии.
- `t-business` (135×36) — Т-Бизнес.
- `t-shield` (29×34) — только щит, для узких шапок и мобильной ширины.
- `-inverse` — для тёмного фона и ночной темы.

Логотип не перекрашиваем и не собираем из частей. Нужной версии нет — берём из этой группы ближайшую или спрашиваем в `~tui-design-ask`.
