# tui-logo-square

Квадратные логотипы 24×24 для аватаров ячеек, списков банков и сервисов, кнопок входа.

- **Т-экосистема:** `t-shield` (`-black`, `-white`, `-transparent`, `-premium`, `-mvno`), `ts-shield-premium` (`-solid`), `t-money`, `t-private`, `dolyame`.
- **Банки:** Альфа-Банк (`alfa-bank`, `-circle`), Газпромбанк, Совкомбанк, Цифровой рубль (`digital-rub-circle`).
- **Платёжные системы и кошельки:** `payment-*` (Mastercard, Maestro, Visa, Мир, Mir Pay, Mir Supreme, UnionPay, Alipay, СБП, T-Pay), `sberpay`.
- **Сторы и сервисы:** `apple`, `android`, `google`, `google-play`, `appgallery`, `rustore`, `gosuslugi`, `yandex`, `ryadom`, `jira`, `jivo`, `ktalk`.

Чужие логотипы показываем без обрезки и искажений. Перекрашивать можно в одном случае — белый знак на фирменном фоне банка в аватаре (`Avatar` `background` + `color`, `Cell` `avatarBackground`). В остальных местах — как есть, на нейтральном фоне.
