# tui-logo

Логотипы продуктов, подписок, платёжных систем и кошельков, высота 24. Ставим в ячейки, карточки, списки способов оплаты и бейджи подписок.

- **Платёжные системы** `payment-*`: Mastercard, Maestro, Visa, Мир, Mir Supreme, UnionPay, СБП. Есть варианты `-monochrome`, `-metal`, `-gold`; `-mini` — короткая версия; `payment-sbp-wordmark` — СБП с надписью.
- **Кошельки** `wallet-*`: T-Pay, Mir Pay, Alfa Pay, Google Pay, Samsung Pay.
- **Подписки** `subscription-*`: Pro, Premium, Private. Есть капсулы (`-capsule`), цветные (`-color`), с градиентом (`-gradient`) и инверсные (`-inverse`).
- **Щиты на подложке** `shield-on-bg-*` (80×80): общий, Бизнес, Инвестиции, Мобайл.
- **Прочее:** `t-id`, `t-private-white`, `time`, `tui`.

Суффиксы:
- `-inverse` и `-on-dark` — для тёмного фона и ночной темы;
- `-monochrome` — когда цветной логотип спорит с интерфейсом.
