# Фильтры и сортировка

Пересказ Figma-гайда-паттерна «Фильтры и сортировка». Статус «Актуально», последнее изменение 22.07.2026, хранители `@cdp-filter-and-sort`. Готовые сборки лежат в разделе «Шаблоны экранов». Здесь — правила, по которым их применять.

**Главное различие:** фильтрация меняет **состав** выдачи, сортировка — **порядок** вывода.

## Точка входа: строка чипсов
- Всё живёт в `tui-chip-group`, базовый размер чипса — **medium**.
- Порядок фиксированный:
  1. **Сортировка** — всегда первая, только иконка `arrows-up-down`.
     Чип только с иконкой — без текста, с `ariaLabel` («Сортировка», «Все фильтры»); в `ChipGroup` — `ariaLabel` у пункта.
  2. **Расширенные фильтры** — иконка `settings`. Если сортировки нет, встают первыми.
  3. **Одиночные фильтры** — название и иконка dropdown.
  4. **Бинарные фильтры** — в конце, только текст.

**Какие фильтры выводить:**
- **1–2 ключевых параметра** — только одиночные фильтры, экран расширенных не нужен. Например, «Марка» и «Цена».
- **3 и больше параметров** — добавляем расширенные фильтры и сохраняем одиночные в строке. Популярные параметры могут повторяться в обоих местах.
  - Исследование T-Авто показало: часть людей идёт через расширенные фильтры, часть меняет параметры из строки. Нужны оба входа.
- **Параметр был только в расширенных** — после выбора выносим его в строку.

**Где стоит строка:**
- **Часть контента** — сервисы, построенные вокруг выдачи (T-Авто, Шопинг).
  - Строка в теле страницы.
  - При скролле вниз уходит из вида.
  - При скролле вверх появляется снова и прилипает к нижней границе аппбара.
- **Часть навигационной панели** — сервисы с картой или другой постоянной рабочей областью (Топливо, Путешествия, Недвижимость, Банкоматы). Строка видна всегда.

## Типы фильтров

**Бинарный** — параметр «да/нет».
- Пример: «Со скидкой», «Для бездорожья».
- `tui-chip` с названием и, при необходимости, иконкой. По тапу становится `accent` и сразу обновляет выдачу.
- Бейджи, каунтеры и крестики не используем.

**Одиночный** — один параметр за раз: одно или несколько значений из фиксированного списка.
- Собирается в `tui-bottomsheet`: заголовок, значения, кнопка применения.
- Как показывать значения:
  - **Чипсы** — названия короткие, значений немного, без вертикального скролла. Выбранные подсвечиваются. Кнопка применения обязательна, даже если значение одно.
  - **Список `tui-cell`** — меньше 10 значений, но названия длинные или список удобнее сканировать. Выбранные остаются на своих местах.
  - **Список с поиском** — больше 10 значений.
    - Шторка на всю высоту.
    - Выбранные остаются на местах в списке и дублируются чипсами в закреплённом блоке под поиском, в порядке нажатия.
    - Если чипсы не помещаются, блок скроллится горизонтально.
  - **Поля ввода** — числа и диапазоны (см. ниже).

**Расширенный** — несколько групп параметров.
- Fullscreen-модалка с аппбаром, группами и кнопкой применения. Переходы внутри — по разделу «Навигация в мобильных приложениях».
- Каждая группа начинается с `tui-header` размера **S**. Содержимое группы:
  - **список чипсов** — множественный, единичный или бинарный выбор (тогда каждый чип — отдельный параметр). По умолчанию не больше **3 рядов**. Правило одно для всех групп на экране;
  - **поля ввода** для чисел и диапазонов;
  - **`tui-cell [switch]`** со стилем Heading S — для «да/нет», которые нельзя объединить в чипсы;
  - **кастомные комбинации** контролов. Между границами контента — **20 px**.
- Отступы:
  - в `tui-header` и чипсах уже есть внутренние отступы, внутри секции ничего не добавляем;
  - дополнительный отступ — только между секциями, от аппбара сверху и в конце списка снизу.

**Длинные списки в расширенных фильтрах:**
- **На той же странице** — для популярных параметров.
  - Чип «Ещё N», где N — число скрытых значений. После раскрытия текст меняется на «Свернуть», с иконкой `arrow-sort-up`.
  - В свёрнутом виде до 3 строк чипсов, в развёрнутом — до 10.
- **На отдельном экране** — для слишком длинных параметров.
  - Переход по `tui-button [link]` «Ещё», без числа.
  - Выбор синхронизируется в обе стороны.
  - Новое значение после возврата встаёт первым в группе.
  - Лимит в 3 ряда на основной странице сохраняется.
  - Снятое на основной странице значение не исчезает сразу — только после повторного захода и возврата.

**Взаимоисключающие значения.** Если у комбинации нет результатов, после первого выбора недоступные значения в других группах дизейблим. Так пользователь не приходит к пустой выдаче. Если вариантов слишком много, сервис может их скрывать.

## Сортировка
- Всегда в `tui-bottomsheet` с заголовком «Сначала показывать».
- Варианты короткие и отвечают на вопрос «что показать первым»: Популярные, Дешёвые, Дорогие, С высоким рейтингом.
- Поведение:
  - Одно значение выбрано всегда. Пустого состояния и «Сбросить» нет.
  - Дефолтный вариант стоит первым.
  - Порядок списка при выборе не меняется.
  - Применяется сразу, без кнопки подтверждения.

## Чипсы на выдаче
**Активное состояние:**
- Сортировка и расширенные фильтры → `accent`, только базовая иконка. Без бейджей, каунтеров и расшифровок.
- Одиночный фильтр:
  - **одно значение** — вместо названия параметра пишем значение («BMW»);
  - **несколько значений** — название параметра и бейдж с каунтером («Кузов» + 2).
- Числа — не «сухие», с единицами и контекстом:
  - «От 150 л. с.» — изменена нижняя граница;
  - «До 600 л. с.» — изменена верхняя;
  - «150 – 600 л. с.» — обе. Среднее тире, вокруг него неразрывные пробелы.
- Максимальная ширина `tui-chip` — **184 px**, дальше фейд.
- **Фильтр со значением по умолчанию** (период «Этот месяц», город по геолокации): с дефолтным значением чип нейтральный и показывает это значение; `accent` — только когда значение отличается от умолчания. Открытый дропдаун или календарь цвет чипа не меняет.
- **Чипы как переключатель** (`ChipGroup` `single` вместо `Segmented`): это выбор раздела, а не фильтр со значением по умолчанию — первый вариант «Все» выбран и синий (решение команды, 29.10.2026).
- **Лента операций:** фильтры — период (месяц), карта, счет и т. п. Тип операции (поступления и списания) фильтром-переключателем не делаем — его показывают знак и цвет суммы.

**Выбор прямо в строке** (одиночный и бинарный):
- После нажатия чипс остаётся на месте, чтобы интерфейс не прыгал.
- В начало ряда встаёт, только если пользователь ушёл с выдачи и вернулся.
- При сбросе остаётся на текущей позиции.

**Выбор в расширенных фильтрах:**
- Любой выбранный параметр выносится в строку первым. Если чипса не было, он создаётся.
- При сбросе добавленный чипс не исчезает сразу, а остаётся неактивным до ухода с выдачи.

## Кнопка применения
- Большая `tui-button` на подложке по гайду `tui-floating-container`, закреплена внизу экрана.
- Текст — «**Показать [количество] [объектов]**» со склонениями: «Показать 15 моделей», «Показать 21 модель».
- «Ок», «Готово», «Применить», «Закрыть» нельзя — они не говорят, сколько будет результатов.
  - Исключение: на экране со списком значений внутри расширенных фильтров допустимо статичное «Применить». После нажатия выбор фиксируется, и пользователь возвращается назад.
- **Пересчёт.** При любом изменении (чипс, список, ввод) на кнопке лоадер. Против мерцания — правило **300/500**.
- **Ноль результатов.** Кнопку не дизейблим. Пишем «Таких [объектов] нет» и ведём на экран пустой выдачи. Тексты экрана пустой выдачи — `copy.md`, ER8.

## Кнопка «Сбросить»
- Появляется в аппбаре без анимации, когда есть выбранные значения или изменены предустановленные.
- Сбрасывает значения, пользователь остаётся на экране.
- Есть и в расширенных, и в одиночных фильтрах. У сортировки её нет.

## Поиск по списку
Поле поиска берём из TUI Mobile.
- Добавляем, если значений **больше 10**.
- Во время ввода прячем кнопку подтверждения.
- Фильтруем по мере ввода.
- При выборе значения или скролле поиск деактивируется.
- При скролле поиск прилипает к аппбару.
- Нет совпадений — «Ничего не нашлось».

## Пустая выдача
- `tui-block-status`. Сначала коротко причина, затем что делать дальше.
- Примеры:
  - «Не нашли подходящих авто» / «Попробуйте изменить фильтры или оставьте заявку на подбор»;
  - на карте: «Не нашли подходящих квартир» / «…или отдалить карту».
- Сообщение без подсказки оставляет в тупике — так нельзя.

## Поля ввода
Цена, пробег, год — `tui-textfield`, в одиночных и расширенных фильтрах.
- **Дефолт.** Где уместно по бизнес-логике, поля заранее заполнены минимумом и максимумом. Пока границы не тронуты, параметр неактивен, а чипс показывает только название («Цена»).
- **Проверка ввода:**
  - меньше минимума или 0 → заменяем на дефолтный минимум;
  - больше максимума → на дефолтный максимум.
- **Иконку очистки выключаем.**
- **Фокус:**
  - в расширенных фильтрах инпут подскролливается в зону видимости, а CTA прячется за клавиатурой;
  - в одиночных клавиатура поднимает всю шторку, и CTA остаётся видимым.
- Изменена хотя бы одна граница → значение выносим в чипс.
