# Лейауты страниц

Каркасы страниц: где шапка, какая ширина колонки, какие отступы между крупными блоками. Отдельного гайда по лейаутам нет — правила собраны по рабочим макетам продуктовых команд. Собирая экран, сначала найдите здесь подходящий лейаут, потом наполняйте его компонентами.

## Детали операции

Экран операции из ленты. Источник — TUI Templates: `[desktop] template-feed-details` и `[mobile] template-details-modal`. В коде — `TaigaUI.DetailsLayout`, контент — любые компоненты ДС.

### Порядок блоков
1. Шапка — `BlockDetails`: превью, название и описание, сумма, описание суммы, комментарий, бейджи, статус.
2. Ряд действий — `ButtonVertical`.
3. Карточки — `CardLarge`: заголовок, подзаголовок, справа аватар или ссылка; внутри ячейки `Cell`.

Иконки на экране — **Fancy** (`medium/…`): в кнопках действий, аватарах ячеек и превью. Pragmatic не используем. В аватарах Fancy подставляется сам; в кнопках действий набор указываем явно — там имя без набора (`cards`) сначала ищется в Pragmatic.

### Десктоп: модалка (по умолчанию)
- `Dialog` M: 600, поля 28, радиус 24, подложка с размытием, крестик 32.
- Заголовок — дата и время операции, Heading 6 (20/24) по центру. Между заголовком и контентом 24.
- Между шапкой, рядом действий и карточками — **40**.
- Действия: `ButtonVertical` 80 × 70, между кнопками **8**, ряд по центру. Ширина у всех одинаковая — по самой длинной подписи в одну строку (до 120); до 12 символов в строку, длиннее — на вторую строку, высота по самой высокой (правила — в карточке Row).
- Карточки — `CardLarge` compact (радиус 16), между карточками **20**.
- Высота окна — по контенту; если не помещается, скроллится подложка (как у `Dialog` без `height`).

### Десктоп: полноэкранный (`mode: 'fullscreen'`)
- Полноэкранный `Dialog`, аппбар 64: «Закрыть» слева, по центру дата и время, справа пусто.
- Колонка 720, первый блок в 96 от верха. Отступы те же: 40 между блоками, 8 между кнопками, 20 между карточками. Карточки обычного размера.
- При скролле, когда название из шапки уходит под аппбар, в аппбаре вместо даты — название и сумма (UI S 13, `text-tertiary`). Смена — fade, `duration-fast`. Решение команды, утверждено; взято из редизайна «Детали операций 2.0» (файл «Операции и аналитика»).

### Мобилка
- Полноэкранный диалог с `NavigationBar`: «Закрыть» слева, дата и время по центру. Фон экрана и навбара — `background-elevation-1`, карточки — `background-elevation-2`.
- `BlockDetails` с полями 16 / 16 / 32 → ряд `ButtonVertical` 90 × 70 через 12, поля ряда 16, снизу 32 → карточки `CardLarge` через **20** с полями 16.
- Карточки — шапка «Header» со ссылкой справа и список ячеек.
- Карточкам и компонентам внутри лейаут сам ставит `platform: 'mobile'`.

### Состояния
- **Загрузка:** скелетоны шапки, кнопок и карточек (`details.skeleton`, у карточек — `skeleton`). Заголовок или аппбар и крестик доступны сразу.
- **Статус** под суммой — `details.status`, например «Обрабатываем операцию».
- **Действие из карточки** открывает обычный `Dialog` поверх деталей.

### Пробелы
- **Наведение и нажатие** у десктопной `ButtonVertical` в шаблоне не показаны.
