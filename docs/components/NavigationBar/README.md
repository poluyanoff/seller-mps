# NavigationBar (`tui-app-bar` + `tui-header [large]`)

Мобильная шапка экрана: статус-бар, аппбар и крупный заголовок. По гайду tui-appbar; варианты экранов — из Figma TUI Templates («Интернет-банк / ЛК» → `[mobile] template-ib-header`). Десктопный аппбар — `DesktopAppBar` (ниже).

**Аппбар — обязательный элемент навигации. Любой мобильный экран начинается с `NavigationBar`.** Шапку из своих `div` не собираем.

## Платформы
| | Что это | `system` |
|---|---|---|
| Нативный iOS | системный UINavigationBar без изменений | — |
| Нативный Android | TUI-компонент на навигационной панели Material 2 | — |
| **WebView / PWA, iOS** | TUI-компонент, **имитирует iOS 26** (кнопки в стекле) | `ios` (по умолчанию) |
| **WebView / PWA, Android** | тот же компонент, что в нативе | `android` |
| Старые макеты | плоский аппбар iOS 18 — только legacy | `ios18` |

## Анатомия
`start-action` (назад, закрыть или пусто) · `content` (тайтл, тайтл + сабтайтл, прогресс или свой контент) · `end-action` (иконочные или текстовые кнопки). Все части необязательны.

## iOS (PWA / WebView) — стекло iOS 26
- **Высота аппбара 54:** кнопки 44, снизу 10, по бокам **16** (на экранах от **428** — 20).
- **Отступ сверху 16** (`topIndent`, высота 70) — в режиме браузера (`display-mode: browser`), чтобы тень кнопок не обрезалась статус-баром, и в шторках (там добавляется сам). К отступу сверху прибавляется `env(safe-area-inset-top)`.
- **Кнопки** — круги 44 в «жидком стекле»: фон `--tui-background-ios-liquid-glass` (день `#ffffffb3`, ночь `#ffffff1a`), размытие 4, тень `0 8px 32px rgba(0,0,0,.09)`, фаска — внутреннее свечение и градиентная кромка 1px. Несколько кнопок справа — в одной капсуле (иконки через 24, поля 10).
  - Текстовые кнопки: поля **12** (от 428 — 16), в том числе когда их несколько.
  - Нажатие: кнопка скейлится до 1.25 и становится ярче; две кнопки — скейлится весь контейнер. В вебе быстрее, чем в нативе (`duration-fast`, `expressive-entrance`).
  - При входе на страницу кнопки появляются прозрачностью и «расфокусом» с 16 — сглаживает скачки при viewTransitions.
  - Кнопки нельзя использовать отдельно от аппбара.
- **Тайтл** — Heading S (SF Pro Semibold 17). С подзаголовком тайтл уменьшается до UI M Bold (15).
- **Переполнение:** тайтл по центру всего аппбара, пока помещается в симметричную область между левым и правым блоками; дальше — выравнивание влево на всё свободное место, многоточие.
- **Скролл** (`sticky`): прилипают статус-бар и аппбар, под ними появляется прогрессивное размытие с градиентом (linear 150ms). Если в аппбаре нет тайтла, эффект можно выключить (`scrollEffect={false}`).
- **Тайтл при скролле:** крупный заголовок уезжает под аппбар, и тайтл появляется в аппбаре (прозрачность + блюр, 500ms).
- **Фон:** аппбар работает на светлом и тёмном фоне; стиль кнопок в вебе выбираем вручную по теме (`*-day` / `*-night`).
- В Figma стекло и блюр точно не воспроизводятся — расхождение с макетом это норма.

## Android
- **Высота 56**, иконки 24 в зонах 56 (отступы 16), справа иконки через 24. Тайтл слева — Roboto Medium 20, текстовое действие — 16 Regular `text-action`.
- **Переполнение:** тайтл прижат влево и уходит в фейд.
- **Выравнивание:** можно поставить тайтл по центру всего бара (`titleAlign: 'center'`), остальное на месте.
- **Нажатие:** в нативе системный риппл, в PWA / WebView цвет меняется на `action-hover`.
- **Тайтл при скролле** появляется прозрачностью (`duration-fast`, `productive-standard`).
- **Фон при скролле:** если фон прозрачный (`background: 'transparent'`), он меняется на нужный цвет с началом скролла и заканчивается к позиции 32.

| до ячеек | 12 | 12 |

## Шапка чата
`large: false` + `avatarProps` (или `avatar`) — шапка экрана переписки по Figma «TMSG. Library» → navigation-bar / chat: после «Назад» аватар 36, через 12 имя и статус, всё прижато влево. Справа — иконки: поиск — `service/search-common`, по толщине как «Назад» (`service/search-ios` тоньше).
- Имя: iOS — Heading S (17), Android — Heading S (Roboto Medium 16), `text-primary`. Статус (`subtitle`): UI S, `text-secondary` — «На связи 24/7», «Был сегодня в 12:30».
- `avatarProps` — пропсы `Avatar`: `{ bank: 't-bank' }`, `{ name }`, `{ src }`. Или `avatar` — имя иконки или URL.
- `onTitleClick` — нажатие на аватар и имя: профиль собеседника или чата.
- Фон в чате — `background: 'base'`, как у ленты.
```js
h(TaigaUI.NavigationBar, { large: false, background: 'base', title: 'Поддержка', subtitle: 'На связи 24/7', avatarProps: { bank: 't-bank' }, onBack: back, right: [{ icon: 'service/search-common', label: 'Поиск' }] })
```
Лента и панель ввода — `ChatMessage`, `ChatDivider`, `ChatInput`.

## Прогресс, крупный заголовок, варианты
- **Прогресс** — вместо тайтла: 140×8, радиус 100, дорожка `background-neutral-1`, заливка `background-accent-2`. Для шагов сценария.
- **Крупный заголовок** — `tui-header [large]`: iOS 30/36 Bold, Android 28/34 Medium, по бокам 16. Справа кнопка-иконка (`titleAccessory`); `personTitle` — аватар 36 через 12 и шеврон 24 (переход в профиль).
- **Статус-бар** — iOS 44, Android 32. В макетах, прототипах и превью показываем всегда. `statusBar={false}` — только в коде продукта для WebView, там его рисует система.
- **Строка под крупным заголовком** (`largeSubtitle`) — через 8: UI M, `text-secondary`. Например, «УСН «Доходы» 6%».
- Фон по умолчанию — `background-base-alt`; другой — `background` (имя токена, `base` или `transparent`).

| Вариант шаблона | Как собрать |
|---|---|
| title | `title` |
| appbar + header (back / close / progress) | `title` + `onBack` / `onClose` / `progress` |
| appbar (компактный) | `title`, `large={false}` |
| header + button | `title`, `titleAccessory` |
| appbar + personTitle | `title`, `avatar`, `onTitleClick` |

## Когда какой
- **Экран первого уровня** — крупный заголовок без «Назад», внизу `TabBar`.
- **Вложенный экран (push)** — «Назад» и крупный заголовок; таб-бар остаётся.
- **Сценарий (модалка)** — «Закрыть» слева, шаги прогрессом, таб-бара нет. Модальный экран iOS 18 — `modal` (аппбар 56).
- **Нет крупного заголовка** — тайтл в аппбаре (`large={false}`): детали операции, длинные списки, фильтры.

## Десктоп — `DesktopAppBar`
- Высота от **64**, ширина любая — рекомендуем от **720**. Можно увеличивать высоту (`height`).
- Слева шеврон 16 + «Назад», справа текстовые действия — 17, `text-action`; тайтл по центру — 17 Medium.
- Между блоками 20. Тайтл по центру, пока помещается между блоками, дальше — фейд.
- Наведение — `action-hover`, нажатие — `action-pressed`.
- На нём построен аппбар полноэкранного `Dialog`.
- `subtitle` — вторая строка под тайтлом: UI S 13, `text-tertiary` (например, сумма операции). `titleKey` — при смене ключа тайтл появляется fade, `duration-fast`.

## Дополнительно
- Цвета и стиль текста можно менять. Режим чувствительных данных (`tui-sensitive`) в ДС пока нет. Смена тайтла по «якорям» при скролле (fade, `duration-fast`; следующий якорь — через 200 % высоты аппбара) есть только на десктопе в `DetailsLayout`; общего механизма для навбара пока нет.

## API
```js
h(TaigaUI.NavigationBar, { title: 'Платежи', sticky: true })                                   // iOS 26, крупный заголовок схлопывается в аппбар
h(TaigaUI.NavigationBar, { title: 'Перевод', onBack: back, progress: 0.3 })
h(TaigaUI.NavigationBar, { system: 'android', title: 'Фильтры', onClose: close, right: { label: 'Сбросить', onClick: reset }, sticky: true, background: 'transparent' })
h(TaigaUI.NavigationBar, { title: 'Детали операции', subtitle: '12 октября', large: false, onBack: back, right: [{ icon: 'medium-pragmatic/share', label: 'Поделиться' }] })
h(TaigaUI.DesktopAppBar, { onBack: back, title: 'Заявка на кредит', right: { label: 'Закрыть', onClick: close } })
```
| Проп | Значения |
|---|---|
| `system` | `ios` (iOS 26, по умолчанию; `ios26` — то же) · `android` · `ios18` (legacy) |
| слева | `onBack` → «Назад», `onClose` → «Закрыть»; `left`: `back` · `close` · `none` · `{ label, onClick }` · элемент |
| середина | `title`, `subtitle`, `progress`, `titleAlign: 'center'` (Android) |
| справа | `right`: `{ icon, label, onClick, badge }` или `{ label, onClick }`, можно массив |
| крупный заголовок | `large` (по умолчанию `true`), `largeSubtitle`, `titleAccessory`, `avatar`, `onTitleClick`, `compactTitle={false}` — не показывать тайтл в аппбаре при скролле |
| скролл | `sticky`, `scrollEffect` (по умолчанию со `sticky`), `scrollTarget` (по умолчанию ближайший скроллящийся родитель) |
| прочее | `statusBar`, `time`, `topIndent`, `modal`, `background`, `children` — блок под заголовком (поиск, чипы) |

## Пробелы
- Прогрессивное размытие упрощено: один слой блюра с маской и градиентом вместо 20 слоёв из гайда.
- Длительность появления кнопок при входе на страницу в гайде не указана: `duration-moderate`.
- Когда именно включать `topIndent` в WebView, по гайду не до конца ясно: по умолчанию выключен, в шторке включается сам.
