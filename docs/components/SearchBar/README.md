# SearchBar (`tui-search-bar`)

Панель с полем поиска и кнопкой закрытия поиска (раньше «Отменить»). Не путать с обычным полем: на десктопе поиск — это `Input` с иконкой (см. «Поле поиска» в разделе про формы). Источник — гайд `tui-search-bar`. Готов на всех платформах.

## Платформы
- **iOS (натив)** — системный `UISearchBar` / `UISearchController`, иконка поиска перекрашена в `UIColor.secondaryLabel`.
- **Android (натив)** — TUI-компонент на основе панели поиска Material 2.
- **WebView / PWA** — TUI-компонент, который имитирует нативную панель: на iPhone — как в iOS 26, на Android — как в Android. В коде платформу задаёт `system`.

**Анатомия:** левая иконка, поле с лейблом, правая иконка (очистка), действие справа (закрытие поиска).

## iOS 26 (и PWA на iPhone)
- **Панель:** отступы 0 / 20 / 16 / 20 (высота 60), между полем и кнопкой закрытия 16. Поля у панели свои: не оборачиваем её в контейнер с отступами. Поиск получается на 4 уже карточек экрана (20 против 16) — так по гайду.
- **Поле:** высота 44, пилюля, отступы 10 / 8 / 10 / 10. Слот иконки 24 (лупа 16), до текста 6. Текст `ios-ui-l` 17/20 (Android — `android-ui-m` 14/16).
- **Неактивный текст и иконки** — кастомный цвет, как в нативе: `#3C3C4399` в светлой теме, `#EBEBF599` в тёмной.
- **Стили:**
  - `floating` — стекло (liquid glass), для закрепления при скролле;
  - `inline` — заливка `neutral-2`, внутри контента страницы.
- **Очистка** появляется только у заполненного поля, с анимацией opacity 0→1 и scale 0.8→1 (`productive-standard`, `fast`). Фокус после очистки остаётся в поле.
- **Кнопка закрытия** — круг 44 со стеклом. Выезжает из-за края экрана при активации, поле при этом сужается: `expressive-entrance`, `slow`, смещение 60.
- **Длинный запрос:** в фокусе обрезается начало строки, без фокуса — фейд в конце. Отдельного состояния нажатия у поля нет.

## Поведение iOS
- **При скролле:**
  - со сменой стиля — под большим заголовком поиск `inline`, при скролле становится `floating`;
  - всегда закреплённый — поиск закреплён вместе с аппбаром и стиль не меняет.
- **При активации** панель уезжает к верху экрана, стиль становится `floating`, появляется кнопка закрытия.
  - **Выдача встроена в контент** — страница плавно подскролливается вверх, аппбар скрывается.
  - **Выдача в оверлее** — панель переезжает без анимации. Резкость сглаживают клавиатура, появление кнопки и сдвиг фонового контента на 10 вверх.
  - **По желанию** — прогрессивный блюр фона для читаемости.
- **Инлайновая активация** (поле активируется на месте) — только если другие варианты не подходят, например в шторках.

## Android
Построение одинаковое в нативе и вебе.
- **Панель:** отступы 10 / 16.
- **Поле:** высота 36, радиус 20, заливка `neutral-2`, отступы 6 / 12 / 6 / 10. Текст `Body M` 14, по бокам 8.
- **Иконки и нажатия:**
  - Иконки 24, область нажатия 44, у кнопок свой контейнер с рипплом 32.
  - Слева лупа (`text-secondary`). После активации она меняется на «Назад» синим, после первого символа справа появляется очистка.
  - На нативе ripple при нажатии на поле и очистку, в вебе без эффекта.
- **Выдача:**
  - на новом экране (натив) — поле сразу наверху и в фокусе, анимация системная;
  - в оверлее (PWA / WebView) — как на iOS: без анимации панели, сдвиг контента на 10.
- **Вызов по кнопке:** поиск можно открыть кнопкой — оверлеем или на новом экране, поле сразу активно, клавиатура открыта.

## Для веба (iOS-стекло)
- **Фон:** днём `#ffffffb3`, ночью `#ffffff1a`.
- **Эффекты:** `backdrop-filter: blur(4px) saturate(1.3) brightness(1.05)`, тень `0 8px 32px rgba(0,0,0,.09)`.
- **«Фаска»** — псевдоэлементы с маской и градиентом `--tui-background-button-ios-liquid-glass-bevel-gradient`, полные стили в гайде.
- **Нажатие кнопки** — `scale` и яркость, быстрее, чем в нативе.

В коде фаска упрощена до тонкой светлой обводки.

## API в коде
```js
h(TaigaUI.SearchBar, { appearance: 'inline', placeholder: 'Поиск', value: q, onChange: setQ, onCancel: close })
h(TaigaUI.SearchBar, { system: 'android', onSubmit: search })
```
Пропсы:
- вид: `system` (ios · android), `appearance` (floating · inline; в активном состоянии всегда floating), `placeholder` / `label`;
- значение: `value` / `defaultValue` / `onChange`, `onSubmit` (Enter);
- активность: `active` / `defaultActive` / `onActiveChange`, `onCancel` (кнопка закрытия, «Назад», Esc), `onFocus`, `onBlur`, `autoFocus`;
- подписи для озвучки: `cancelLabel`, `clearLabel`, `ariaLabel`.

Подъём к верху экрана, скрытие аппбара, смену стиля при скролле и блюр делает экран, который использует компонент.
