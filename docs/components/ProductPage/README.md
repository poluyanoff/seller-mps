# ProductPage — продуктовая страница (Продуктовая 2.1)

Экран с информацией о продукте, когда клиенту не хватает данных, чтобы решиться. Десктоп — попап (Figma «Origination. Demo Guides (Web)», «Продуктовая 2.1», компонент `Product page`). Мобилка — экран `platform="mobile"` (Figma «Продуктовая 2.0», раздел «Web (mobile)»: Browser, PWA, WebView). Правила контента — в разделе «Ориджинейшен».

**Это лейаут, а не самостоятельный компонент:** десктоп собран из `Dialog`, `Header`, `CardLarge`, `Cell`, `Link`, `Button`; мобилка — из `NavigationBar`, `Header`, `CardLarge`, `Cell`, `Avatar`, `Loader`, `FloatingContainer`. Своё у него — только сетка, графический блок и фейды. Стили частей не меняем.

## Где используется
- В ориджинейшене: жёлтая кнопка закрывает попап и ведёт на следующий шаг.
- Вне ориджинейшена: жёлтая кнопка ведёт в ориджинейшен продукта. Попап закрывается, открывается модалка оформления с «Закрыть».
- Анимация — как у `OnboardingFlow`.

## Построение
| | |
|---|---|
| Оверлей | `service-backdrop` + blur 32 (это `Dialog`) |
| Попап | 960 × 636, радиус 24, `elevation-1`, `shadow-popup`; крестик 32 в 16 / 16 |
| Графический блок | слева 480 × 636: градиент продукта + 3D-иллюстрация по центру, картинка на весь блок или видео (автоплей без звука); пока грузится — шиммер |
| Правая колонка | 480, отступы 48 / 48 / 0 / 48; `Header` H3 (Heading 3) → контент через 24; блоки контента через 20 |
| Контент | карточки `CardLarge` на `elevation-2`; выгоды — `benefits` (квадратные аватары) |
| Ссылка и лигал | в конце контента, между ними 20; лигал — `ui-s`, `text-secondary`, не закреплён |
| Кнопки | закреплены снизу колонки, L во всю ширину (384), бока 48; одна — снизу 48; две — между 8, снизу 24; подложка — фейд в `elevation-1` |
| Скролл | при фиксированной высоте скроллится только правая колонка; при скролле сверху появляется фейд 110 |
| `fixedHeight={false}` | попап растёт по контенту, медиа по центру слева, скроллится оверлей |
| Внутренний переход (`page`) | контент на всю ширину попапа (864), отступы 48, `Header` H4 → контент через 24, «Назад» 32 в 16 / 16 слева, крестик справа; при скролле фейд 120 |
| Уже 960 | сжимается графический блок, правая колонка остаётся 480 |

## Мобилка (`platform: 'mobile'`)
Экран на `background-base`, сверху вниз:

| Блок | Обязательный | Построение |
|---|---|---|
| Навигационная панель | да | `NavigationBar` поверх картинки, слева «Закрыть»; фон прозрачный, при скролле — цвет фона экрана (поведение NavigationBar) |
| ProductHeroBanner | да | картинка или видео во всю ширину, высота **320**, `object-fit: cover` (обрезается по ширине, по центру); снизу фейд **64** в `background-base` |
| ProductTitle | да | caption (`body-m`, `text-secondary`, по центру; 8 / 16 / 0 / 16) → `Header` L по центру с описанием (8 / 16 / 20 / 16) |
| ProductBenefits | да | сверху 12, карточки через 20, снизу 20, поля 16 |
| ProductSecondaryAction | нет | `Cell` во всю ширину, текст `text-action`: открыть PDF или информационный экран |
| ProductLegalText | нет | `ui-s`, `text-secondary`, 8 / 16 / 0 / 16; может содержать ссылки на PDF и экраны (например, сбор согласий) |
| Кнопка | да | `FloatingContainer` с градиентной подложкой, кнопка L; снизу контента 24 |

- **Блоки выгод** (`benefits`): `ProductBenefitsSingle` — карточка с одной ячейкой; `ProductBenefitsCommon` — карточка со списком **3–10 ячеек одного вида**. Аватар Small 40, квадрат, по умолчанию фон `neutral-2`, иконка `text-primary` (цвет можно менять: `background`, `color`). Блоки можно заменить своим лейаутом или компонентом — передайте элемент в `benefits` или `children`.
- **Тексты:** caption — до 40 символов, заголовок — до 50, описание — до 100, title ячейки и description — до 80–85.
- **Картинка:** готовим отдельно для светлой и тёмной темы (`image` и `imageDark`). Видео стартует при открытии страницы.
- **Загрузка медиа:** пока картинка или видео грузятся — `Loader` 40 по центру; появление — `duration-fast` (150 мс), `productive-standard`.
- **Загрузка экрана** (`skeleton`): лоадер в картинке, скелетон заголовка и три карточки-скелетона; ячейки-действия, лигала и кнопки нет. Оптимально 1–3 секунды, дальше — ошибка. Данные из кэша показываем сразу.
- **Ошибка загрузки экрана** — `BlockStatus` («Что-то не загружается» / «Попробуйте зайти позже») на экране с «Закрыть» в аппбаре; в компонент не встроена.
- **Ресайз:** всё тянется по ширине, поля 16 сохраняются.

## Контент
- Заголовок — название продукта в 1–3 слова, в одну строку (максимум две). Описание (`subtitle`) обязательно.
- **1 киллер-фича + 3–4 УТП.** Больше не читают, меньше — образуется «дыра».
- **Аватары выгод — квадратные** на обеих платформах: `Avatar` Small 40, радиус 12, фон `neutral-2`, иконка `text-primary`. Проп `benefits` ставит их сам; собирая карточки руками, передавайте в `Cell` элемент `Avatar` с `shape: 'square'`, а не `avatarTone`. Акцию подсвечиваем жёлтым фоном иконки (`background` у выгоды).
- Блок хелпов (частые вопросы) — внизу. Ссылки на внешние ресурсы открываем в новой вкладке.
- Кнопка — жёлтая `primary` (Pro, Premium, Private — по брендбуку: `primaryAction.appearance`), до 29 символов. Вторая кнопка (`flat`, под основной) — только если без неё никак.
- Внутренние переходы — только информационные, без форм.

## Заглушка картинки
Пока продукт не передал свою картинку (`image`, `video`, `media`), в графическом блоке стоит заглушка — 3D-иллюстрация (карта Business, купюра, «0») на прозрачном фоне. На десктопе — в рамке **480 × 368** по центру блока, внутри поля 48 сверху и снизу и 64 по бокам, на фоне продукта (`background`, по умолчанию `neutral`). На мобилке — крупно, почти на весь блок 320: поля 16 по бокам и снизу, 40 сверху. Своих 3D-картинок в ДС нет: база иллюстраций живёт отдельно, продукт кладёт файл рядом с прототипом и передаёт в `image`. Отключить заглушку — `placeholder: false`.

## Фон графического блока
`background` — пресет продукта или любой CSS-фон:
`business`, `insurance`, `platinum`, `investments-1`, `investments-2`, `black`, `black-2`, `airlines`, `installment` (Рассрочка / Кубышка), `junior-1…4`, `mobile`, `pro`, `premium`, `referral`, `city-afisha`, `city-supermarket`, `city-restaurants`, `city-fuel`, `city-shopping`, `city-travel`, `city-auto`, `city-beauty`, `city-services`, `city-5-letters`, `city-flowers`, `neutral`.
- **Свой фон у каждого продукта.** Пресеты — только то, что есть в компоненте Figma. Фон конкретного продукта (например, линейный градиент из макета) передаём в `background` строкой CSS: `'linear-gradient(160deg, #FDC160 0%, #914613 100%)'`. В ДС такие фоны не добавляем.
- Продукт без своего цвета — `neutral` (подставится сам, если задана иллюстрация, а фона нет). Градиенты по бизнес-линиям скоро уйдут.
- В тёмной теме фон иллюстрации не меняется.
- 3D-иллюстрация приземлённая или левитирующая, без пьедестала (кроме Premium). Иллюстрации — из библиотек 3D и SME.

## API
```js
h(TaigaUI.ProductPage, {
  open, onClose: close,
  background: 'business',                 // пресет или CSS-фон
  image: h(TaigaUI.Illustration, { name: 'card-check', size: 220 }), // или URL картинки
  imageFit: 'center',                      // 'center' — иллюстрация на градиенте; 'cover' — картинка на весь блок
  video: 'promo.mp4', poster: 'promo.jpg', // вместо image
  title: 'Дебетовая карта', subtitle: 'Бесплатная, с кэшбэком рублями',
  primaryAction: { label: 'Оформить карту', onClick: next },
  secondaryAction: { label: 'Оформить только сервис' }, // только если необходимо
  link: h(TaigaUI.Link, { href: '…', target: '_blank' }, 'Тарифы и условия'),
  legal: 'Нажимая «Оформить карту», вы соглашаетесь…',
  page: null,                              // внутренний переход: { title, content, onBack }
}, killerFeatureCard, uspCard, faqCard)

// Мобилка: тот же компонент, другой лейаут
h(TaigaUI.ProductPage, {
  platform: 'mobile', onClose: close,
  image: 'hero-day.jpg', imageDark: 'hero-night.jpg', // или video
  caption: 'Дебетовая карта', title: 'Black', subtitle: 'Кэшбэк рублями и бесплатное обслуживание',
  benefits: [
    { icon: 'bonus-percent', title: 'До 30% кэшбэка', description: 'У партнеров' },          // Single
    { items: [{ icon: 'piggy-bank', title: '…' }, { icon: 'card-frontside', title: '…' }, { icon: 'cash-check', title: '…' }] }, // Common, 3–10
  ],
  infoAction: { label: 'Тарифы и условия', onClick: openPdf },
  legal: 'Нажимая «Оформить карту»…',
  primaryAction: { label: 'Оформить карту', onClick: next },
})
```
Пропсы: `platform` (`mobile` — мобильный экран), `system` (мобилка), `statusBar`, `appBar` (доп. пропсы NavigationBar), `caption` (мобилка), `imageDark` (мобилка), `skeleton` (мобилка), `benefits` (оба: блоки выгод), `infoAction` (`{ label, onClick, href }`: десктоп — ссылка, мобилка — ячейка), `open`, `onClose`, `title`, `subtitle`, `header` (доп. пропсы `Header`), `background`, `image`, `imageFit`, `video`, `poster`, `media` (свой элемент в графический блок), `mediaLabel`, `mediaLoading` (принудительная загрузка медиа), `placeholder` (по умолчанию true — 3D-заглушка без своей картинки), `children`, `link`, `legal`, `primaryAction`, `secondaryAction`, `footer` (свои кнопки вместо действий), `fixedHeight` (по умолчанию true), `page`, `backLabel`, `closeLabel`, `inline`, `container`, `dialog` (доп. пропсы `Dialog`), `className`.

## Пробелы
- Цвета градиентов в Figma заданы без токенов (компонент `background`, вариант Color) — в ДС лежат пресетами компонента. Вариант `Custom` в Figma пустой.
- Мобилка: в гайде цвет нижнего фейда указан двояко — «Neutral 1 Opaque» в параметрах градиента и «iOS — Elevation 1, Android и Web — Base» в цвете; в макетах Web / PWA / WebView — `background-base`. В ДС — `background-base`.
- Мобилка: фон аватара в макете привязан к `State/Background/Neutral 1 Hover`, а в описании — `Neutral 2`. В ДС — `neutral-2` по описанию.
- Мобилка: у `Header` в ДС нет скелетона — в скелетоне экрана текст заголовка закрыт плашками `service-skeleton`, как в BlockDetails.
- Мобилка: в макете аппбар iOS 18 (текст «Закрыть»); в ДС по умолчанию iOS 26 (стеклянная кнопка с крестиком), legacy — `system`.
- Мобилка: внутри карточки ячейка у `CardLarge` начинается на 8 от верхнего края, в макете — на 12. Оставил поведение `CardLarge`.
- Лигал в макете — `tui-text-expandable` (сворачиваемый текст); такого компонента в ДС нет, лигал выводится целиком.
- Размеры фейда под кнопками и зазор между контентом и кнопками при скролле взяты по макету (фейд на всю высоту подложки 104 / 144, контент заканчивается за 24 до кнопки).
