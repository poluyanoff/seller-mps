# Loader (`tui-loader`)

Индикатор загрузки неопределённой длительности по гайду tui-loader v1.1.1. Готов на всех платформах.

Спиннер и лоадер — одно и то же. `Loader` стоит внутри `Button` (`loading`, цвет текста кнопки, 20 / 16), полей `Input` и `Select` (`text-tertiary`, 20 / 16 / 12) и `Dropdown` (24 / 20 / 16). Своих спиннеров в ДС нет.

Если известна доля выполненного, используйте [`ProgressBar`](../ProgressBar/README.md) или [`ProgressCircle`](../ProgressCircle/README.md).

## Варианты и построение
- **Размеры:** 12, 16, 24 (по умолчанию в коде), 32, 40. Можно задать любой, например 18, 28 или 36.
- **Толщина линии** — 1/12 размера, но не меньше 1,5:
  - 12 и 16 → 1,5;
  - 24 → 2;
  - 32 → 2,67;
  - 40 → 3,33.

  Свою толщину задаёт `thickness`. Тоньше 1,5 не бывает.
- **Цвет:**
  - десктоп — `background-accent-1`;
  - мобилка — `brand-t-bank`.

  Можно задать любой цвет из палитры или свой (`color`).

## Поведение
- Работает неопределённое время.
- **Минимальное время показа** — 500 мс после появления (`minDuration`, можно поменять). С пропом `loading` лоадер сам выдерживает это время, а потом показывает `children` или ничего.
- **Анимация** — полный цикл 4000 мс, интерполятор linear. Две части:
  - **линия** — за 2000 мс растёт от 0 до 95 % окружности, следующие 2000 мс убывает до 0;
  - **контейнер** — вращается вокруг центра, оборот за 2000 мс.

## Доступность
- Не увеличиваем при крупном шрифте.
- Отдельно не фокусируем. Озвучку («Идет загрузка») закладываем в родительский компонент: по умолчанию лоадер скрыт от скринридера.
- `label` (`true` — «Идет загрузка» или своя строка) делает лоадер `role="status"` со скрытым текстом — когда родителя, который озвучит загрузку, нет.

## API
```js
h(TaigaUI.Loader, { size: 24 })
h(TaigaUI.Loader, { size: 40, platform: 'mobile' })
h(TaigaUI.Loader, { size: 28, color: 'tui-text-action' })
h(TaigaUI.Loader, { loading: isLoading, minDuration: 500, label: true }, content) // держит лоадер не меньше 500 мс
```
Пропсы:
- `size`, `thickness`, `color`;
- `platform`;
- `loading`, `minDuration`, `children`;
- `label`, `className`, `style`.

## Пробелы
- **Уменьшенное движение.** В гайде не описано. При `prefers-reduced-motion` показываем статичную дугу 80 %, как в компоненте Figma.
