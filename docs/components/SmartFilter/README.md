# SmartFilter (смартфильтр)

Поиск и фильтры в одной строке: пользователь собирает условия «атрибут → оператор → значение» и добавляет текстовые запросы, не переключаясь между полями. Только десктоп.

## Когда использовать
- Параметров много или у них нет иерархии, и набор отдельных селектов не помещается или путает.
- Нужны операторы сравнения (>, <, ≤, ≥, ≠), мультивыбор (IN, NOT IN) или диапазон (BETWEEN) — в обычном селекте их нет.
- Нужен поиск по значению вместе с фильтрами.
- Простой листинг на 1–5 параметров — `FilterBuilder` с поиском и селектами, раздел «Табличные листинги».

## Построение
- **Поле** растягивается на всю ширину контейнера. Высота — по числу строк: 1 строка — 44 (как поле M), дальше строками по 40.
- Поля: слева 8, справа 10, радиус 8.
- Слева иконка `settings-2` 16 (поля 6 / 2, сверху 14), справа крестик полного сброса `cross` 16 в зоне 24 (сверху 10). Обе — по первой строке.
- **Элементы** — между ними 6 по горизонтали, 0 по вертикали. Элемент не переносится целиком; длинный текст в чипах гасится фейдом, элемент не шире строки.
- **Фильтр** — атрибут → оператор → значение: чипы S 32 через 2, поля группы 4 (зона ховера), высота 40.
  - Атрибут — чип с иконкой 16 `text-tertiary` и подписью.
  - Оператор — чип с иконкой (`math-equal`, `math-more`, `math-less`, `math-non-equal`, `math-more-or-equal`, `math-less-or-equal`) или текстом `ui-s-bold` `text-secondary` (NOT IN, IN, BETWEEN).
  - Значение — чип с текстом; в редактировании — `Input` S 216.
- **Поиск по значению** — чип с текстом, без иконки.
- **Курсор** — поле ввода: высота 40, поля 10 / 4, от 175. Плейсхолдер `body-s` `text-secondary`.

### Состояния элемента
- **Ховер** — чипы `status-info-pale`, чип под курсором — `status-info-pale-hover`, обводка группы 1. В правом верхнем углу — кнопка удаления.
- **Кнопка удаления** — 20 × 20, радиус 16, `background-accent-2` → hover `-hover` → pressed `-pressed`, крестик `service/cross` 16 `text-primary-on-dark`. Стоит на 8 правее и на 8 выше угла группы.
- **Редактирование** — значение в `Input` S 216, ховера и кнопки удаления нет.
- **Ошибка** — пустое значение: слот 216 на `status-negative-pale` с плейсхолдером; некорректное: чип `status-negative-pale`, текст `text-negative`, текст ошибки — в тултипе по наведению. На ховере ошибка остается красной, голубеют остальные чипы.

## Дропдауны
- **Атрибуты** (SmartFilter dropdown) — 348, до 500 в высоту, радиус 8, фон `elevation-1`, обводка `border-normal`, тень `shadow-small`. Открывается под курсором через 4 — по левому краю поля ввода, но не шире поля.
  - Тело: поля 6. Чипы атрибутов столбцом через 6, поля 6 сверху и по бокам.
  - Разделитель → «Недавние запросы» (`ui-s`, `text-secondary`) → пункты: `magnifier` 16 → 12 → текст до 3 строк → 16 → крестик. Пункт от 36, радиус 4, ховер и активный — `neutral-1`. Между пунктами 0.
  - Атрибуты закончились — вместо чипов текст «Фильтров больше нет. Напишите запрос для поиска или удалите один из фильтров».
  - Футер 44: `background-base-alt`, поля 10 / 12. Подсказки клавиш через 12: клавиша — чип 24 (`neutral-1`, радиус 4) и подпись через 4, `text-secondary`. Справа — `Link` на документацию (необязательна).
- **Поиск** (SmartFilter search dropdown) — набран текст: `Dropdown` S 320 с одним пунктом «Искать „…“» и клавишей Enter справа.
- **Операторы** (SmartFilter operator dropdown) — под чипом оператора через 4: поля 8, чипы операторов через 4, по левому краю, радиус 8. Активный оператор в списке не показываем. Набор операторов задает продукт.
- **Значения** — `Dropdown` S той же ширины, что поле (216), через 4. Дата — `CalendarDropdown`. Ключ:значение — панель `KeyValueSelect` 434.

## Поведение
- **Клик в поле** — focus и дропдаун атрибутов.
- **Создание фильтра:**
  1. Выбор атрибута. Вместо курсора встает элемент: атрибут, оператор «=» (если он есть у атрибута) и поле значения в фокусе.
  2. Выбор значения — как у `Input` и `Select` по типу атрибута. После выбора элемент заполнен, снова курсор.
  3. Оператор можно поменять: навести на элемент и нажать на чип оператора. Если новому оператору нужен другой вид значения (одно, несколько, диапазон) — значение сбрасывается, элемент в фокусе.
  4. Значение можно поменять: навести на элемент и нажать на чип значения — элемент в фокусе.
- **Поиск по значению.** Пользователь печатает вместо выбора атрибута — дропдаун меняется на поиск. Enter или клик по пункту — в строке появляется чип поиска. Поисков может быть несколько, вместе с фильтрами. Клик по чипу поиска — правка текста.
- **Удаление** — ховер на элементе и кнопка удаления. Крестик справа сбрасывает всю строку; при наведении он `text-tertiary-hover`.
- **Запрос** формируется сразу после изменения, без кнопки «Применить» (`onChange`).
- **Ошибки.** Фокус ушел, а значение не выбрано — элемент в ошибке. Значение не прошло проверку (`validate`, формат даты, число) — элемент в ошибке, текст — в тултипе. Такие условия в запрос не идут.
- **Клавиатура:** ↑↓ — пункты дропдауна, Enter — выбрать или применить поиск, Esc — закрыть дропдаун или отменить правку значения. В меню операторов — ↓ с чипа оператора, ↑↓ и Enter.

### Значения по операторам
| Операторы | Значение | В чипе |
|---|---|---|
| =, ≠, >, <, ≥, ≤ | одно: ввод (`text`, `number`), выбор (`select`), дата (`date`), ключ:значение (`tag`) | «Алиса Чистова» |
| IN, NOT IN | несколько: список с чекбоксами; при повторном открытии выбранные сверху, под ними разделитель | «Активно и **еще 1**» |
| BETWEEN | диапазон: два поля 216 через 2 — «от» в фокусе, после выбора фокус на «до» | «2.2.1 – 5» |

### Иконки атрибутов
За частыми атрибутами закреплены метафоры, остальным — по смыслу. По умолчанию `sparkle`.

| Атрибут | Иконка |
|---|---|
| Название | `sticker` |
| Создатель, автор, владелец | `user-pencil` |
| Статус | `chart-pie` |
| Группа | `users` |
| Тенант | `folder` |
| Теги | `tag` |
| Время, дата изменения или создания | `clock-circle` |
| Кем изменено или создано | `pencil` |

## Внутри FilterBuilder
SmartFilter может стоять в `FilterBuilder` (Basic filter) вместо основной строки — тогда к нему добавляются быстрые фильтры: сегменты, чипсы, тоггл, «Результат», «Очистить». Поиск, селекты, кнопка фильтров и кнопка действия не показываются.
- Чипсы быстрых фильтров можно делать пресетами: нажатие ставит в строку набор условий.

```js
h(TaigaUI.FilterBuilder, {
  smart: { attributes, value, onChange: setValue },
  segmented: { items: ['Все', 'Мои алерты'], value: seg, onChange: setSeg },
  chips: { items: ['Мои активные'], value: preset, onChange: applyPreset },
  result: 128
})
```

## Тексты
- Плейсхолдер — «Поиск или фильтр по параметру».
- Подписи атрибутов — как заголовки столбцов: «Статус», а не «Выберите статус».
- Тексты ошибок — что не так: «Дата в формате ДД.ММ.ГГГГ», «Напишите число». Без точек в конце, без «ё».

## Решения команды и отличия от Figma
- **Тексты — по-русски.** В гайде английские: «Search or filter by parameter» → «Поиск или фильтр по параметру», «Recent searches» → «Недавние запросы», «No filters left…» → «Фильтров больше нет…», «for navigating» / «to select» → «навигация» / «выбор», «Link» → «Документация». Мультивыбор «Alice and 1 more» → «Alice и еще 1», диапазон «2.2.1 and 5» → «2.2.1 – 5» (среднее тире в неразрывных пробелах, как в разделе «Фильтры и сортировка»).
- **Операторы NOT IN, IN, BETWEEN — латиницей, как в гайде**, не переводим (решение 25.10.2026).
- **Шрифт клавиш** в футере — шрифт ДС `ui-s`, в гайде SF Pro.
- **Фокус поля значения — фокус `Input` ДС** (2 `border-focus`), в гайде черная рамка 1.
- **Список значений — S** (пункт 28): так в разделе «Кастомизация», и по правилу ДС список того же размера, что поле (32). В разделе «Поведение» — M (пункт 36).
- **Тень дропдаунов — `shadow-small`**, как у `Dropdown`. В гайде `Shadow/Dropdown` 0 8 16 rgba(0,0,0,.16) — не токен. Ночью теней нет.
- **Дата — формат `InputDate` ДС** (ДД.ММ.ГГГГ, календарь `CalendarDropdown`). В гайде маска «dd-mm-yyyy hh:mm:ss:ms» и значение «08.08.2024 12:34:45.123» — не совпадают между собой; время не поддерживаем.
- **Длинный текст в чипах — фейд**, как во всех чипах ДС. В гайде многоточие.
- **Иконки атрибутов — из таблицы метафор.** В примерах гайда у всех атрибутов `sparkle`.
- **Разделитель в дропдауне атрибутов — разделитель `Dropdown` ДС** (16), в гайде 12 + отступ 4.
- **Обводка группы при ховере — 1 `status-info-pale-hover`** (решение 25.10.2026). В гайде токена нет, по пикселям ≈ #428bf9 48 %.
- **Клик по недавнему запросу — текст запроса встает в строку поиском** (решение 25.10.2026). В гайде не описан. Свое поведение — `onRecentSelect`.

## Пробелы
- **Радиус обводки группы** — 12 (чип 8 + поле 4), в гайде не указан.
- **Иконка «Название»** в таблице метафор не подписана: по описанию компонента в файле — `sticker`.
- **Максимальная ширина элемента** — в гайде ссылка на другой файл. В коде элемент не шире строки поля.
- **Disabled и loading** не показаны. Disabled — как у `Input` (0.56), loading списка значений — `loading` у атрибута (лоадер `Dropdown`).
- **Ночь** показана для поля, элемента и дропдаунов атрибутов и операторов. Фокус поля, список значений и тултип ночью — по токенам ДС.
- **Как подтверждается ввод** (`text`, `number`) — в гайде не сказано. Enter или уход фокуса.
- **Backspace на пустом курсоре** (удалить последний элемент) — в гайде нет, не делаем.
- Мобильной версии в гайде нет.

## API
```js
h(TaigaUI.SmartFilter, {
  attributes: [
    { key: 'creator', label: 'Создатель', icon: 'user-pencil', type: 'select', options: ['Алиса Чистова', 'Борис Ким'] },
    { key: 'status', label: 'Статус', icon: 'chart-pie', type: 'select', options: statuses, operators: ['=', '!=', 'in', 'not-in'] },
    { key: 'modified', label: 'Дата изменения', icon: 'clock-circle', type: 'date' },
    { key: 'port', label: 'Порт', type: 'number', validate: function (v) { return v > 65535 ? 'Не больше 65535' : null; } },
    { key: 'tag', label: 'Теги', icon: 'tag', type: 'tag', keys: { env: ['prod', 'stage'], 'browser.name': ['Chrome', 'Safari'] }, allowCustom: true }
  ],
  value: items,                                  // [{ id, attribute, operator, value }, { id, search }]
  onChange: function (items, query) { setItems(items); load(query); },
  recent: ['Статус = Активно'], onRecentSelect: applyRecent, onRecentRemove: forget,
  docsLink: { href: '/docs/search' }
})
```
- **Элемент:** `{ id, attribute, operator, value }` или `{ id, search }`. Значение: одно — строка или число (дата — ISO `ГГГГ-ММ-ДД`), IN / NOT IN — массив, BETWEEN — `[от, до]`. В управляемом режиме задавайте `id`.
- **`onChange(items, query)`** — `items` — все элементы, `query` — только применимые: со значением и без ошибки. Запрос отправляйте по `query`.
- **Атрибут:** `key`, `label`, `icon`, `type` (`text` · `number` · `select` · `date` · `tag`), `operators`, `options`, `placeholder` (для BETWEEN — `[от, до]`), `validate(value, operator)` → текст ошибки, `min` / `max` (даты), `loading`, `hidden`; для `tag` — `keys`, `allowCustom`, `docsLink`.
- **Операторы:** `'='`, `'!='`, `'>'`, `'<'`, `'>='`, `'<='`, `'in'`, `'not-in'`, `'between'`. По умолчанию: `text` — = ≠; `number` и `date` — = ≠ > < ≥ ≤ BETWEEN; `select` — = ≠ IN NOT IN BETWEEN; `tag` — = ≠.
- **Остальное:** `recent`, `onRecentSelect`, `onRecentRemove`, `docsLink`, `hints` (false — без подсказок клавиш), `footer` (false — без футера), `placeholder`, `searchLabel` («Искать»), `recentLabel`, `emptyText`, `clearLabel`, `onClear`, `disabled`, `label`, `className`, `style`.
- В `FilterBuilder` — проп `smart` с теми же пропсами.
