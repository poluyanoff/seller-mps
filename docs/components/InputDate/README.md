# InputDate (`tui-input-date`)

Поле даты с маской ДД.ММ.ГГГГ и календарём в выпадашке. Наследует `Input`, календарь — `CalendarDropdown` (десктоп) и `Calendar` (мобилка). Добавлено в ДС по запросу команды: в гайде полей отдельной страницы про дату нет, сборка опирается на правила `Input`, `Calendar` и раздел «Формы и поля ввода».

## Когда использовать
- Одна дата в форме: дата погрузки, дата рождения, дата выдачи.
- Период в фильтре — не это поле: там фильтр `type: 'period'` у `FilterTable` и `FilterBuilder` (`CalendarDropdown` с саджестами периодов).

## Построение
- Базовое поле `Input`: лейбл (существительное, без «Укажите»), значение, справа крестик и иконка календаря `small-pragmatic/calendar` 16 в контейнере 24, `text-tertiary`.
- **Маска ДД.ММ.ГГГГ.** Точки ставятся сами, остаток маски виден серым вплотную к введённому (`text-tertiary`), как у поля времени. День с цифры 4–9 и месяц с 2–9 получают ведущий ноль, день больше 31 и месяц больше 12 не вводятся.
- **Выпадашка** — `CalendarDropdown` в режиме `single` без футера: под полем через **4**, по левому краю, как список у `Select`. Нет места снизу — над полем.
- **Саджесты** (`suggests`) — колонка справа от календаря: «Сегодня», «Завтра», «Через неделю».

## Поведение
- Открытие: клик по полю, иконка календаря, ↓ или Enter в пустом поле. Esc и клик снаружи закрывают.
- Выбор дня или саджеста подставляет дату и закрывает выпадашку, фокус остаётся в поле.
- Ручной ввод полной даты сразу меняет значение и закрывает календарь. Tab закрывает календарь и ведёт к следующему полю.
- **Валидация при потере фокуса:**
  - не дописана — «Дата в формате ДД.ММ.ГГГГ»;
  - несуществующая (31.02) — «Такой даты нет — проверьте день и месяц»;
  - вне `min` / `max` — «Выберите дату не раньше 20.10.2026» / «не позже …»;
  - недоступная (`disabledDates`) — «Эта дата недоступна».

  Свой текст ошибки (`error`) важнее встроенного. Тексты — по редполитике ошибок: что сделать, без машинного языка.
- **Мобилка** (`platform="mobile"`): поле только для выбора. По нажатию — **отдельный экран** (решение команды, 29.10.2026): «Назад», заголовок-лейбл, `Calendar`, кнопка «Выбрать» (`pickLabel`). Так в WebView: шторки в модальном WebView не используем (`webview.md`). Для PWA и мобильного веба — `picker: 'sheet'`: `Calendar` в шторке `BottomSheet`, выбор дня закрывает шторку. Календарь в выпадашке на мобилке не показываем (правило `CalendarDropdown`).

## API
```js
h(TaigaUI.InputDate, { size: 'l', label: 'Дата погрузки', value: '2026-10-21', onChange: function (iso, date) {}, min: '2026-10-20',
  suggests: [{ label: 'Сегодня', value: '2026-10-20' }, { label: 'Завтра', value: '2026-10-21' }] })
h(TaigaUI.InputDate, { platform: 'mobile', label: 'Дата доставки' })
```
Пропсы:
- поле — как у `Input`: `size`, `platform`, `label`, `labelOutside`, `hint`, `hintAlways`, `error`, `disabled`, `readOnly`, `cleaner`, `loading`;
- `value` / `defaultValue` — `'ГГГГ-ММ-ДД'` или `Date`; `onChange(iso | null, date | null)`;
- календарь: `min`, `max`, `disabledDates`, `today`, `weekendHighlight`, `markers`, `labels`, `month`;
- `suggests` — `{ label, value }`;
- `onOpenChange`, `openOnClick` (`false` — открывать только иконкой);
- мобилка: `system`, `sheetTitle`, `sheet`.

## Пробелы
- В Figma-гайде полей страницы `tui-input-date` нет: размеры и отступы взяты у `Input`, выпадашка — у `CalendarDropdown`.
- Цвет иконки календаря при наведении (`text-secondary`) — по аналогии, в гайде не задан.
- Ввод в середину маски не поддержан: каретка уходит в конец.
- Диапазон дат одним полем (`tui-input-date-range`) не сделан.
