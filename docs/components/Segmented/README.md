# Segmented (`tui-segmented`)

Контрол для переключения разделов или видов внутри одного экрана, без перезагрузки страницы. По гайду `tui-segmented` (v1.3.1, 31.08.2026). Компонент разработан не на всех платформах (TUIPRJ-134), наличие в коде проверяйте.

## Варианты
- **Shape square** (по умолчанию на десктопе) — скругления как у полей и кнопок.
- **Shape rounded** — в фильтрах и рядом с другими круглыми элементами, например чипсами.
- На мобилке свой вид для iOS и Android. Дефолтное место — шапка экрана, для переключения разделов.

## Построение
- Контейнер с пунктами (items). **Минимум 2** пункта. Рекомендуемый максимум — **5 на десктопе, 3 на мобилке**.
- В пункте можно включать: icon-start, label, `tui-badge`, icon-end.
  - Если элемент остаётся один, это текст или иконка.
  - Бейдж — только вместе с текстом, единственным элементом быть не может.

## Размеры
Контейнер: padding **2**, между пунктами **4**, высота фиксированная, элементы по центру.

| | высота | радиус контейнера / пункта (десктоп) | радиус (мобилка) | паддинги пункта | текст | иконка | min ширина пункта |
|---|---|---|---|---|---|---|---|
| **L** | 56 | 12 / 10 | 16 / 14 | 14 по бокам + 6 у текста (до текста 20) | `body-m` 15/24 | 24 | 52 |
| **M** | 44 | 8 / 6 | 12 / 10 | 8 + 6 у текста (до текста 14) | `body-m` 15/24 | 24 | 40 |
| **S** | 32 | 8 / 6 | 10 / 8 | 6 + 4 у текста (до текста 10) | `ui-s` 13/16 | 16 | 28 |

Между иконкой, текстом и бейджем внутри пункта — 4. На мобилке текст `ios-ui-m` 15/18 (S — `ios-ui-s` 13/16). Мобильные размеры M и L появились в v1.3.1.

## Состояния
- **Активный пункт** — фон `elevation-3` + `tui-shadow-small`. Ночью тени нет, отделяется цветом.
- **Десктоп:**
  - **hover** — фон пункта темнее, соседние разделители скрываются;
  - **selected hover**;
  - **focus** — рамка 2 px `border/focus`; в Figma отдельного состояния нет, накладываем вручную;
  - **disabled** — прозрачность 50 %; в Figma накладываем вручную;
  - **pressed** выглядит как normal, чтобы не спорить с анимацией переключения.
- **Мобилка:**
  - iOS: нажатие на активный пункт — текст `text-primary-pressed`, на неактивный — фон `neutral-1`;
  - Android: на любом пункте — системный ripple `service/ripple`.

## Поведение
- **Динамическая ширина (auto-fit, по умолчанию)** — контейнер подстраивается под текст.
- **Фиксированная ширина (auto-fit off)** — блок фиксированной ширины, пункты делят её поровну, контент по центру, непоместившийся текст уходит в фейд.

## Разделители
- Нужны, если пунктов **больше двух**.
- Стоят по центру промежутка между пунктами.
- Не показываются у крайнего правого пункта, по краям активного пункта и рядом с пунктом под курсором.
- Опциональны: их можно выключить, чтобы снизить визуальный шум. В Figma — проп `show-separator` на нужных пунктах.

## Анимация
Фон выбранного пункта переезжает, разделители исчезают, подсветка при нажатии появляется. Параметры везде одинаковые, на десктопе и мобилке: `duration-fast`, `productive-standard`.

## Кастомизация
- **Цвета** фона группы, активного пункта и текста — любые. Состояния hover и pressed тоже продумайте.
- **Шрифты** — начертание и цвет в отдельных пунктах или состояниях. Стабильно работает только с **фиксированной** шириной, с динамической появляются артефакты анимации.

## Редполитика
- Подпись однозначно говорит, что увидит пользователь: «Все», «Входящие», «Черновики», «Товары», «Документы».
- Прилагательные или существительные, не глаголы: «Дата», а не «Указать дату»; «Период», а не «Настроить период».
- Не больше двух слов, сокращаем без потери смысла.

## Правила использования
- Для навигации по разделам или формам без перезагрузки страницы.
- **Не** для группировки разнородного контента и **не** как якорная навигация.
- Под большим заголовком: в `tui-header [large]` вшит отступ 24, под сегментом уменьшаем его до **16**.
- Под аппбаром — отступ **12**.

## Доступность
- **iOS** — шрифт растёт только до **xxxLarge**. Высота и горизонтальные отступы не меняются, иконки не увеличиваются, бейдж — по своим правилам. Непоместившийся текст уходит в фейд.
- **Android** — шрифт растёт до **140 %**.
- **Озвучка.** Это группа кнопок, фокус идёт слева направо. Формат: «Выбрано, Label, 1 из 3, кнопка». С бейджем: «Label, есть одно обновление». Подсказка: «Коснитесь дважды, чтобы выбрать».
- Пункты без текста обязательно получают своё описание (`ariaLabel`).

## API в коде
```js
h(TaigaUI.Segmented, { size: 'm', items: ['День', 'Неделя', 'Месяц', 'Год'], defaultIndex: 0, onChange: setPeriod })
h(TaigaUI.Segmented, { platform: 'mobile', autoFit: false, items: ['Дебетовые', 'Кредитные'] })
h(TaigaUI.Segmented, { size: 's', items: [{ label: 'Все' }, { label: 'Входящие', badge: 1 }, { icon: 'grid-big', ariaLabel: 'Плитка' }] })
```

| Проп | Значения |
|---|---|
| `items` | строки или `{ label, icon, iconEnd, badge, disabled, ariaLabel }` |
| `size` | `l` \| `m` \| `s`, по умолчанию `m` |
| `shape` | `square` \| `rounded` |
| `platform` | `desktop` \| `mobile` |
| `autoFit` | по умолчанию `true` |
| `separators` | по умолчанию `true` при 3+ пунктах |
| прочее | `disabled`, `label` (aria-label группы), `activeIndex`, `defaultIndex`, `onChange` |
