# Row (`tui-row`)

Горизонтальный скролл однотипных элементов: карточек, аватаров с подписью, вертикальных кнопок или любых компонентов. Источник — гайд `tui-row` (v1.0.2). Готов на всех платформах.

## Пресеты
| пресет | элемент | между элементами |
|---|---|---|
| `card-medium` 140 | `tui-card-medium` 140×140: радиус 12, отступы 12 / 12 / 10 / 12, фон `neutral-1-opaque`; аватар 56 (`accent-2` — исключение из синей иконки в нейтральном круге, по гайду), заголовок `UI M Bold`, подзаголовок `UI S` серый | 12 |
| `card-medium` 92 | 92×92: иконка 24 (`text-action`) и подпись `UI XS Bold` | 8 |
| `avatar-labelled` | ширина 72: аватар 56, подпись `UI XS` через 6 | 12 |
| `button-vertical` | `tui-button [vertical]` 90×70: радиус 12, отступы 12 сверху и снизу, 8 по бокам, иконка 24 и подпись `UI XS` через 8 — обе `text-action`, фон `component-button-vertical` | 12 |
| `custom` | любые компоненты (в Figma `tui-row [custom]`) | 12 |

## Построение
- **Высота** — по самому высокому элементу.
- **Позиционирование.** Если элементы помещаются без скролла, они стоят на месте без bounce-эффекта; выравнивание по левому краю или по центру.
- **Боковые отступы:**
  - отдельно на экране — 16, в карточке — 20;
  - `avatar-labelled`: отдельно 8, в карточке 12 — отсчёт идёт от картинки, у самого компонента внутренний отступ 8.
- **`button-vertical`:** до 3 кнопок — по центру; от 4 — слева с отступом 16.
- **Подписи `button-vertical` не обрезаются:**
  - ширина у всех кнопок в ряду одинаковая — по самой длинной подписи в одну строку: от 90 до 106 на мобилке, от 80 до 120 на десктопе. 106 — чтобы 3 кнопки помещались в 375 без скролла;
  - поля по бокам **8** (в шаблоне 12, сверху и снизу 12 остаются) — иначе «Не учитывать» на мобилке не встаёт в строку. Поля 8 и лимит 12 символов — решение команды, утверждено;
  - подпись до 12 символов с пробелом встаёт в одну строку («Не учитывать»);
  - длиннее — переносится на вторую строку между словами, без дефисов. Больше 2 строк не бывает;
  - высота у всех кнопок в ряду — по самой высокой (70 с одной строкой; с двумя — 84 на мобилке, подпись UI XS 12/14, и 86 на десктопе, UI S 13/16);
  - слово, которое не помещается даже в 106 / 120, расширяет кнопку; в консоли предупреждение.
- **`ButtonVertical` на десктопе** — `platform: 'desktop'`: от 80 × 70, поля 12 / 8, иконка → подпись 6, подпись UI S 13/16 `text-action`; в ряду между кнопками 8 (TUI Templates, `[desktop] template-button-vertical`). Скелетон — `skeleton`. Наведение и нажатие в шаблоне не показаны.
- **Иконки в одном ряду — из одного стиля.** Можно Pragmatic (`medium-pragmatic`) или Fancy (`medium`), но не вперемешку; в аватарах (`avatar-labelled`, аватар `card-medium`) — только Fancy, по гайду tui-avatar. Набор указываем явно (`medium-pragmatic/folder`, `medium/folder`): имя без набора ищется сначала в Pragmatic, потом в Fancy, и ряд может собраться из разных стилей.

## Кастомизация
- В скролл можно положить любые компоненты.
- Расстояние между элементами по умолчанию 12, его можно менять.
- Боковые отступы можно менять. Сверху и снизу можно добавить отступы, если элементы отбрасывают тень (`paddingY`).
- **На экране ряд идёт на всю ширину**: не кладём его в контейнер с боковыми отступами и не обнуляем `padding`. Поле 16 у ряда своё, скролл доходит до края экрана, иначе карточки обрезаются раньше края.

## Доступность
- **Крупный шрифт:** вложенные компоненты увеличиваются по своим правилам.
- **Озвучка:**
  - до трёх элементов — без группировки, каждый читается по своим правилам;
  - больше трёх — группируем: группа с названием и трейтом «Список» / «Элемент регулировки», элементы листаются одним свайпом и читаются как «Title, Subtitle, 2 из 4».
- В коде больше трёх элементов — `role="list"` с `aria-label` и `listitem` с позицией.

## API в коде
```js
h(TaigaUI.Row, { preset: 'card-medium', items: [{ title: 'Кэшбэк', subtitle: '1\u00a0240\u00a0₽', icon: 'medium/star', onClick: open }], label: 'Сервисы' })
h(TaigaUI.Row, { preset: 'avatar-labelled', items: [{ label: 'Анна', initials: 'А' }] })
h(TaigaUI.Row, { preset: 'button-vertical', items: [{ label: 'Пополнить', icon: 'medium-pragmatic/plus', onClick: topUp }] })
h(TaigaUI.Row, { gap: 8 }, chip1, chip2, chip3)          // custom
```
Пропсы `Row`:
- состав: `preset` (card-medium · avatar-labelled · button-vertical · custom), `items` или `children`, `cardSize` (140 · 92);
- отступы: `inCard` (отступы 20 / 12), `padding`, `paddingY`, `gap`;
- выравнивание и озвучка: `align` (left · center), `label` (название группы).

Элементы можно использовать и отдельно:
- `TaigaUI.CardMedium`: `size`, `title`, `subtitle`, `icon`, `onClick`, `href`;
- `TaigaUI.AvatarLabelled`: `label`, `secondLine`, `size` (small · medium · large), `icon`, `image`, `initials`, `avatarTone`, `fade` — подробно в карточке Avatar;
- `TaigaUI.ButtonVertical`: `label`, `icon`, `onClick`.

Скелетоны и другие режимы `tui-card-medium` (текст сверху, без фона) в коде не сделаны.
