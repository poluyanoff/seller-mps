# Timeline и TimelineItem (`tui-timeline-item`)

Вертикальный таймлайн: каждый пункт — одно событие с маркером на оси слева и контентом справа. Контент бывает простым (только заголовок) и расширенным (статус, время, описание, вложенный контент в слоте). По Figma «TimelineItem».

`TimelineItem` — один пункт. `Timeline` — список пунктов одного размера: задает размер и маркер всем пунктам, у последнего убирает линию вниз.

## Когда использовать
Когда важно показать порядок событий во времени и быстро дать контекст: что произошло, когда и что важно в каждом событии.
- История изменений, audit log: создано, обновлено, удалено, кем и когда.
- Журнал действий пользователя или системы: события процесса, статусы, ошибки.
- Хронология по сущности — заказ, тикет, документ: последовательность действий и решений.
- Этапы процесса, где каждое событие — отдельный шаг со статусом или деталями.
- События с вложенными деталями — карточка, метрики, список параметров в слоте.

## Размеры
| Размер | Где | Маркер → контент | Снизу | Слот | Заголовок | Время и описание | Статус |
|---|---|---|---|---|---|---|---|
| **M** (по умолчанию) | основная страница: главные экраны, детальные страницы объекта | 12 | 16 | через 12 | `body-m-bold` 15/24 | `body-s` 13/20 | Badge medium 20 |
| **S** | Drawer и ResizablePanel; плотные журналы и логи, сайдпанели, таймлайн как второстепенный контент | 12 | 16 | через 8 | `body-s-bold` 13/20 | `body-xs` 12/19 | Badge small 16 |
| **XS** | IDE-системы: модули, ResizablePanel с отступами Thin | 8 | 8 | через 8 | `body-s-bold` 13/20 | `body-xs` 12/19 | Badge small 16 |

- Максимальная ширина пункта — **890**. Высота — по содержимому.
- В одном таймлайне — один размер.

## Построение
Маркер → контент: строка заголовка (заголовок → 4 → статус) → время → описание; справа через 32 — действие; ниже — слот.

- **Маркер.** M — `Avatar` 40 (`small`), S и XS — 24 (`xx-small`); в Figma это avatar M и XS. Тон — по умолчанию (`accent-icon`): иконка `text-action` на `background-neutral-1`. Можно инициалы или фото — передайте пропсы `Avatar` в `avatar`. Вместо аватара — точка 8 (`marker: 'dot'`) с коннектором сверху.
- **Линия** — 1 px `border-normal` от маркера вниз до следующего пункта, через 4 от маркера. Колонка маркера: у M снизу 4, у S и XS сверху и снизу 2. У последнего пункта линии нет.
- **Заголовок** — одна строка до 680, длинный обрезается многоточием. Необязателен.
- **Статус** — `Badge` с точкой статуса (`*-pale`), всегда сразу после заголовка, в той же строке. Необязателен.
- **Время** — под строкой заголовка, `text-secondary`. Дата и время, одна строка без переносов. Необязательно.
- **Описание** — под временем: текст и ссылки (`Link inline`), до 1000 символов. Блок растет по высоте и увеличивает пункт. Необязательно.
- **Действие** — кнопка в правом верхнем углу: `Button` XS `secondary`, только иконка (по умолчанию карандаш). Необязательно.
- **Слот** (`children`) — вложенный контент под событием: карточка, метрики, список параметров. Высота не ограничена. Необязателен.
- У S и XS текст опущен на 3 — строка 20 встает по центру аватара 24.

## Тексты
- В заголовке — коротко, суть события. Подробности — в описании.
  - Нельзя: «Это событие говорит о том, что произошла ошибка авторизации, в которой были проблемы» — заголовок обрезается, смысл теряется.
  - Можно: заголовок «Произошла ошибка», статус «Ошибка», детали и ссылка на тикет — в описании.
- Если пункт состоит только из заголовка, заголовок обязателен.
- Без точек в конце, без «ё».

## Решения команды и отличия от Figma
- **Время и описание в S и XS — `body-xs` 12/19.** В Figma — старый Body XS 11/16, он в Legacy и в новых макетах не используется. Пункт без слота стал выше на 6: 77 вместо 71 (XS — 69 вместо 63).
- **Маркер — `Avatar` по умолчанию** (`accent-icon`). В Figma — серый круг `neutral-4` с белой иконкой, такого тона у `Avatar` нет.
- **Пустой кружок рядом со статусом** (Placeholder-icon 20 / 16) не переносим: назначение не описано. Вернем, когда появится сценарий.
- **Точка — `background-neutral-4`.** В Figma `neutral-4-on-light`: днем значения совпадают, но ночью он не меняется и точка пропадает на темном фоне.
- **Коннектор над точкой поднят на 4**, чтобы линия от предыдущего пункта не рвалась. У первого пункта коннектора нет.
- **У последнего пункта нет линии вниз.** Лента подгружается дальше — `continued`, линия остается.

## Пробелы
- Цвет линии в Figma не подписан, взят `border-normal`. Подтвердить.
- Не описано, когда ставить точку, а когда аватар. Колонка точки — 8, аватара — 40: если их смешать, линия ломается. Не смешивайте в одном таймлайне.
- Нет мобильной версии — только десктоп.
- Нет скелетона, пустого таймлайна, наведения и нажатия на пункт.

## API
```js
h(TaigaUI.Timeline, { size: 's', label: 'История документа', items: [
  { id: 1, icon: 'check-circle', title: 'Документ подписан', status: { label: 'Подписан', appearance: 'positive-pale' },
    time: '24.10.2026 14:37', description: 'Подписал Иван Петров', action: { label: 'Изменить', onClick: edit } },
  { id: 2, avatar: { name: 'Анна Белова' }, title: 'Отправлен', status: { label: 'Ждет подписи', appearance: 'warning-pale' }, time: '24.10.2026 11:02' },
  { id: 3, icon: 'doc-blank', title: 'Документ создан', status: 'Черновик', time: '23.10.2026 18:15',
    children: h(TaigaUI.Cell, { size: 's', inset: 'none', avatar: 'doc-blank', title: 'Счет-фактура №128.pdf', description: '124 КБ' }) }
] })

// Детьми
h(TaigaUI.Timeline, { marker: 'dot' },
  h(TaigaUI.TimelineItem, { title: 'Запрос отправлен', time: '22.10.2026 12:30' }),
  h(TaigaUI.TimelineItem, { title: 'Ждем ответа банка', time: '22.10.2026 12:31' }))
```
- **`Timeline`:** `size` (m · s · xs), `marker` (avatar · dot) — по умолчанию для всех пунктов, `items` или `TimelineItem` детьми, `continued`, `label` (подпись списка для озвучки). Список — `ol`, пункты — `li`.
- **`TimelineItem`:** `size`, `marker`, `icon` (имя без набора — Fancy), `avatar` (пропсы `Avatar` без `size` или элемент), `title`, `status` (строка — `neutral-pale`, или `{ label, appearance, dot }`, или элемент), `time`, `description`, `action` (`{ label, icon, onClick }` или элемент), `children` — слот. Без `icon` и `avatar` маркер — точка.
