# TabBar (`tui-tabbar`)

Навигационная панель корневых разделов приложения, по гайду tui-tabbar v1.3.0.
- **В нативе** — системные компоненты: `UITabBar` на iOS (жидкое стекло, системные эффекты), системная панель на Android (риппл).
- **В вебе (PWA, мобильный веб)** — `tui-tabbar`, это и есть компонент ДС.
- **Нажатие** в PWA и WebView без анимаций.

## iOS — стеклянная капсула
Стекло имитируем CSS: фон `ios-liquid-glass` (день `#ffffffb3`, ночь `#ffffff1a`), размытие 4 + saturate 1.3, внутреннее свечение 12 и «фаска» градиентом по краю. Фаска на дневной теме видна только на реальном айфоне.
- **Капсула** — высота **62**, паддинг **4**, радиус 999, тень `0 8 32 rgba(0,0,0,.1)`.
- **Отступы** — по бокам **20**, снизу `max(env(safe-area-inset-bottom), 20px)`, и в standalone, и в браузере (над панелью Safari).
- **Ширина вкладок:**
  - 2–3 вкладки — фиксированные **94**, капсула по центру;
  - 4 и больше — капсула растянута по ширине экрана.
- **Пункт** 54:
  - сверху 8, иконка Fancy 24, через 3 подпись SF Pro 10/12, снизу 7;
  - подпись упирается в паддинги 6 и обрезается многоточием.
- **Цвета** — невыбранный `text-primary` (подпись Medium), выбранный `text-action` (подпись Semibold).
- **Подсветка активного** — капсула `background-neutral-2`. У крайних пунктов она равна ширине пункта, у внутренних шире на 4 с каждой стороны (если вкладок больше 3).
- **Фейд под панелью** — 150, цвет `background-base` с маской-градиентом. В отличие от натива, не перекрашивается под контент.

## Android
Лейаут один для натива и WebView.
- Панель во всю ширину, вкладки растянуты. Фон `background-base`, тень сверху.
- **Пункт** 56: сверху 8, иконка 24, через 2 подпись Roboto 12/14, снизу 8.
- **Снизу** — `env(safe-area-inset-bottom)`.
- **Цвета** — невыбранный `text-secondary`, выбранный `text-action`.
- **Длинная подпись** в вебе обрезается многоточием.

## Общее
- **Бейджи** — через `tui-badged-content`: точка или число. iOS — до 99, Android — «99+».
- **Кастомизация** — только цвет активного пункта (`activeColor`).
- **Набор мобильного банка** (по умолчанию) — Главная · Платежи · Город · Чат · Ещё. Иконки Fancy: `card-frontside` (активная — `logo-t-shield`), `coin-compact`, `logo-city`, `chat`, `more`. В Figma есть пресет для неавторизованного пользователя с вкладкой «Войти».
- **Набор Т-Бизнеса** — `preset: 'business'`: Главная · Платежи · Сервисы · Чат · Еще. Иконки Fancy: `card-frontside` (активная — та же карта), `coin-compact`, `grid`, `chat`, `more`. По скриншоту приложения (30.10.2026). Экраны Т-Бизнеса собираем с этим набором, свой не придумываем.
- **Где ставить:** на экранах, где таб-бар виден в приложении: корневые разделы и экраны вроде счета (решение команды, 29.10.2026). В коде продукта внутри WebView таб-бара нет: сценарии в WebView изолированы (раздел «Мобильный веб: WebView»). В прототипе его показываем, чтобы экран выглядел как в приложении (`PageLayout/README.md`).
- `system="ios18"` — старая плоская панель iOS 18 (50 + 34). Только для старых макетов.

```js
h(TaigaUI.TabBar, { value: tab, onChange: setTab })                       // iOS, набор МБ
h(TaigaUI.TabBar, { preset: 'business', value: tab, onChange: setTab })  // Т-Бизнес
h(TaigaUI.TabBar, { system: 'android', items: [{ label: 'Главная', icon: 'medium/card-frontside' }, { label: 'Чат', icon: 'medium/chat', badge: 2 }] })
h(TaigaUI.TabBar, { items: ['Главная', 'Услуги'].map(l => ({ label: l, icon: 'medium/more' })), activeColor: '--tui-text-positive' })
```
Пропсы:
- `system` — `ios` (по умолчанию), `android` или `ios18`;
- `preset` — `bank` (по умолчанию) или `business`; `items` важнее;
- `items` — пункты `{ label, icon, iconActive?, value?, href?, badge? }`;
- `value`, `defaultValue`, `onChange(value, item)` — выбранный пункт;
- `activeColor` — цвет активного пункта;
- `fade` — `false` убирает фейд;
- `homeIndicator`, `sticky`, `label`.
