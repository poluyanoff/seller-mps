# InputCopy

Поле ввода с отдельной кнопкой копирования текущего значения. Собрано из `Input` / `InputChip` и `ButtonCopy`. Только Desktop.

```js
h(TaigaUI.InputCopy, {
  label: 'Номер счета', size: 'l',
  defaultValue: '40702810900001234567'
})
h(TaigaUI.InputCopy, {
  multiple: true, label: 'Получатели',
  defaultValue: ['Анна', 'Борис']
})
```

## Поведение

- Ввод и изменение значения работают как в исходном поле. `value` / `onChange` — управляемый режим, `defaultValue` — внутреннее состояние.
- Кнопка справа копирует актуальное значение. У обычного поля перед копированием выделяется вся строка. Клик по полю сам по себе не копирует.
- Пустое поле остаётся доступным для ввода; кнопка копирования отключена. `disabled` отключает всё поле; в обычном `readOnly` копирование доступно.
- У `multiple` копируются полные подписи чипов через `, `, даже если на экране они обрезаны. Незавершённый текст ввода не входит в список. Для `items` берутся подписи выбранных вариантов; `stringify(item)` задаёт свой текст.
- `copyProcessor(text)` преобразует получившуюся строку перед записью в буфер.
- Успех — тост «Скопировано» (решение команды, 30.10.2026); `toast: false` — подтверждение у кнопки на 3 секунды. Ошибка не выдаётся за успех и вызывает `onCopyError`.
- Копирование доступно по Tab и Enter / пробелу. Подсказки, темы и озвучка результата — из `ButtonCopy`.

## API

Общие параметры: `copyProcessor`, `copyLabel` (доступное имя кнопки, по умолчанию «Скопировать»), `onCopy(value, index)`, `onCopyError(error, value, index)`.

При `multiple: false` доступны пропсы [Input](../Input/README.md), кроме `platform`. При `multiple: true` — пропсы [InputChip](../InputChip/README.md) и `stringify`. Значения — строки или числа; строки с ведущими нулями не превращайте в числа.

Очистка обычного поля по умолчанию выключена (`cleaner: false`), её можно включить. Существующий `accessory` сохраняется рядом с копированием. В `InputChip` добавлен слот `accessory` для такой композиции.

Источники: [официальный пример InputCopy](https://taiga-ui.tcsbank.ru/components/copy#input-copy) и связанная с ним директива `tuiCopy`. В Angular пример — директива внутри Textfield; здесь тот же сценарий оформлен React-компонентом.
