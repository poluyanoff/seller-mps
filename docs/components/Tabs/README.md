# Tabs (`tui-tabs`)

Вкладки по гайду tui-tabs v1.0.0. Быстрая навигация между сгруппированным контентом: разделами или разными формами без перезагрузки страницы.

## Когда использовать
- Переключение между однородными разделами («Все», «Входящие», «Исходящие»).
- **Не используем:** для группировки разнородного контента; как фильтр (для этого фильтры и чипы); как якорную навигацию.
- **Не больше 6 вкладок** — большое количество сложно воспринимать.
- **На мобилке** лучше чипы (`ChipGroup`) или `Segmented`. Если вкладки всё же нужны и не помещаются — горизонтальный скролл; активная вкладка всегда видна (в том числе после обновления страницы).

## Размеры
| | Medium (клиентские интерфейсы) | Small (служебные и мобильные версии) |
|---|---|---|
| Высота вкладки | 56 | 44 |
| Текст | `body-m` 15/24 | `body-s` 13/20 |
| Между вкладками | 24 | 16 |
| Вертикальная вкладка | 44, отступы 10 / 20 / 10 / 0 | 36, отступы 8 / 20 / 8 / 0 |

Кликабелен весь контейнер вкладки.

## Стили и состояния
| Состояние | Вид |
|---|---|
| Normal | текст `text-secondary` |
| Hover | текст `text-primary`, линия 2 `border-normal` |
| Selected | текст `text-primary`, линия 2: **default** — `background-accent-1` (жёлтая), **clear** — `background-accent-opposite-pressed` |
| Disabled | прозрачность 56 % |
| Focus | рамка фокуса с клавиатуры |

- Общая линия под вкладками — 1 `border-normal` (`underline={false}` — без неё).
- **Жёлтый стиль** (`appearance: 'default'`) лучше на белом фоне: на плохих мониторах активную вкладку видно хуже. Иначе — `clear`.
- **Анимация:** смена состояний — 150ms, `productive-standard`; фон одинаковый на десктопе и мобилке.

## Иконки и бейдж
- **Слева** (`icon`) — иллюстрирует текст или привлекает внимание. Если иконки слева — **во всех вкладках**. Иконка 16 в контейнере 20, до текста 8.
- **Справа** (`iconRight`) — служебные неинтерактивные, например индикатор раскрытия, если у вкладки есть вложенные сущности.
- **Закрытие** (`onClose`) — интерактивная иконка справа, скрывает вкладку. Какую вкладку выбрать после закрытия активной, решает продукт.
- **Бейдж** (`badge`) — количество вложенных элементов, обновления, уведомления: `Badge` L `dark-text`, через 4. Где и что показывать — решает продукт (на одной вкладке общее количество, на другой только новые).
- Иконки и бейдж можно комбинировать.

## Вертикальные
`orientation: 'vertical'` — когда вкладок много: навигация по разделам или якорям внутри статьи. Линия справа (`position: 'right'` — слева, тогда отступ 20 с другой стороны).

## Редполитика
- Название однозначно говорит, что пользователь увидит после нажатия.
- Прилагательные или существительные: «Все», «Входящие», «Черновики», «Товары», «Документы».
- Сокращаем без потери смысла — желательно не больше 2 слов: «Вход» / «Регистрация», а не «Войти» / «Зарегистрироваться».

## API
```js
h(TaigaUI.Tabs, { items: ['Все счета', 'Входящие', 'Исходящие', 'Черновики'], value, onChange })
h(TaigaUI.Tabs, { size: 's', appearance: 'clear', items: [{ label: 'Все', badge: 235 }, 'Исходящие', { label: 'Еще', iconRight: 'small-pragmatic/chevron-down' }] })
h(TaigaUI.Tabs, { items: [{ label: 'Карты', icon: 'small-pragmatic/card' }, { label: 'Документы', icon: 'small-pragmatic/doc' }] })
h(TaigaUI.Tabs, { orientation: 'vertical', items: ['Профиль', 'Безопасность', 'Уведомления'] })
```
Пропсы: `items` (строки или `{ label, value, icon, iconRight, badge, badgeAppearance, disabled, onClose, panelId }`), `value` / `defaultValue` / `onChange(value, item)`, `size` (m · s), `appearance` (default · clear), `underline`, `orientation` (horizontal · vertical), `position` (left · right), `end` — свои элементы справа от вкладок, `label`, `id`.

Клавиатура: ← / → (у вертикальных ↑ / ↓), Home, End. Роли `tablist` / `tab`; контенту вкладки задайте `role="tabpanel"` и `id`, указанный в `panelId`.

## Пробелы
- Вид состояния Focus в гайде не показан: рамка 2 `border-focus`.
- Отступы бейджа и правой иконки у Small взяты такими же, как у Medium (4).
- Вкладки третьего уровня в `PageHeader` — отдельный паттерн шапки ЛК из шаблонов, не `Tabs`.
