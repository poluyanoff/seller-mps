# Button (`tui-button`)

Кнопка запускает действие: положить в корзину, заказать карту, дать согласие, подтвердить. По гайду `tui-button` (страницы «Правила», «Редполитика», «Дизайн»).

**Кнопка — не ссылка.** По кнопке почти никогда не уходят просто на другую страницу; если переход — он связан с действием. Для «Все», «Показать все», «Подробности» — `tui-button [link]`.

**Сплит-кнопка и группа кнопок** — `Group` (tui-group): отступ 2, скругления только на внешних углах; у кнопок с обводкой — `collapsed`.

## Стили
| Стиль | Когда |
|---|---|
| `primary` (жёлтая, бывш. primary-tinkoff) | главное действие; **на странице / экране — одна** |
| `accent` (синяя, бывш. primary-accent) | альтернативный акцент; тоже одна на экране |
| `primary-grayscale` (бывш. primary-opposite) | монохромная, инвертируется с темой |
| `primary-grayscale-on-light` / `-on-dark` | на светлом / тёмном цветном фоне, тему не меняет |
| `primary-destructive` | главное деструктивное действие |
| `secondary` · `secondary-grayscale` · `secondary-destructive` | второстепенные действия; `-on-light` / `-on-dark` — на цветных фонах |
| `flat` · `flat-grayscale` · `flat-destructive` | текстовые — рядом с primary; в остальных случаях лучше `[link]` |
| `outline` · `outline-grayscale` · `outline-destructive` (десктоп) | менее контрастная, чем secondary; для групп кнопок |
| `glass` · `glass-on-light` · `glass-on-dark` | стекло с блюром поверх пёстрых фонов и фото |
| `floating` | с тенью поверх карт и неоднородных фонов, без акцента |

Цвета кастомизируем только в крайнем случае — сначала `~tui-design-ask`. Старые имена (`primary-tinkoff`, `primary-accent`, `primary-opposite`, `primary-on-light`, `secondary-on-dark`…) в коде приводятся к новым.

## Размеры
**Десктоп** — 4 размера, высота фиксирована:
| | высота | радиус | отступы | текст | иконка |
|---|---|---|---|---|---|
| L | 56 | 12 | 16 + 4 у текста | `ui-m` 15/20 | 24 |
| M | 44 | 8 | 10 + 6 у текста | `ui-m` 15/20 | 24 |
| S | 32 | 8 | 8 / 4 + 2 у текста | `ui-s` 13/16 | 16 |
| XS | 24 | 4 | 4 + 2 у текста | `ui-s` 13/16 | 16 |

**Мобилка** — 3 размера, у каждого минимальная высота, ширина тянется:
| | высота | радиус | отступы | текст iOS / Android | где |
|---|---|---|---|---|---|
| L | 56 | 16 | 16 + 8 у текста | `ios-ui-l` 17/20 / Android `ui-l` 16/19 | основные действия на формах и экранах; **во всю ширину**; меньше ставить нельзя |
| M | 44 | 12 | 10 + 8 у текста | `ios-ui-m` 15/18 / Android `ui-m` 14/16 | в карточках и группах; во всю ширину или по контенту |
| S | 30 | круглая | 7 + 4 у текста | `ios-ui-s-bold` 13 / UI S Bold | в ячейках, карточках, списках; по контенту |

## Состояния
- **Hover** (только десктоп) — подложка на токен `-hover`; у flat — `neutral-1`, у outline — обводка `border-hover`.
- **Pressed**: десктоп — `-hover`; **iOS** — токены `-pressed`, мгновенно, без анимации; **Android** — системный ripple (`service/ripple-*`) под текстом.
- **Focus** — обводка 2 px `border/focus` (`border/focus-on-dark` где не видно).
- **Loading** — только после нажатия: внутри лоадер, **текст не меняем** («Загружаем…» — нельзя), размер кнопки сохраняется.
- **Disabled** — прозрачность 50 %, без фокуса, тултипов и выделения. **Почти не используем:** в формах кнопка активна, по нажатию валидируем поля или показываем тост. Допустимо, только если весь блок грузится.

## Правила
- **Одна главная кнопка на экране.** Три разных стиля рядом — плохо.
- **Порядок:** в формах сабмит слева; в десктопных попапах подтверждение справа; в мобильных попапах кнопки друг под другом, основная снизу.
- **Расположение:** важные действия — на видном месте с воздухом вокруг. На мобилке значимые кнопки — во всю ширину друг под другом; рядом — если текст позволяет.
- **Иконка + текст** помогает найти кнопку; в панели с множеством кнопок иконки оставляем только у важных.
- **Кнопка-иконка** — для второстепенных действий или меню, когда места мало; иконки понимают не все — используем осторожно, с подписью для озвучки. Можно сделать круглой (`rounded`; мобильная S уже круглая).
- **Два лейбла** (`secondLabel`, например сумма) — только L и M; приоритет у правого, левый уходит в фейд; между лейблами минимум 8; второй можно сделать жирным.
- **Длинный текст:** на десктопе обрезается, на мобилке фейдится; не сокращаем слова и не переносим на две строки.
- **Крупный шрифт:** высота растёт под текст, минимальная сохраняется; иконки ×1.25 только в AX1.

## Редполитика
- Кнопка — реплика пользователя в диалоге: глаголом, с точным ожиданием результата: «Открыть счёт», «Оформить доставку».
- Осторожно с пугающими действиями: не «Взять кредит», а «Узнать лимит».
- Согласие — «Понятно» (не «Хорошо»); «я всё, дальше» после выбора или заполнения — «Готово»; онбординг — «Дальше», осознанный флоу с выбором — «Продолжить»; можно направление: «На главную».
- Коротко: «Забронировать место», а не «Забронировать рабочее место в офисе»; «К оплате», «Назад» вместо «Перейти к оплате», «Вернуться назад».
- Общие правила текстов и коды — раздел «Тексты интерфейса» (`copy.md`): группа BT, рядом с заголовком — HD2.

## API в коде
```js
h(TaigaUI.Button, { platform: 'mobile', size: 'l' }, 'Дальше')            // мобильная L — во всю ширину по умолчанию
h(TaigaUI.Button, { appearance: 'secondary', size: 'm', icon: 'star' }, 'В избранное')
h(TaigaUI.Button, { loading: true }, 'Оплатить')
h(TaigaUI.Button, { block: true, secondLabel: '12\u00a0500\u00a0₽' }, 'Оплатить')
h(TaigaUI.Button, { appearance: 'secondary', icon: 'plus', rounded: true, title: 'Добавить' })
```
Пропсы: `appearance`, `size` (l · m · s · xs), `platform`, `block` (мобильная L — по умолчанию true), `icon`, `iconRight`, `loading`, `disabled`, `rounded`, `secondLabel`, `secondLabelBold`, `title` / `ariaLabel` (для кнопки-иконки), `onClick`, `type`.

**Иконки в кнопке — Pragmatic по размеру кнопки:** S и XS — `small-pragmatic` (16), M и L — `medium-pragmatic` (24). Набор можно не указывать (`icon: 'plus'`); если указан другой (`small-pragmatic/…` в M, Fancy `medium/…`), кнопка сама возьмет нужный, когда такая иконка в нем есть. `service/…` и `fixed-color/…` не меняются.

**`appearance` по умолчанию — `primary` (жёлтая).** Кнопка без `appearance` — главная, поэтому у остальных кнопок экрана стиль задавайте явно. Других стилей, кроме таблицы «Стили», нет: незнакомое имя не сработает.
