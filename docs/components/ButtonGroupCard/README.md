# ButtonGroupCard (`tui-button-group-card`)

Компактный блок с быстрыми действиями: 2–3 кнопки «иконка + подпись» или одна кнопка в строку. Например, «Пополнить», «Перевести», «Оплатить» под панелью счёта (`Panel`). Построение одинаково на десктопе и мобилке. Источник — Figma «tui-button-group-card», гайд v1.1.2. В шапке гайда: «Компонент разработан не везде».

## Стили (`appearance`)
| `appearance` | Фон | Тень |
|---|---|---|
| `elevated` (по умолчанию) | `background-elevation-1` | `shadow-medium` |
| `flat` | `background-neutral-1` | нет |

## Построение
- **2–3 кнопки:** высота 88, радиус 24. Кнопки делят ширину поровну. Внутри кнопки поля 18 сверху и снизу, 4 по бокам. Иконка 28 → 8 → подпись `ui-s-bold`, цвет `text-action`, по центру.
- **2 кнопки:** внешние поля 28 — входят в область нажатия.
- **1 кнопка:** высота 56, радиус 16, поля 16, иконка 28 → 8 → подпись `ui-l` (Body L) в одну строку, по центру.
- **Мобилка:** у карточки свои поля 16 (карточка 343 на экране 375) — не оборачивайте её в отступы. **Десктоп:** на всю ширину контейнера.
- **Иконки** — только Fancy (`tui-ic-medium`), 28. Передавайте имя без набора (`'plus-circle'`, `'cards'`) — компонент берёт его из Fancy; Pragmatic-имя тоже заменяется на Fancy, если такая иконка есть, иначе в консоли предупреждение. Цвет по умолчанию — `text-action`.
- **Длинный текст:** подписи переносятся, карточка растёт по высоте с теми же отступами. Пишем не больше двух строк короткими словами, слова не рвём. Длинный текст у одной кнопки в дизайне не применяем.
- **Количество:** лучше не больше 3 действий. В описании компонента — от 1 до 3; 4 кнопки с разорванными словами — «Неправильно».

## Состояния
- **Область нажатия** одинаковая для обоих стилей: вся ячейка кнопки на всю высоту; у одной кнопки — вся карточка.
- **Десктоп:** наведение — `background-neutral-1-hover`, нажатие — `background-neutral-1-pressed` на ячейке. Фокус — по кнопкам слева направо, рамка `border-focus` по ячейке.
- **Мобилка (WebView):** нажатие — подложка ячейки `background-neutral-1`. Риппла в WebView нет (раздел «WebView»), поэтому на Android так же. Одна кнопка `elevated` при нажатии сжимается до 0.95.
- **Тёмный фон** (`onDark`): наведение и нажатие — `background-neutral-1-on-dark-hover` / `-pressed`, на мобилке — `background-neutral-1-on-dark`.

## Анимация смены контента (`swapKey`)
Например, на экране карты при свайпе между картами блок остаётся на месте и меняет контент. Смените `swapKey` вместе с `items`:
1. подписи и иконки гаснут — `productive-exit`;
2. меняются высота (88 ↔ 56), радиус (24 ↔ 16) и фон — `productive-standard`;
3. новые подписи и иконки появляются — `productive-standard`.

Весь цикл — `duration-moderate`, по трети на шаг. Режим «следования за пальцем» не реализован (см. «Пробелы»).

## Кастомизация
- Фон — `background` (токен, цвет или градиент); тень — через `style`.
- Цвет подписей — `color`, иконок — `iconColor` (могут различаться).
- Бейдж на иконке — `badge` у кнопки: 16 в правом нижнем углу иконки, цвет `badgeColor` (например, `status-warning`).
- Цвета интерактивных состояний для тёмного фона — `onDark`.

## Доступность
- У каждой кнопки своя озвучка: подпись, роль «Кнопка». Свою — `ariaLabel`. Подпись группы — `label`.
- Крупный шрифт (AX1 на iOS, 150 % на Android): 2–3 кнопки перестраиваются в вертикальный список `tui-button-group` с выравниванием по левому краю, одна кнопка остаётся в строку. В WebView крупный шрифт пока не поддерживается (раздел «Типографика»), список включается вручную — `vertical: true`: строки 44, поля 16, иконка → подпись 8, контейнер 8 сверху и снизу.

## API
```js
h(TaigaUI.ButtonGroupCard, {
  platform: 'mobile',
  appearance: 'elevated',
  items: [
    { label: 'Пополнить', icon: 'plus-circle', onClick: topUp },          // Fancy
    { label: 'Перевести', icon: 'arrow-right', onClick: transfer },
    { label: 'Оплатить', icon: 'cards', badge: 'lock', badgeColor: 'status-warning' },
  ],
})
```
Пропсы — `ButtonGroupCardProps` в `index.d.ts`.

## Пробелы
- **Противоречия гайда:**
  - число кнопок — «от 1 до 3» в описании и «не ограничиваем» в корнер-кейсах;
  - шрифт Android — в таблице стилей SF Pro, в «Доступности» Roboto. Взята типографика Android (`android-ui-s-bold`, `android-ui-l`), как во всей ДС;
  - вертикальный режим — «только для нативных платформ» в «Построении» и «применимо к мобильному вебу» в «Доступности»;
  - у строки вертикального списка справа в слоях 8, на аннотации 16. Взято 16.
- **Не видно в материалах:** disabled, loading, skeleton, Night-значения, алгоритм подсветки iOS (взята `background-neutral-1`), длительность и кривая hover, pressed и scale (взяты `duration-fast`, `productive-standard`), параметры фокус-рамки, вырез иконки под бейджем (в компоненте нет), отступ карточки от соседних блоков.
- **Режим «следования за пальцем»** анимации (прогресс по свайпу) не реализован, есть только линейный по `swapKey`.
- **Наведение на десктопе:** в макете 8 % и 10 %, токены `neutral-1-hover` / `-pressed` — 9 % и 11 %.
