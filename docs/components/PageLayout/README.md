# PageLayout, PageFooter (`template-ib-layout`, `template-ib-footer`)

Каркас страницы личного кабинета: шапка → контент в одну или две колонки → футер. Источник — Figma TUI Templates, страница «Интернет-банк / ЛК»: `[desktop] template-ib-layout`, `[mobile] template-ib-layout`, `[desktop] template-ib-footer`.

**Страницу ЛК собираем на `PageLayout`, сетку руками не верстаем.** Колонки, отступы, шапка и футер встают на свои места, контент остаётся на продукте.

## Десктоп (1360)
- **Шапка** — `PageHeader` (264), по умолчанию `size="l"`. Пропсы шапки — в `header`.
- **Контент** — 1104 по центру, поля 128. Две колонки: узкая **336** и широкая **672**, между ними **96**. Внутри колонки блоки через **32**, после колонок **32**.
  - `layout="default"` — узкая слева, широкая справа;
  - `layout="reversed"` — широкая слева, узкая справа;
  - `layout="single"` — одна колонка 1104 (статусные страницы, `template-ib-status-block`).
- **Уровень** (`level`): `root` — страница первого уровня; `nested` — вложенная, в шапке «‹ Назад».
- **Что обычно в колонках** (по шаблону): в широкой сверху поиск на всю ширину, ниже `CardLarge` elevated; в узкой — `CardLarge` со списком ячеек L и кнопкой secondary во всю ширину, промо-карточка.
- **Футер по умолчанию не показываем** (решение команды). Нужен — `footer: true`, пропсы `PageFooter` или свой элемент.
- **Футер** — `PageFooter`, 88 от контента, высота 348:
  - полоса на `background-base` (76): логотип слева, справа телефон Heading 5 `text-primary` и подпись 11/16 `text-secondary` (`legacy-body-2xs`);
  - блок на `background-base-alt`: ссылки 13/20 `text-action` через 24, текст про cookie и копирайт 13/20 `text-tertiary`.
- **Кнопку чата по умолчанию не показываем** (решение команды). Нужна — `chat: true` или обработчик.
- **Кнопка чата** (`chat`) — круг 56 `background-accent-1`, иконка Fancy `medium/chat` 24 цветом `text-primary-on-accent-1`, в 20 от правого и нижнего края страницы. `chatFixed` — к краю окна, а не страницы.
- Фон страницы — `background-base`.

## Мобилка (375)
- `NavigationBar` с крупным заголовком (132) → поиск (`search`, `SearchBar appearance="inline"`) через **20** → стопка контента через **20**, поля **16** → `TabBar` снизу.
- Фон экрана и шапки — `background-base` (у `NavigationBar` лейаут ставит `background: 'base'`).
- **В WebView** таб-бара нет и статус-бар рисует система: `tabBar` не передаём, в коде продукта в `header` — `statusBar: false`. В прототипах и превью статус-бар и таб-бар показываем (решение команды, 29.10.2026): ДС — для дизайнеров и продактов, экран должен выглядеть как в приложении вживую. Таб-бар — на экранах, где он виден в приложении, в том числе на экране счета.
- **Поля 16 — один раз.** Стопка даёт поля 16 карточкам и полям ввода. Компоненты от края до края со своими полями 16 — отдельно стоящая `Cell`, `Header` с `inset`, `FloatingContainer`, `Row` — компенсируют поля стопки сами (через `--tui-screen-inset`, в любой вложенности), поэтому тоже встают в 16 от края. Своих обёрток с боковым `padding` не добавляем: получится 32. Внутри карточки, шторки, диалога и выпадашки компенсации нет — там свои правила. Двойные поля ловит `TaigaUI.check()` (`inset`).
- **Кнопки внизу экрана.** `FloatingContainer` кладём последним ребёнком `PageLayout`, без обёртки: при коротком контенте он прижимается к низу экрана, при длинном — прилипает при скролле. Экран не ниже вьюпорта (`100dvh`); внутри рамки со своим скроллом (превью, макет) — высотой рамки, `PageLayout` для этого — прямой ребёнок рамки фиксированной высоты.

## API
```js
h(TaigaUI.PageLayout, {
  header: { brand: 'bank', title: 'Главная', activeSection: 'Главная', user: { name: 'Константин' } },
  layout: 'default',            // default · reversed · single
  aside: h(AccountsCard),        // узкая колонка 336
  main: [h(Search), h(OperationsCard)]    // широкая колонка 672
})
h(TaigaUI.PageLayout, { layout: 'single', level: 'nested', header: { title: 'Заявка отправлена', titleAlign: 'center' } }, h(TaigaUI.BlockStatus, { … }))
h(TaigaUI.PageLayout, { platform: 'mobile', header: { title: 'Главная' }, search: h(TaigaUI.SearchBar, { appearance: 'inline' }), tabBar: true }, cards)
```
| Проп | Значения |
|---|---|
| `platform` | `desktop` (по умолчанию) · `mobile` |
| `header` | пропсы `PageHeader` (десктоп) или `NavigationBar` (мобилка), свой элемент или `false` |
| `layout` | `default` · `reversed` · `single` |
| `level` | `root` (по умолчанию) · `nested` — «Назад» в шапке |
| `aside`, `main` | узкая и широкая колонки; `children` — для `single` и мобилки |
| `footer` | `false` (по умолчанию) · `true` · пропсы `PageFooter` · свой элемент |
| `chat`, `chatFixed`, `chatLabel` | кнопка чата: нет (по умолчанию) · `true` или обработчик |
| `chatOpen` | окно чата открыто: на кнопке крестик `medium-pragmatic/cross`, подпись «Закрыть чат». Смена иконки — `fade-in-scale` micro. Само окно — `ChatWindow` |
| `search`, `tabBar` | мобилка: блок поиска; `true`, пропсы `TabBar` или элемент |

`PageFooter`: `brand` (`bank` · `business`), `phone`, `phoneCaption`, `links` (строки или `{ label, href, onClick }`), `disclaimer`, `copyright`, `onNavigate`, `logoHref`, `onLogo`. `false` или пустая строка убирают блок.

## Пробелы
- **Экран уже 1360** (например, 1024): страница уменьшается целиком, как картинка — сетка 1104, шрифты и отступы в масштабе ширина / 1360 (на 1024 ≈ 0,75). Горизонтальной прокрутки нет (решение команды, 30.10.2026). Ширина берется у родителя: в рамке прототипа — ширина рамки. Окна `Dialog`, тосты и выпадашки рисуются поверх страницы и не уменьшаются. Отключить — `scale: false`.
- **Футер Т-Бизнеса** в шаблонах нет. С `brand="business"` ставится логотип Т-Бизнеса, а тексты по умолчанию — из шаблона Т-Банка: передайте свои.
- **Тексты футера в шаблоне устарели** («АО «Тинькофф Банк»», © 2006—2024). Юридические формулировки берём у продукта и юристов.
- **Иконка чата** в шаблоне — `Pack / ic-chat-48` (28 × 26), в ДС её нет; стоит Fancy `medium/chat` 24 (решение команды). Наведение и нажатие кнопки чата в шаблоне не показаны: взяты `accent-1-hover` / `-pressed`, как у кнопки primary.
