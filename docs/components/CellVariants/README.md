# Cell · варианты

Таблица популярных комбинаций `tui-cell` — повтор страницы «Превью вариантов» из Figma-файла `tui-cell`.

- **Строки:** Text, Switch, Disclosure, Checkbox.
- **Колонки:** iOS, Desktop L, Desktop M, Desktop S.
- **Внутри каждого типа** ячейка показана с аватаром или без, с description или caption.

Тоггл и чекбокс в превью можно нажимать. Правила и размеры — в карточке Cell.
