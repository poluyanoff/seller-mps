# KeyValueSelect (Key-value-select)

Выбор пары «ключ:значение» в поле с чипами (`tui-input-chip`): сначала ключ, потом его значение. Для тегов и меток вида `device.arch:arm64`. Только десктоп. Внутри `SmartFilter` — значение атрибута `type: 'tag'`.

## Построение
- **Поле** — `InputChip`: ширина — по контейнеру, S (32) по умолчанию, M — `size: 'm'`. Выбранные пары — чипы с крестиком.
- **Панель** — во всю ширину поля, через 4 под ним. Высота — по контенту, до 380; скроллится только список. Радиус 8, фон `elevation-1`, обводка `border-normal`, тень `shadow-small`.
  - **Шапка** 40 — `background-base-alt`, поля 10 / 12: иконка `tag` 16 → 4 → «Ключи» или «Значения», `body-s`.
  - **Пункты** 36 через 2, поля 4 / 12. Пункт: поля 6, радиус 4, `ui-s`; ховер и активный — `neutral-1`; длинный текст — фейд.
  - **Футер** 44 — `background-base-alt`, поля 10 / 12: подсказка клавиши (чип 24, `neutral-1`, радиус 4) и ссылка на документацию справа.

## Поведение
- **Клик в поле** — focus и список ключей.
- **Ключ** выбирают из списка, ищут вводом. Свой ключ — через «:» (`allowCustom`).
- **Значение.** Ключ выбран — в поле «ключ:», список меняется на значения. Поиск по значениям — вводом после двоеточия. Свое значение — по Enter (`allowCustom`).
- После выбора значения в поле — чип «ключ:значение». `multiple` — снова список ключей для следующего чипа. Backspace на пустом вводе удаляет последний чип.
- Ничего не нашлось — «Ничего не найдено».
- **Ошибка ввода** (`validate`) — поле в ошибке, справа «?» (`ButtonTooltip`) с правилами из `hint`, список не закрывается. Пара с ошибкой не добавляется.
- Клавиатура: ↑↓ — пункты, Enter — выбрать, Esc — закрыть список.

### Кастомизация
- Нет создания своих ключей и значений — подсказки клавиш в футере скрыты (без `allowCustom`).
- Нет ссылки на документацию — без `docsLink`.
- Нет ни того, ни другого — футера нет. Убрать футер явно — `footer: false`.

## Решения команды и отличия от Figma
- **Тексты — по-русски:** «Keys» / «Values» → «Ключи» / «Значения», «to add key» / «to add value» → «добавить ключ» / «добавить значение», «More in documentation» → «Документация», «Nothing found» → «Ничего не найдено», «Search key» → «Найти ключ».
- **Шрифт клавиш** — шрифт ДС, в гайде SF Pro.
- **Тень — `shadow-small`**, как у `Dropdown`, в гайде 0 8 16 rgba(0,0,0,.16). Ночью теней нет — в ночном макете гайда тень есть.
- **Фокус поля — фокус `Input` ДС** (2 `border-focus`), в гайде черная рамка 1. Ошибка — фон `status-negative-pale`, как у полей ДС, в гайде красная рамка.
- **Скроллбар** — системный тонкий, как у `Dropdown`. В гайде #cccccc — не токен.

## Пробелы
- Disabled, loading, клавиатурная навигация, удаление и правка чипа, перенос чипов не показаны — поведение `InputChip`.
- Ширина панели в гайде 434, в тексте — «по ширине поля». В коде — по полю; в `SmartFilter` — 434.
- Куда ведет ссылка на документацию — задает продукт.

## API
```js
h(TaigaUI.KeyValueSelect, {
  keys: { 'device.arch': ['arm64', 'x86_64'], 'browser.name': ['Chrome', 'Safari', 'Firefox'] },
  multiple: true, allowCustom: true,
  value: tags, onChange: setTags,
  validate: function (key, value) { return /[^a-z0-9._-]/i.test(key + (value || '')) ? 'Только латиница' : null; },
  hint: 'Ключ и значение должны состоять из латинских букв',
  docsLink: { href: '/docs/tags' }
})
```
- `keys` — `{ ключ: значения }` или `[{ key, label, values }]`.
- `value` / `defaultValue` / `onChange` — строка «ключ:значение» или массив при `multiple`.
- `allowCustom`, `validate(key, value)`, `hint`, `error`, `docsLink`, `hints` (false — без подсказок клавиш), `footer` (false — без футера), `size` (`s` · `m`), `label`, `placeholder`, `keysLabel`, `valuesLabel`, `emptyText`, `disabled`, `id`, `className`, `style`.
