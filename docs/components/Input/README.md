# Input (`tui-input` / `tui-textfield`)

Базовое текстовое поле. По гайду «tui-input / tui-textfield / tui-select / tui-combobox / tui-textarea», страница «Базовое поле». На этом каркасе построены селект, комбобокс, многострочное поле, поле с суммой, маски, слайдер. Их правила, формы и редполитика — в разделе «Формы и поля ввода».

Поля выбора (селект, комбобокс, автокомплит) — отдельные компоненты на этом поле, карточка **Select**. Сумма, телефон и пароль — **InputAmount**, **InputPhone**, **InputPassword**; многострочное — **Textarea**; с чипами — **InputChip**.

## Какой компонент брать
| Платформа | Код | Figma |
|---|---|---|
| Натив iOS/Android | `tui-textfield` (в формах — фреймворк SmartFields) | `tui-textfield`, TUI Mobile |
| PWA / WebView | `tui-input` (React/Angular), выглядит как натив | `tui-textfield`, TUI Mobile |
| Десктоп | `tui-input` | `tui-input`, TUI Desktop |

Компоненты с префиксом `[legacy]` и `[deprecated]` в новых макетах не используем (см. «Миграция» в разделе форм).

## Построение
`top-label` (снаружи, опционально) → поле: `start-accessories` · `content` (label + value/placeholder) · `end-accessories` → `hint` (опционально).
- Лейбл и подсказка необязательны, значение обязательно.
- Пустое поле без фокуса показывает лейбл крупно, на месте значения. В фокусе и заполненное — мелко над значением.

## Размеры
| | высота (min) | радиус | отступы слева / справа | лейбл | значение |
|---|---|---|---|---|---|
| Desktop **L** (по умолчанию, клиентские) | 56 | 12 | 16 / 16 | `ui-s` 13/16 | `ui-m` 15/20 |
| Desktop **M** (служебные, плотные) | 44 | 8 | 12 / 10 | `ui-2xs` 11/13 | `ui-s` 13/16 |
| Desktop **S** (компактные служебные) | 32 | 8 | 10 / 6 | только снаружи | `ui-s` 13/16 |
| **Mobile** (iOS, Android, PWA) | 56 | 16 | 12 / 12 | `ios-ui-s` 13/16 | `ios-ui-l` 17/20 |

- **Мобилка:** один размер. Внешние боковые отступы **16** заложены в компонент переменными, их можно отключить. Внутри: 8 сверху и снизу, между лейблом и значением 2. Отступы по бокам не зависят от accessories.
- **Десктоп:**
  - справа до **3** accessories, каждый в контейнере **24**, между ними 4;
  - от контента до accessories 8;
  - левый accessory: на L отступ 16, на M 12, на S 8.
- **Подсказка** — **8** от поля, несколько подсказок — тоже через 8. **Лейбл снаружи** — 8 до поля.
- Нужно ввести длинный текст — берите многострочное поле.
- **Размер по умолчанию в коде — L** (решение команды, 25.10.2026): поле без `size` на десктопе — L. Так же `Select`, `Combobox`, `Textarea`, `InputDate`, `InputTime`, `InputAmount`, `InputPhone`, `InputPassword`, `InputChip`, `InputCopy`; список у `Select` и `Combobox` — того же размера. M и S — только явным `size`: служебные и плотные экраны, тулбары. Поля внутри фильтров и выпадашек берут размер своего компонента.

## Состояния
- **Normal.**
- **Hover** (десктоп) — фон `neutral-1-hover`.
- **Pressed** (мобилка):
  - iOS — `neutral-1-pressed` без анимации;
  - Android — системный ripple.
- **Focus** — активное поле.
- **Invalid** — фон `status-negative-pale`, текст подсказки `text-negative`.
- **Disabled.**
- **Read-only** — можно выделить и скопировать.
- **Loading.**
- **Tap-only** (только натив) — поле целиком нажимается, например чтобы скопировать.

В Figma hover и pressed отдельных вариантов не имеют, красим руками.

## Поведение
**Длинный текст:**
- в нативе фейд в начале или в конце, в зависимости от состояния;
- на десктопе и в PWA текст обрезается, фейд технически невозможен.

**Курсор при фокусе:**
- iOS — всегда в конец;
- Android и веб — в точку тапа, иначе в конец (Android) или в начало (веб).

**Выделение и автозаполнение.** Фон выделения — `service/selection-background`. Автозаполнение работает на десктопе и в PWA (e-mail, пароль, телефон), поле подсвечивается `service/autofill`.

**Очистка:**
- десктоп — крестик виден у заполненного поля;
- мобилка — только в фокусе и только если нет других end-accessories;
- клик по крестику в неактивном поле фокусирует и очищает его;
- текст стирается мгновенно;
- крестик можно отключить.

**Подсказки (hint):**
- мобилка — по умолчанию только в фокусе, десктоп — всегда (оба режима переключаются);
- в нативе подсказки есть только в SmartFields;
- появление: opacity 0 → 1, `productive-entrance`, `duration-moderate` 300 мс, контент ниже сдвигается;
- скрытие: `productive-exit`, `duration-fast` 150 мс;
- несколько подсказок анимируются одним блоком.

**Ошибка:**
- валидация при сабмите (по умолчанию) или по мере ввода;
- при ошибке показываем **только** её текст, остальные подсказки скрываем;
- на мобилке поле трясётся с хаптиком:
  - первый раз — `duration-slow` 500 мс, X: 0 → −3 → 3 → −3 → 3 → 0;
  - повторная валидация — 300 мс, 0 → −3 → 3 → 0;
- после правки символа ошибка снимается.

**Счётчик символов:**
- обычная подсказка или появляется у порога (например, при 100 из 300);
- сверх лимита по умолчанию вводить можно — поле переходит в ошибку («Максимум 5 символов — нужно удалить 1»);
- можно включить жёсткое ограничение: лишнее не вводится, вставка обрезается, на мобилке haptic Impact Heavy.

**Переходы между состояниями** и появление крестика — `duration-fast` 150 мс, `productive-standard`.

**Области нажатия:**
- в нативе высота области = минимальная высота поля, ширина = элемент с отступами;
- на десктопе у крайних элементов зона шире.

## Дополнительные возможности
- **Без лейбла (`labelOff`)** — если поле понятно и так, например лупа в поиске.
- **Лейбл снаружи** (только десктоп) — вместо внутреннего или вместе с ним.
- **Текст по центру** — только без лейбла, accessories, плейсхолдера в фокусе и крестика. Например, код из СМС.
- **Префиксы и суффиксы.**
  - «от 2 дней», «100 шт.», «₽». Можно отбить пробелом или ставить вплотную (%).
  - Без плейсхолдера видны сразу в фокусе, с плейсхолдером — после начала ввода.
  - При переполнении суффикс остаётся виден.
- **Крупный шрифт значения** для сумм:
  - уменьшается по мере ввода до 10 px, затем переполнение;
  - высота не меняется;
  - на десктопе только размер L, без крестика.
- **Авторост высоты** (+1 строка, можно задать min-height) — для многострочных полей и списков.
- **Загрузка.** Лоадер всегда левый в правом блоке, его стиль не меняем. Размер зависит от размера поля.
- **Динамические accessories** — кнопка меняет содержимое (показать пароль).
- **Кастомизация:**
  - свой контент справа: «10%» у первоначального взноса;
  - кнопка вместо иконки («Не помню») — правый отступ можно убрать;
  - бейдж (только мобилка — на десктопе перекроет рамку фокуса);
  - левый блок — иконка, кнопка, бейдж (номер карты);
  - картинка в подсказке;
  - ссылка в подсказке (`text/action`).
- **Тултип** (десктоп) — кнопка «?» по правилам `tui-tooltip`.

## Правила использования
- **Ширина поля по содержимому.** Чем короче значение, тем уже поле. «Дом», «Корпус», «Квартира» — узкие поля в ряд.
  - Это правило для полей в ряду. Одиночное поле в карточке, колонке формы или шаге — на всю ширину контейнера, без пустого места справа (решение команды, 25.10.2026).
- **Ряд полей заполнен целиком.** Колонок столько же, сколько полей: два поля — две колонки, а не три с пустой. Последнее поле доходит до правого края. Подробно — в разделе форм, «Ширина полей».
- Лейбл — существительное без двоеточия, без «Введите» и «Укажите» (подробно — в разделе форм).

## Тексты
- Лейбл — существительное: «Номер телефона». Не повторяет заголовок экрана. Необязательное поле — «ИНН, если есть». Звездочек нет.
- В лейбле и плейсхолдере не пишем «Введите…»: поле само подразумевает ввод. Пример — «например, „Оплата аренды офиса“».
- Ошибки: пустое — «Напишите <что>» (выбор — «Выберите <что>»), длина — «ИНН — 10 цифр», лимит — «Максимум 100 символов», формат — «Проверьте формат — подходят …».
- Общие правила текстов и коды — раздел «Тексты интерфейса» (`copy.md`): HD3–HD6, VL1–VL5. Готовые тексты для типовых полей — `forms.md`.

## Доступность
- Крупный шрифт: до AX1 на iOS, до 150 % на Android, то же в мобильном вебе и PWA. Иконки ×1.25 только в AX1/150 %. В WebView крупный шрифт пока не прокинут (гайд по WebView), но вёрстка не должна ломаться при росте текста.
- Высота растёт, если заполненный текст не влезает. Отступы при этом минимум 8. Пустое поле той же высоты, что заполненное, чтобы форма не прыгала.
- React-веб масштабирует высоту коэффициентом:

  | Размер шрифта | Коэффициент |
  |---|---|
  | 120 % | 1.05 |
  | 130 % | 1.15 |
  | 140 % | 1.25 |
  | 150 % | 1.35 |

- Лейбл всегда в одну строку. Поля в ряд оборачиваем в `tui-adaptive-row`: при крупном шрифте они встают в столбик.
- Если третий элемент справа шире 35 %, с 130 % он переносится на новую строку. Лоадер и крестик остаются на месте.
- **Озвучка:**
  - «Label, текстовое поле (iOS) / окно редактирования (Android), Value»;
  - ошибка — «Ошибка: <описание>»; подсказка озвучивается в фокусе, можно включить всегда;
  - крестик — «Очистить поле, кнопка»; loading — «Идет загрузка»; tap-only — «Нажмите дважды, чтобы скопировать текст»;
  - кликабельные accessories фокусируются отдельно, некликабельные озвучиваются в value, декоративные пропускаем.

## API в коде
```js
h(TaigaUI.Input, { size: 'l', label: 'Сумма перевода', defaultValue: '1 500', suffix: '₽', hint: 'Без комиссии до 100\u00a0000\u00a0₽' })
h(TaigaUI.Input, { platform: 'mobile', label: 'Номер телефона', error: 'Нужен номер, чтобы курьер мог связаться с вами' })
h(TaigaUI.Input, { size: 's', labelOutside: true, label: 'Поиск по статьям', labelOff: true, iconLeft: 'magnifier', placeholder: 'Справки' })
```
Пропы:
- `size` (l | m | s), `platform`;
- `label`, `labelOutside`, `labelOff`;
- `value`, `defaultValue`, `onChange`, `placeholder`;
- `hint` (строка или массив), `hintAlways`, `error`, `invalid`;
- `disabled`, `readOnly`;
- `cleaner`, `dropdown` (шеврон поворачивается в фокусе или по `open`), `select` (поле только для выбора), `onClear`, `loading`, `tooltip`, `accessory`, `iconLeft`;
- `prefix`, `suffix`;
- `maxLength`, `counter`, `limitInput`;
- `align`, `dynamicFont`, `type`, `inputMode`;
- `onClick`, `onKeyDown`, `onFocus`, `onBlur`, `inputRef`, `inputProps` (атрибуты самого `<input>`: role, aria-*).
