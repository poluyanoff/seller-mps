# Select, Combobox, Autocomplete (`tui-select` / `tui-combobox`)

Поля выбора из списка по гайду «tui-input / tui-textfield / tui-select / tui-combobox / tui-textarea». Правила выбора типа, редполитика и поведение — в разделе «Формы и поля ввода». Поле наследует `Input`, список — `Dropdown`.

| Компонент | Когда | Поведение |
|---|---|---|
| `Select` | до 10–15 значений, один выбор (на мобилке оптимально 5–7) | без поиска, своё значение нельзя |
| `Select multiple` | несколько значений | чекбоксы в списке; в поле — текст через запятую или счётчик «Выбрано 2 из 10» (`display: 'count'`). Чипами (десктоп) — `InputChip` с `items` |
| `Combobox strict` | больше 15, один выбор из списка | ввод — поиск; невалидное значение сбрасывается при потере фокуса; фильтрацию не отключить |
| `Combobox` (гибкий, по умолчанию) | больше 15, можно своё | список фильтруется, нет совпадений — список скрывается; своё значение сохраняется; `filter={false}` — без фильтрации |
| `Autocomplete` | свободный ввод + подсказки | список только при вводе и только с совпадениями, без шеврона, с индикатором загрузки |

## Десктоп
- Список — `DropdownList` размера поля во всю его ширину, через **4** от рамки поля, до **400** по высоте, дальше скролл.
- Выбранный пункт — иконка справа; пункты группируются заголовками (`{ type: 'header' }`); пресеты: текст, текст + описание, текст + аватар + описание.
- Шеврон при открытии поворачивается на 180° (`productive-entrance`, `fast`).
- **Загрузка:** лоадер в поле появляется через **300 мс** и держится минимум **500 мс** (`loading`, правило 300/500 из раздела «Загрузки»). Загрузка и ошибка списка — `listLoading`, `listError` + `onRetry` («Не загрузилось. Обновить»), подгрузка — `onMore`.
- **Клавиатура:** Enter или ↓ — открыть; ↑ / ↓ — по списку; Enter или пробел — выбрать; Esc — закрыть.
- **Очистка** (`cleaner`): поле очищается, фокусируется, у комбобокса открывается список.

## Мобилка (`platform="mobile"`)
- **Селект** — шторка `BottomSheet`: заголовок — лейбл поля, ячейки во всю ширину. После выбора шторка закрывается, фокус переходит к следующему полю (`focusNext={false}` — отключить). Мультиселект — чекбоксы **справа**, кнопка «Применить».
- **Комбобокс и автокомплит** — полноэкранный список: поле уезжает наверх, под ним саджесты (`productive-entrance`, `moderate`, opacity 0 → 1). Текст в поле и в саджестах — на одной линии.
  - Поле с ошибкой: текст ошибки под полем, саджесты ниже — список не прячем. После первого введённого символа ошибка скрывается.
- Полноэкранный список сверху — `NavigationBar` со статус-баром и «Готово» справа, как на остальных экранах. В коде продукта для WebView — `statusBar: false`.
- Полноэкранный список закрывается выбором саджеста, «Готово» (`doneLabel`), тапом по пустому аппбару, свайпом вниз (iOS) или вправо (Android).
- **Ошибка валидации:** сначала хинт с ошибкой, список — после изменения текста.

## API
```js
h(TaigaUI.Select, { label: 'Способ оплаты', items: ['Наличными', 'Картой онлайн', 'СБП'], value, onChange })
h(TaigaUI.Select, { label: 'Уведомления', multiple: true, display: 'count', items: [{ label: 'СМС', value: 'sms' }, …], value: ['sms'], onChange })
h(TaigaUI.Combobox, { label: 'Страна', strict: true, items: countries, value, onChange })
h(TaigaUI.Combobox, { label: 'Профессия', items: jobs, value, onChange })        // гибкий: onChange('Свое значение', null)
h(TaigaUI.Autocomplete, { label: 'Адрес', inputValue, onInputChange, loading, items: suggestions })
h(TaigaUI.Select, { platform: 'mobile', label: 'Способ оплаты', items, value, onChange })   // шторка
```
Общие пропсы поля — как у `Input` (`size`, `label`, `placeholder`, `hint`, `error`, `disabled`). Списка — `items` (строки или `{ label, value, description, avatar, disabled }`, заголовки `{ type: 'header' }`), `maxHeight`, `emptyText`. Мобилка — `system`, `sheet` (пропсы шторки), `sheetTitle`, `applyLabel`.

**Положение списка:** под полем через 4. Если снизу не помещается, а сверху помещается — над полем, как у `Dropdown` (Select, Combobox, Autocomplete).

## Пробелы
- Выравнивание аватара саджеста по линии поля на мобилке — не сделано (текст выровнен).
- В нативе списки есть только в SmartFields v3 — компонент только для веба и PWA.
