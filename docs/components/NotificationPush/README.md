# NotificationPush (`tui-notification-push`)

Пуш-нотификация на десктопе: сообщает о событии в продукте — пришли документы, изменился статус, есть что подписать. По Figma «TUI Web. Demo & Guides» → Notification Push.

Не путать с `Toast` — короткая реакция на действие пользователя, и с `NotificationBanner` — статус среди контента. Список пушей в одном окне — `NotificationFeed`.

## Построение
Картинка (необязательно) → шапка: иконка + «Тип • Время» → заголовок (необязательно) → текст → действия (необязательно). Крестик — всегда.

- **Контейнер:** ширина **360**, высота по контенту. Фон `background-elevation-2`, радиус **24**, поля **20**, тень `tui-shadow-medium`.
- **Картинка:** сверху, **360 × 170**, без полей.
- **Шапка:** иконка **20** → 12 → тип и время `body-s` 13/20, `text-secondary`, между ними «•» с отступами 5.
- **Заголовок:** через 12 от шапки, `ui-m-bold` 15/20, `text-primary`, справа отступ 24 под крестик.
- **Текст:** через 4 от заголовка, `body-m` 15/24, `text-primary`.
- **Действия:** через 12 от текста.
  - два — `Button` S → 16 → `Button` S `flat`;
  - одно — только `Link`;
  - без действий.
  - Кнопка в светлом пуше — `secondary`, в тёмном — `accent`.
- **Крестик:** `ButtonClose` x-small (24), в 12 от верхнего и правого края. Без картинки — `default` (`neutral-1`, иконка `text-tertiary`), на картинке — `glass-on-light`. Для тёмной картинки — `closeAppearance: 'glass-on-dark'`.

## Поведение
- **Пуш кликабелен целиком** (`onClick`) — ведёт к событию. Действия и крестик нажимаются отдельно и пуш не открывают.
- **Расположение:** правый нижний угол окна, **32** от правого и нижнего края (макет «Транспортные документы»).
- **На экране один пуш.** Новый заменяет текущий: текущий уезжает, новый выезжает.
- **Открыта лента** (`NotificationFeed floating`, тот же угол) — пуш не всплывает: уведомление сразу появляется в ленте в «Новых». Открытие ленты убирает показанный пуш (`onClose('feed')`).
- **Анимация** (гайд по анимации, своей у пуша в Figma нет — решение команды):
  - появление — slide-in micro: выезжает справа, `duration-moderate`, `easing-productive-entrance`;
  - скрытие — slide-out micro: уезжает вправо, 200 мс, `easing-productive-exit`;
  - при `prefers-reduced-motion` — без движения.
- **Сколько висит:** пока не закроют крестиком или не нажмут на пуш. `duration` — скрыть через N мс.

## Правила
- Тема пуша — светлая или тёмная — не зависит от темы интерфейса (`theme`).
- Таймштамп: «Только что», «1 час назад», «Вчера», «15 июля».
- Картинка — 360 × 170, лучше со сплошным контрастным фоном. Белый фон нельзя.
- Крестик виден всегда.
- Размеры и отступы одинаковые во всплывающем виде и в ленте (`NotificationFeed`). Исключение по Figma — боковые поля пункта ленты 24.

## Тексты
- Заголовок и текст вместе — не больше 4 строк, остальное уходит в многоточие. Заголовок — не больше 2 строк. Компонент обрезает сам.
- Перечисление — без маркированного списка, через запятую. Если элементов много — «и еще N»: «Сертификат, анкета и еще 3».

## API
```js
h(TaigaUI.NotificationPush, {
  icon: 'medium/airplane', type: 'Путешествия', time: '1 час назад',
  title: 'Подпишите документы', text: 'Сертификат, анкета и еще 3',
  actions: [{ label: 'Подписать', onClick: sign }, { label: 'Не сейчас', onClick: later }],
  onClick: open, onClose: close
})
h(TaigaUI.NotificationPush, { theme: 'dark', image: 'promo.png', icon: 'medium/airplane', type: 'Путешествия', time: 'Вчера', text: 'Билеты в Казань от 2\u00a0990\u00a0₽' })

// Показ: правый нижний угол, один пуш, выезжает справа
var id = TaigaUI.showPush({ icon: 'medium/airplane', time: '12:56', title: 'Новый транспортный документ', text: 'Накладная № 1 от ИП Сергеев В.М.', actions: [{ label: 'К документу' }], onClick: open })
TaigaUI.hidePush(id)
// В макете или превью — хост внутри рамки страницы (position: relative)
h(TaigaUI.PushHost, { inline: true })
```
- **`showPush(opts)`** — пропсы `NotificationPush` плюс `duration` (мс, по умолчанию не скрывается) и `onClose(reason)`: `button` · `click` · `timeout` · `replace` · `feed` · `hide`. Если хоста нет, он создаётся сам. Возвращает `id` для `hidePush`.
- **`PushHost`:** `right`, `bottom` (по умолчанию 32), `inline`, `container`.
- `icon` — имя иконки (Fancy — `medium/…`) или элемент, размер 20; `iconColor` — токен без `--tui-` или CSS-цвет, по умолчанию `text-action`.
- `type`, `time` — части шапки; `title`; `text` или `children`.
- `image` — ссылка или элемент, `imageAlt`.
- `actions` — до двух `{ label, onClick, href, target }`: при двух первое — кнопка, второе — кнопка `flat`; одно — ссылка. `href` и `target` работают только у одной ссылки.
- `onClick` — нажатие на пуш целиком; `label` — подпись для озвучки, если нет ни заголовка, ни текста.
- `theme` — `light` / `dark`; без него — как у интерфейса.
- `onClose`, `closeLabel` (по умолчанию «Закрыть»), `closeAppearance` — вид крестика.

## Отличия от Figma
Макет в Figma собран на старых токенах и кнопке. В ДС берём ближайшее:
- **Кнопка:** в Figma высота 36, радиус 12, текст 15/20. В ДС такой нет — `Button` S (32, радиус 8, `ui-s` 13/16).
- **Ссылка:** в Figma 15/20, как у кнопки. Рядом с кнопкой — `Button` S `flat` (`ui-s` 13/16): с `Link` large шрифты кнопки и ссылки расходились (решение команды). Одна ссылка — `Link` large (`body-m` 15/24).
- **Цвета:** `Day/Base/elevation-02` → `background-elevation-2` (ночью в Figma #313131, в ДС #333333); `Day/Text/link` → `text-action`; `Base/secondary` → `background-neutral-1` у кнопки secondary.
- **Тень:** в Figma `Shadow / Default` 0 4 24 12 % — в ДС `tui-shadow-medium` (уровень Elevation 2). Ночью тени нет, как во всей ДС; у тёмного пуша на светлом интерфейсе тень остаётся.
- **Иконка:** в Figma `Base/accent` #428BF9. Иконки в ДС красятся токенами текста — по умолчанию `text-action`.
- **Крестик:** в макете пуша — свой (белый 30 %, иконка чёрная 54 %). Берём `tui-button [close]` из TUI Desktop — `ButtonClose` (решение команды).

## Пробелы
- **Hover и pressed** у пуша заведём отдельно. Сейчас у пуша меняется только курсор; у крестика, кнопки и ссылки — свои состояния.
- **Показ:** сколько пушей видно одновременно и сколько пуш висит, в Figma не описано. Сейчас — один пуш, висит до закрытия. Анимация взята из гайда по анимации, своей у пуша нет.
- **Одно действие:** по гайду пуша одно действие — ссылка; в макете «Транспортные документы» одно действие — кнопка «К документу». Оставили по гайду.
- **Отступ между двумя действиями:** в Figma 16 от кнопки до ссылки. Оставили 16 между кнопками, поэтому текст flat-кнопки стоит на 26 от первой кнопки — 10 занимают её поля.
- **Мобилка** не описана: компонент десктопный.
- Длинный тип в шапке в Figma не показан: обрезаем многоточием, время не обрезаем, справа 24 под крестик.
