# Cell connected (`tui-cell [connected]`)

Ячейки, связанные вертикальной полоской между аватарами. Подходят для шагов процесса («Как проходит сделка», «Как получить вычет») и для последовательных условий. Взято из гайда `tui-cell`, страница `tui-cell [connected]` (v1.0.0). В Figma есть варианты для iOS (375) и Android (360). В коде это та же `Cell` с пропом `connected`.

## Построение
- Боковые отступы 16. Аватар 40 прижат к верху с отступом 16 сверху и снизу. До текста 16.
- Текст: сверху и снизу отступ 16. Строки (caption, title, description) идут через 4; шрифты как у мобильной ячейки: `ios-ui-l` 17/20 и `ios-ui-s` 13/16. Минимальная высота 72, дальше растёт по тексту. Размер текста не ограничен.
- **Полоска:**
  - 1 px, цвет `background-neutral-3`, проходит по центру аватара;
  - от аватара отступает на 4 сверху и снизу и упирается в края ячейки;
  - верхняя всегда 12;
  - нижняя тянется вслед за ячейкой, в том числе при увеличении шрифта.
- **Крайние ячейки.** У первой нет полоски сверху (`connectTop: false`), у последней снизу (`connectBottom: false`). У средних полоски с обеих сторон.
- **Справа** можно поставить бейдж-нотификацию и кнопку-подсказку. Они выровнены по аватару, между ними 16.

## Кастомизация
- **Аватар** настраивается по правилам `tui-avatar`:
  - номер шага;
  - иконка;
  - картинка или логотип;
  - серый для недоступного или будущего шага;
  - прогресс для текущего шага.
- **В одном списке — один стиль аватаров.** Не смешиваем номера с иконками: это путает.
- **Контент** настраивается как у обычной ячейки: caption («Шаг 1»), описание, ссылки под текстом.

## Где используем
- **В карточках.** Ячейки упираются в края карточки. Например, условия по уровням: доступное — синий аватар, закрытое — серый с замком и приглушённый текст.
- **В списках** на экране ориджинейшена или онбординга, например «Как проходит сделка», «Проверьте, всё ли получилось». Номера шагов — синие аватары с белой цифрой.

## Доступность
Озвучивается как обычная `tui-cell`, полоски для скринридера скрыты.

## API в коде
```js
var steps = ['Выбираете авто для продажи', 'Отправляете предложение покупателю', 'Мы формируем договор'];
steps.map(function (t, i) {
  return h(TaigaUI.Cell, { key: i, platform: 'mobile', connected: true,
    connectTop: i > 0, connectBottom: i < steps.length - 1,
    avatarText: i + 1, title: t });
});
```
Пропсы: `connected`, `connectTop` и `connectBottom` (по умолчанию true), `avatar` (иконка или свой элемент), `avatarText` (номер шага), `avatarTone` (`neutral` — серый). Остальные пропсы такие же, как у `Cell`: `caption`, `description`, `accessory`, `disabled`…

Вариант Figma `fixed-height=on` (высота 72, текст не растёт) в коде отдельно не сделан, используем обычный.
