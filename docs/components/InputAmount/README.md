# InputAmount (`tui-input-number` / InputAmount)

Поле суммы. Наследует `Input`. Формат суммы — как у [`Amount`](../Amount/README.md) (`tui-amount`). Правила — «Поле с суммой» в разделе «Формы и поля ввода». В React это InputAmount (мобилка) и InputNumber (десктоп), в Figma — `tui-input-number`; в ДС — один компонент.

## Форматирование (автоматически, пробелы неразрывные)
- Разряды по 3, начиная с 4 цифр: 999, 1 000, 1 000 000.
- Дробная часть (`decimals`, по умолчанию 2): всегда 2 цифры (299,90) или скрыта, если нули. Разделитель — запятая. `decimals: 0` — только целые.
- Минус — `−` (U+2212), без пробела (`allowNegative`).
- Валюта справа через неразрывный пробел (`currency`, по умолчанию ₽; без знака — код латиницей, `'MXN'`); `currency={false}` — без валюты.
- Во время ввода каретка не прыгает: форматирование держит её после той же цифры.

## Варианты
- **Мобилка:** крестик всегда выключен.
- **Крупный шрифт** (`large`): только без лейбла; на десктопе только L; без крестика.
- **Всегда заполненное** (`uncleanable`): 0 при входе, ввод заменяет ноль, пустое при потере фокуса снова 0.
- **Справа** — иконка или кнопка («+100», «+1 000»): `accessory`.
- **Саджесты** — кнопки сумм под полем (`suggestions: [100, 500, 1000]`): `Button` secondary XS на десктопе, S на мобилке, через 8.
- Озвучка «100 знак рубля» — задача разработки, читается как «100 рублей».

## API
```js
h(TaigaUI.InputAmount, { label: 'Сумма перевода', size: 'l', value, onChange, suggestions: [1000, 5000, 10000] })   // onChange(number | null)
h(TaigaUI.InputAmount, { platform: 'mobile', large: true, uncleanable: true, decimals: 0, value, onChange })
TaigaUI.formatAmount(1234567.5) // '1 234 567,50'
TaigaUI.formatAmount(-1000, { currency: '₽' }) // '−1\u00a0000\u00a0₽' — опции как у Amount
```

## Пробелы
- Размер кнопок-саджестов в гайде не указан: XS на десктопе, S на мобилке (по правилу «действия — `tui-button` S» из `Chip`).
- Иноязычный интерфейс в поле не сделан: только русская локаль. Отображение суммы в иноязычном формате — `Amount` / `formatAmount` с `format: 'foreign'`.
