# Dialog (`tui-dialog`)

Модальное окно по гайду tui-dialog. На десктопе — окно по центру на подложке или полноэкранный диалог (заявочные сценарии). На мобилке (PWA, WebView) — диалог-шторка на `BottomSheet` (по умолчанию) или полноэкранный диалог.

**Когда использовать.** Пояснения, условия, подтверждения, формы без шагов (ориентир — до 6 полей), выбор из короткого списка. Блокирующий диалог — только для важных действий и критических ошибок. Сценарий из нескольких шагов — полноэкранный диалог (см. «Ориджинейшен»).

**Форма в Dialog или Dialog fullscreen** (решение команды, 30.10.2026). Ориентир, не жесткое правило: форма без шагов до 6 полей — обычный `Dialog`. Больше полей, длинные подсказки, загрузка файлов или шаги — `Dialog fullscreen`. Решайте по тому, помещается ли форма в окно без долгого скролла.

## Модальное окно (десктоп)
| | Small | Medium | Large |
|---|---|---|---|
| Ширина | 400 | 600 | 800 |
| Паддинг | 24 | 28 | 28 |
| Между блоками | 20 | 24 | 24 |
| Заголовок (`Header`) | h5 | h4 | h4 |
| Отступ заголовка справа (под крестик) | 38 | 34 | 34 |
| Кнопки | M (44) | L (56) | L (56) |
| Футер сверху | — | +8 | +8 |

- **Окно:** фон `background-elevation-1`, радиус **24**, тень `tui-shadow-popup`.
- **Подложка:** `tui-service-backdrop`, размытие **32** (только десктоп, отключается `blur={false}`). От краёв вьюпорта — **64**.
- **Крестик:** круг **32** `background-neutral-1`, иконка 16, **16** от верхнего и правого края. Можно убрать (`closeButton={false}`).
- **Футер:** кнопки справа через **12**: flat (второстепенное) + primary (основное, последнее в `actions`). Шапка и футер необязательны.
- **Ширина** своя — `width`, например для `OnboardingFlow`.
- **Ячейки в контенте** (десктоп, обычный и полноэкранный): кликабельная `Cell` без `inset` встаёт как `bleed` — аватар по линии заголовка, ховер выступает на 12 (карточка Cell, «Боковые отступы»). Свой отступ или `inset` для этого не нужен.

### Скролл
- **Фиксированная высота контента** (`height`): шапка и футер на месте, скроллится контент. Фейды **8**: нижний — пока есть что листать, верхний — после начала прокрутки, `duration-fast`.
- **Без высоты:** окно растёт, при переполнении скроллится вся подложка. Окно начинается в 64 от верха, скроллбар — у правого края экрана, ничего не липнет.
- Выпадашки (`Dropdown`) могут выходить за границы окна.

### Анимация
Окно появляется со сдвигом **32** снизу и прозрачностью 0 → 1, подложка — прозрачностью; `duration-moderate`, `productive-standard`. Закрытие — так же в обратную сторону.

> В общем разделе «Движение» модальным окнам отведены `duration-slow`/`slowest`. Гайд диалога задаёт `duration-moderate` — для `tui-dialog` берём его.

### Закрытие
- клик по подложке (`dismissible={false}` — отключить);
- Esc (`closeOnEsc={false}`);
- крестик;
- действие внутри.

`onClose(reason)` получает `'overlay' | 'esc' | 'button'`.

### Поведение
- **Вложенные диалоги:** подложка не меняется, нижний диалог затемняется `brightness(0.25)` (на мобилке 0.5). Esc закрывает только верхний.
- **Фокус:** при открытии — на окно, с `autoFocus` — на первое поле. Дальше Tab.
- **Загрузка:** при открытии — скелетон внутри; при отправке — `loading` у кнопки (`actions[i].loading`).
- Под шапкой можно положить свой липкий компонент (в `children`).

## Полноэкранный диалог (десктоп)
`fullscreen`. Для заявок и многошаговых сценариев.
- Фон `background-base`, без тени и подложки.
- **Аппбар 64** (`DesktopAppBar`) на `--tui-component-navigation-bar-background`: слева шеврон и «Назад» (`onBack`), в центре прогресс-бар **140** (`progress` 0…1) или тайтл 17 Medium (`appBarTitle`), справа «Закрыть» — 17, `text-action`, наведение `action-hover`, нажатие `action-pressed`.
  - `appBarSubtitle` — строка под тайтлом (UI S 13, `text-tertiary`); `appBarTitleKey` — при смене ключа тайтл появляется fade, `duration-fast`.
  - `closePosition: 'left'` — «Закрыть» слева, справа пусто (лейаут «Детали операции»). С `onBack` не работает.
- **Колонка 720:** заголовок `Header` h3 через **32** под аппбаром (96 от верха), между шапкой, контентом и футером — **32**.
- **Описание шага** (`description`) — description заголовка: Body L основным цветом, не серый subtitle (гайд ориджинейшена). Так и в мобильном полноэкранном диалоге. В модальном окне `description` по-прежнему серый subtitle.
- **Футер слева**, основная кнопка первой.
- **Лигал** (`legal`) — под контентом через **24**, над кнопками (они через 32 ниже): UI S, `text-secondary`, до 2 строк, ссылка серая с подчёркиванием. `legalPosition: 'right'` — справа от кнопок через 24, для лигала, который появляется и исчезает: так кнопки не прыгают (гайд «Button block & Legal»).
- `stickyFooter` — при скролле футер прилипает к низу: плашка на фоне навбара, отступы 16 сверху и 32 снизу.
- **Смена шагов** (`step` — номер или ключ шага): текущий шаг уходит в прозрачность со сдвигом −16 по X, следующий одновременно приходит с +32, `duration-moderate` (гайд «Ориджинейшен»: параллельно). Аппбар и закреплённый футер остаются на месте, прогресс-бар анимируется. Шаг назад — `stepDirection: 'back'` (движение зеркальное). При `prefers-reduced-motion` — без анимации.

## Мобилка (PWA)
Мобильные веб-версии максимально приближены к нативным приложениям, поэтому берём компоненты TUI Mobile.

**Диалог-шторка** — `platform="mobile"` (по умолчанию): `BottomSheet` с `Header` M, описанием, контентом и кнопками L столбиком, основная сверху. Свои пропсы шторки — в `sheet` (`height`, `snapPoints`, `modal`…). Геометрия, анимация и закрытие — в карточке BottomSheet.

**Полноэкранный** — `platform="mobile"` + `fullscreen`:
- `NavigationBar`: слева крестик «Закрыть», со `onBack` — «Назад», а «Закрыть» справа тоже крестиком (решение команды, 29.10.2026; у легаси `ios18` слева текст); в центре — прогресс или `appBarTitle`. Системы `ios`, `ios26`, `android` (`system`).
- заголовок `Header` L под аппбаром, `description` — description заголовка (iOS Body L основным цветом), контент с отступами 16. Отдельно стоящие `Cell`, `Header` с `inset` и `Row` компенсируют эти отступы сами и встают от края до края (поля 16 у них свои); поля ввода и карточки — в 16 от края. Свой боковой `padding` вокруг них не добавляем;
- контент тянется на всю высоту между шапкой и футером: `BlockStatus` с `type: 'fullscreen'` внутри шага (инфоэкран, ошибка загрузки) встаёт по центру;
- футер — `FloatingContainer` с фейдом, кнопки L столбиком, основная сверху; `legal` — под кнопкой в `FloatingContainer` (до 3 строк), как в нативе.
- Появление снизу: `duration-slow`, `expressive-standard`; закрытие: `duration-moderate`, `expressive-exit`.

## Тексты
- Заголовок — что происходит или о чем вопрос; кнопки — глаголом. Подтверждение критичного действия — «Да, удалить» в паре с «Отмена» или «Оставить».
- Общие правила текстов и коды — раздел «Тексты интерфейса» (`copy.md`): HD1, HD2, BT5, TN4.

## API
```js
h(TaigaUI.Dialog, {
  open, onClose: function (reason) {},
  size: 's' | 'm' | 'l', width,
  title, description, header: {/* пропсы Header */},
  children, height,                       // height — фиксированная высота контента со скроллом
  actions: [{ label: 'Отмена' }, { label: 'Сохранить', onClick, loading }], footer, footerAlign: 'end' | 'start',
  legal, legalPosition: 'bottom' | 'right', // полноэкранный
  closeButton, closeLabel, dismissible, closeOnEsc, autoFocus, blur,
  fullscreen, onBack, backLabel, progress, appBarTitle, stickyFooter, step, stepDirection: 'forward' | 'back',
  platform: 'mobile', sheet: {/* пропсы BottomSheet */}, system: 'ios' | 'ios26' | 'android', statusBar, appBar: {/* пропсы NavigationBar */},
  inline, container, label
})
```
- Рендерится порталом в `document.body`. Тема (`data-theme`) берётся с ближайшего предка. `inline` — внутри родителя (`position: relative`), для превью и вставки в макет.

## Пробелы
- Зеркальное движение при шаге назад — по аналогии.
- Ширина прогресс-бара в десктопном аппбаре взята из «Ориджинейшена» (140).
- Цвет иконки и ховер крестика (`neutral-1-hover` / `pressed`) — по аналогии с кнопками, в гайде не описаны.
