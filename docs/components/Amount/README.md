# Amount (`tui-amount`)

Компонент-утилита для форматирования сумм по гайду tui-amount v1.1.1. Подходит не только для денег, но и для процентов, штук, минут и любых других единиц.

Формат во всех полях и текстах один и тот же. Поле ввода суммы — [`InputAmount`](../InputAmount/README.md), строка без разметки — `TaigaUI.formatAmount`.

## Стили
Размер задаётся стилем текста. Подходит любой стиль из токенов, можно и свой. В Figma зашиты популярные:

| `size` | Где | Десктоп | iOS | Android |
|---|---|---|---|---|
| `numbers-xl` | карточки счёта при переводах | Numbers XL 36/40 | Numbers XL 30/36 (SF Pro Rounded 700) | Numbers XL 30/35 (Open Runde 700) |
| `numbers-m` | поля ввода суммы | Numbers M 20/24 | Numbers M 20/24 (SF Pro Rounded 700) | Numbers M 20/24 (Open Runde 700) |
| `body-l` / `ui-l` | ячейки, наборный текст | Body L 17/28 · UI L 17/24 | UI L 17/20 | UI L 16/19 |
| `body-m` / `ui-m` | ячейки, наборный текст | Body M 15/24 · UI M 15/20 | Body M 15 | Body M 14 |
| `body-s` / `ui-s` | ячейки, наборный текст | Body S 13/20 · UI S 13/16 | UI S 13 | UI S 13 |

Ещё доступны `numbers-2xl`, `heading-4`, `heading-5`, `heading-6`, `body-xl`, а также любой класс текста в `size`.

## Форматирование
Применяется автоматически, по редполитике и гайдам по тексту.
- **Дробная часть** — всегда 2 цифры (299,90), даже если в конце ноль.
  - Нулевую можно скрыть: так по умолчанию (`fraction: 'auto'`).
  - Ненулевую показываем обязательно.
  - `fraction: 'always'` — всегда показывать, `'never'` — выключить.
  - Цвет дробной части — как у целой.
- **Разделитель дробной части** — по локали: в русском интерфейсе запятая, в иноязычном точка.
- **Знаки:**
  - плюс `+` (U+002B), минус `−` (U+2212). Дефисы и тире — нельзя;
  - знак ставим без пробелов и отступов;
  - по умолчанию минус только у отрицательных. `sign: 'always'` — плюс у положительных, `'never'` — без знака.
- **Разряды** — неразрывным пробелом, по 3 цифры справа, начиная с 4 цифр: 1 000, 1 000 000.
- **Все пробелы неразрывные.**
- **Валюта:**
  - в русском интерфейсе — справа через неразрывный пробел (U+00A0): «−123,45 ₽», «−123,45 $»;
  - валюта без знака — код латиницей заглавными через неразрывный пробел: «−123,45 MXN»;
  - в иноязычном интерфейсе (`format: 'foreign'`) — знак слева без пробела: «−$123.45»; код — слева через неразрывный пробел: «−MXN 123.45».

## Кастомизация
- **Цвет** — пресеты `primary` (по умолчанию), `positive`, `negative`. Можно любой токен или цвет.
- **Пробел между суммой и единицей** — `space`. По умолчанию он есть, у `%` и `‰` — нет.
- **Знак плюса и минуса** — `sign`.
- **Знак валюты** — `currency`: любой символ или несколько символов (`'%'`, `'шт'`, `'мин'`, `'MXN'`). `null` — без единиц. По умолчанию `₽`.
- **Дробная часть** — `fraction`, число знаков — `decimals`.

## Суммы в ленте операций
Решение команды, 29.10.2026. Сумма — value у `Cell` (`right`), не обрезается.

| Операция | Знак | Цвет | Код |
|---|---|---|---|
| Поступление | «+» | зеленый | `sign: 'always', color: 'positive'` → «+72 300 ₽» |
| Списание | «−» | основной | по умолчанию → «−5 435,71 ₽» |
| Перевод между своими счетами | «−» | основной | как списание: передайте отрицательное `value` |

- Не делайте поступление без «+» или «+» без зеленого: в ленте приход отличают и по знаку, и по цвету.
- **Пробел:** отмененная операция. Правила нет, известно только, что сумму **не зачеркиваем**. Спросите у ответственного за ДС, не придумывайте.

## Иконка вместо валюты
`currencyIcon` — для продуктовых кейсов: бонусные мили, баллы. Иконки можно кастомизировать.
- Размер иконки — 0,8 от кегля на всех платформах: Numbers XL на десктопе (36) — 28, на мобилке (30) — 24. В Figma у мобильного Numbers XL иконка нарисована 28 — это перенос десктопного размера, ориентируемся на правило.
- Отступ до иконки — ширина неразрывного пробела.
- Иконка по центру высоты строки.
- На мелких размерах берём уменьшенные иконки 24 (`medium-pragmatic`), на крупных — увеличенные иконки 16 (`small-pragmatic`). Если передать имя без набора, набор выбирается сам.

## Доступность
- **Шрифт** увеличиваем до AX1 на iOS и 150 % на Android, в мобильном вебе и PWA тоже. В WebView крупный шрифт пока не прокинут (гайд по WebView), но вёрстка не должна ломаться при росте текста.
- **Озвучка** — по-человечески: «+100,90 ₽» → «плюс 100 рублей 90 копеек», «−100 $» → «минус 100 долларов США». В коде — `aria-label` для ₽, $, €, RUB, USD, EUR и %. Другие единицы читаются как есть. Для иконки подпись задаёт `iconLabel`, свою фразу — `ariaLabel`.

## API
```js
h(TaigaUI.Amount, { value: -123.45 })                                  // −123,45 ₽
h(TaigaUI.Amount, { size: 'numbers-xl', value: 1250, sign: 'always', color: 'positive' })
h(TaigaUI.Amount, { value: 12.5, currency: '%', sign: 'always' })      // +12,50%
h(TaigaUI.Amount, { value: 1250, currency: 'шт' })                      // 1 250 шт
h(TaigaUI.Amount, { value: -123.45, currency: '$', format: 'foreign' }) // −$123.45
h(TaigaUI.Amount, { size: 'body-l', value: 300, currencyIcon: 'bonus', iconLabel: 'баллов' })
TaigaUI.formatAmount(-1000, { currency: '₽', sign: 'always' })         // '−1\u00a0000\u00a0₽'
```
Пропсы:
- `value`;
- `size`, `platform`, `system`;
- `currency`, `currencyIcon`, `iconLabel`, `format` (`ru` · `foreign`);
- `sign` (`auto` · `always` · `never`);
- `fraction` (`auto` · `always` · `never`), `decimals`;
- `space`, `color`, `skeleton`, `ariaLabel`, `className`, `style`.

`formatAmount(value, opts)` и `amountParts(value, opts)` принимают те же опции. Без `currency` возвращают только число.

## Пробелы
- **Иноязычный интерфейс.** Разделитель разрядов взят тот же, неразрывный пробел. Как отбивать разряды в других локалях, в гайде не сказано.
- **Скелетон** — плашка по размеру текста. Точной высоты из спеки в материалах нет.
