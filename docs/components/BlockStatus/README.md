# BlockStatus (`tui-block-status`)

Блок статуса: пустое состояние, ошибка, результат. По гайду tui-block-status. Строится по одному лейауту на мобилке и десктопе: **иллюстрация → заголовок и текст → кнопки**. Элементы нельзя менять местами, выравнивание всегда по центру.

## Анатомия
- **Image** — необязательно. По умолчанию — иллюстрации `tui-illustrations` (`image: 'magnifier'`). Можно вставить растровую картинку любого размера, свой компонент (например, стек аватаров), поменять размер (`imageSize`) или убрать, если места мало.
- **Title** — необязателен, если есть text. **Text** — необязателен, если есть title. Весь текст скрывать нельзя.
- **Buttons** — необязательно, не больше **2**, столбиком.

## Варианты
- **Fullscreen** — в полноэкранном виде: растягивается на всю контентную область и центрируется.
- **Card** — вместо карточки или внутри неё.

## Десктоп
У fullscreen и card одинаковые отступы и размер изображения. Сверху и снизу минимум **32**.

| | **L** (по умолчанию) | **M** |
|---|---|---|
| Иллюстрация | 144 | 96 (можно 80) |
| Иллюстрация → заголовок | 32 | 24 |
| Заголовок | `heading-4` 28/32 | `heading-6` 20/24 |
| Заголовок → текст | 16 | 12 |
| Текст | `body-m` 15/24, `text-secondary` | `body-s` 13/20 |
| Текст → кнопки | 32 | 24 |
| Кнопки | L (56), через 12 | S (32), через 12 |
| Ширина текста | до 560 | до 480 |

В диалоговом окне — размер **M**.

## Мобилка (`platform="mobile"`)
| | Fullscreen | Card |
|---|---|---|
| Картинка | иллюстрация 128 | `tui-avatar` 56 (`avatarIcon` или своя картинка) |
| Картинка → заголовок | 24 | 16 |
| Заголовок | heading-s: iOS 17, Android 16 | так же |
| Заголовок → текст | 8 | 8 |
| Текст | body-m, `text-secondary`: iOS 15, Android 14 | так же |
| Текст → кнопки | 24 | одна flat — вплотную; две — 24 |
| Кнопки | M (44), через 8 | M, через 8 |
| Отступы | занимает всю высоту | 32 сверху, 20 по бокам и снизу; без кнопок снизу 32 |
| Ширина текста | до 290 | до 290 |

## Кнопки
- **Жёлтая** (primary) — когда блок на зеро-стейте или на результирующем экране. Десктоп по умолчанию: primary + flat.
- **На экранах ошибок** — лучше `secondary`.
- **Мобилка fullscreen** — `secondary`.
- **Мобилка card** — одна кнопка `flat`, две — `secondary` + `flat`.
- Стили и размеры кнопок можно менять (`actions[i].appearance`).
- **В шторке** кнопки лучше вынести в `FloatingContainer`, а в блоке оставить картинку и текст.

## Расположение
- Растягиваем на всю контентную область: у текстов уже стоят максимальные ширины.
- **Оптическая компенсация:** блок выровнен по центру вьюпорта с учётом аппбара и нижней сейф-зоны. Если блок стоит под аппбаром, передайте его высоту в `compensate` — центр сместится вверх.
- Несколько пустых секций на экране: для приоритетной — все части (картинка, заголовок, кнопки), для второстепенных — только текст.
- На мобилке компонент занимает всю высоту.

## Правила
- Заголовок, текст и иллюстрация работают на одну идею. Иллюстрация отражает контекст; для ошибок — по рекомендациям раздела «Ошибки».
- Места мало — только текст.

## Экран ожидания
По гайду ориджинейшена «Экран ожидания»: процесс на 5–60 секунд (скоринг), экран встроен в заявку.
- Раскладка — как у статуса: картинка, заголовок, подзаголовок (оба обязательны), по центру. После ожидания статус встаёт на то же место — ничего не прыгает.
- `progress` (0…1) — прогресс-бар **140 × 8** в **64** под текстом, минимальное заполнение 8, `productive-standard`. Необязателен, но с ним ждать легче.
- Значение даёт хук `TaigaUI.useWaiting({ timeout, done })` → `{ progress, finished, timedOut }`:
  - первые 40 % заполняются вдвое быстрее (тайм-аут 60 с — за 12 с вместо 24);
  - ответ пришёл раньше (`done: true`) — бар дозаполняется (`expressive-exit`, `duration-moderate`), потом `finished` — показываем статус или следующий шаг;
  - истёк `timeout` (по умолчанию 60 000 мс) — `timedOut`: статус «займёт больше времени».
- Картинка — анимация бренда (своя для физлиц и для бизнеса) в слоте `image` своим элементом; в ДС её нет, по умолчанию — статичная иллюстрация.
- Аппбар экрана — только «Закрыть», без «Назад» и прогресса шагов.

```js
var w = TaigaUI.useWaiting({ timeout: 60000, done: answered });
h(TaigaUI.BlockStatus, { image: 'card-clock', title: 'Выпускаем карту', text: 'Это займет не больше минуты', progress: w.progress })
```

## Редполитика
- **Заголовок** короткий и информативный: что произошло и почему пользователь видит этот блок. Не больше **двух строк**.
- **Позитивные формулировки:** «Начните с добавления активов данных» вместо «У вас нет никаких данных». Альтернатива — «У вас пока нет никаких данных».
- **Описание** — не больше **трёх строк**, краткая и чёткая инструкция. Нужна помощь — чат поддержки редакторов.
- Пример: «Нет доступа к разделу» / «Запросите доступ и подождите согласования. Если остались вопросы, напишите в чат» / «Запросить доступ».

Тексты типовых ошибок («Не загрузилось» / «Попробуйте снова», массовый сбой, нет интернета) — в разделе «Ошибки».

Общие правила текстов и коды — раздел «Тексты интерфейса» (`copy.md`): ошибки — ER1–ER5, пустые состояния — ER6, успех — SC1.

## API
```js
h(TaigaUI.BlockStatus, { type: 'card', size: 'l', image: 'drawer-empty', title: 'Здесь будет история выгрузок', text: 'Собирайте выгрузки, чтобы работать с ведомостью в формате xlsx', actions: [{ label: 'Собрать выгрузку' }] })
h(TaigaUI.BlockStatus, { size: 'm', kind: 'error', image: 'error-red', title: 'Не загрузилось', text: 'Попробуйте снова', actions: [{ label: 'Повторить', appearance: 'secondary' }] })
h(TaigaUI.BlockStatus, { platform: 'mobile', type: 'fullscreen', image: 'wi-fi-off', title: 'Не загрузилось', text: 'Проверьте доступ к интернету и попробуйте снова', actions: [{ label: 'Повторить' }] })
h(TaigaUI.BlockStatus, { platform: 'mobile', type: 'card', avatarIcon: 'medium-pragmatic/doc', title: 'Документы не загрузились', text: 'Попробуйте снова', actions: [{ label: 'Повторить' }] })
```
Пропсы: `type` (fullscreen · card), `size` (l · m, десктоп), `platform`, `system` (ios · android), `image` (имя иллюстрации, элемент или `false`; с `kind: 'error'` по умолчанию `error-red`), `imageSize`, `avatarIcon`, `title`, `text`, `actions` (до 2: `{ label, appearance, onClick, loading, disabled }` или элементы), `kind: 'error'` (роль alert), `compensate`, `progress` (экран ожидания, 0…1). Нужен `components/illustrations.js`.

`ListingStatus` в `FilterTable` теперь — `BlockStatus` card M.

## Пробелы
- Размеры отступов мобильного fullscreen сверху и снизу не заданы: блок центрируется по высоте.
- Размер иконки в аватаре 56 в гайде не указан: 28. Фон аватара — `background-neutral-1`.
- Анимация появления в гайде не описана.
