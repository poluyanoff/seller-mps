# PageHeader (`template-ib-header` + `tui-navigation`)

Шапка страницы личного кабинета на десктопе: навигация в две строки и заголовок страницы. Источник — Figma TUI Templates, страница «Интернет-банк / ЛК» (`[desktop] template-ib-header`), навигация — `tui-navigation` (пресеты Business и Bank).

**Любая десктопная страница ЛК начинается с `PageHeader`.** Шапку не верстаем руками: логотип, вкладки, профиль и отступ до заголовка задаёт компонент.

## Какой бренд
| `brand` | Где | Первая строка | Вторая строка | Справа |
|---|---|---|---|---|
| `business` | Т-Бизнес (юрлица и ИП) | лого «Т · Бизнес» 135×36; продукты: Счета и платежи, Бизнес, Касса, Инвестиции, Страхование ⌄ | Главное, Операции, Платежи, Выставление счета, Заказы, Настройки, Еще, ВЭД | поиск, название компании и аватар компании |
| `bank` | Т-Банк (физлица) | щит 29×34; продукты: Банк, Бизнес, Касса, Инвестиции, Сим-карта, Страхование, Путешествия, Город | Главная, Операции, Платежи, Бонусы, Заказы, Настройки, Еще | имя и аватар; во второй строке «Все продукты» с сеткой |

Бизнес-продукт — `business`, продукт для физлиц — `bank`. Пункты меню по умолчанию взяты из Figma; для своего раздела передайте `products` и `sections`.

## Построение
- **Навигация** (`tui-navigation`) — 128, фон `background-neutral-1-on-elevation-1` (как в шаблоне: днём #F6F7F8, ночью #383838 — отделяется от фона страницы), во всю ширину страницы. Две строки по 64, между ними линия `border-normal`.
- **Сетка.** L — контент 1104 по центру (экран 1360, поля 128). S — 824 (экран 1024, поля 100). По умолчанию `size="auto"`: до 1360 — S, шире — L.
- **Вкладки.** Текст 13/20 Neue Haas Unica, `text-secondary`, между вкладками 24; у логотипа и правой части отступ 32.
  - Наведение — `text-primary`.
  - Активная — `text-primary` и линия 2 снизу `text-secondary`.
  - Вкладка с выпадающим списком — шеврон 16 через 4.
  - Вкладка с иконкой — иконка 24 через 8 (`text-tertiary`).
- Если вкладки не помещаются, строка прокручивается, справа появляется фейд.
- **Правая часть**, отступ между элементами 16:
  - иконка-кнопка 32 (поиск, уведомления с точкой-сигналом);
  - профиль: имя 13/20 `text-secondary` и аватар 32 с радиусом 8. Без фото и инициалов в аватаре Fancy-иконка 20 белым на `text-tertiary`: `medium/briefcase` у `business`, `medium/user-impersonal` у `bank` (решение команды, 26.10.2026).
- **Заголовок страницы** — `tui-header` h3 (T-Sans 36/40), 64 от навигации, 32 до контента. Весь блок — 264.
  - `back` — над заголовком «‹ Назад» 13/20 `text-secondary`, 20 от навигации и 24 до заголовка; высота блока та же. Для вложенных страниц (`level=nested` в лейауте).
  - `titleAlign="center"` — заголовок по центру (статусные и подтверждающие страницы).
  - Accessories справа — через `header` (это пропсы `Header`): `button`, `action`, `badge`.
  - Переименование заголовка (свое название сущности) — тоже через `header`: `onRename`, `renameValue`, `renamePrefix`, `renameMaxLength`, `renameEmpty`. Правила — в карточке `Header`, «Переименование».
- **Третий уровень** (`tabs`) — белая полоса: «Назад», заголовок 20/24 Medium с бейджем, справа вкладки третьего уровня. Это страница продукта с собственными разделами (счёт, проект).

## Поведение
- Ссылки — `href` у пунктов. Без `href` вызывается `onNavigate({ level, item, index, label })`: level 1 — продукты, 2 — разделы, 3 — вкладки.
- Активный пункт — `activeProduct` / `activeSection` / `activeTab`: индекс или подпись. Без своих списков активны первые пункты.
- `sticky` — навигация прилипает к верху при прокрутке. Заголовок прокручивается вместе со страницей.
- В ночной теме меняются фон, линии и текст по токенам. Слово «Бизнес» в логотипе берёт `text-primary`, знак остаётся фирменным.

## Доступность
- `nav` с подписью, списки вкладок с `aria-label`, у активной вкладки `aria-current="page"`.
- У иконок-кнопок — `aria-label` («Поиск», «Уведомления»).
- Логотип — ссылка на главную с подписью.
- Заголовок страницы — `h1` (единственный на странице).

## API
```js
h(TaigaUI.PageHeader, { brand: 'business', user: { name: 'ООО «Ромашка»' }, title: 'Документы',
  header: { subtitle: 'Выписки и справки', button: { label: 'Заказать справку', appearance: 'primary' } },
  activeSection: 'Главное', onNavigate: go })
h(TaigaUI.PageHeader, { brand: 'bank', back: true, onBack: goBack, title: 'Кэшбэк', activeSection: 'Бонусы' })
h(TaigaUI.PageHeader, { brand: 'business', back: true, title: 'Счет •• 4417', badge: 'Новый', tabs: ['Обзор', 'Выписки', 'Реквизиты'] })
```
| Проп | Значения |
|---|---|
| `brand` | `business` (по умолчанию) · `bank` |
| `size` | `auto` · `l` · `s` |
| навигация | `products`, `sections` (`false` — без второй строки), `activeProduct`, `activeSection`, `sectionsAccessory` (`{ label, icon }` или `null`), `onNavigate` |
| правая часть | `search`, `onSearch`, `notifications` (`true` · `'badge'` · число), `onNotifications`, `user` (`{ name, avatar?, initials?, href? }` или `false`), `onProfile` |
| логотип | `logoHref`, `logoLabel`, `onLogo` |
| заголовок | `title`, `subtitle`, `header` (пропсы `Header`), `titleAlign`, `back` (`true` или текст), `backHref`, `onBack` |
| третий уровень | `tabs`, `activeTab`, `badge`, `titleAccessory` |
| прочее | `sticky`, `children` — блок под заголовком (фильтры, поиск) |

Пункт меню — строка или `{ label, href?, active?, dropdown?, icon?, badge?, onClick? }`.

Мобильная шапка — `NavigationBar`, таб-бар — `TabBar` (отдельные карточки).
