# ServiceBar (`tui-service-bar`)

«Сервисы» — остров на витрине мобильного приложения: до четырёх банковских сервисов в ряд. Набор и количество зависят от сегмента пользователя. Источник — гайд «[1403] Сервисы» (файл «Витрина — Корзина гайд»). Платформа — мобилка (iOS, Android, WebView).

## Построение
- **Остров:** фон `background-elevation-1`, радиус 24, тень `shadow-small`, поля 20 сверху и снизу, 8 по бокам. Ширина — во всю ширину контейнера (на витрине — экран минус 16 с каждой стороны).
- **Ряд:** сервисы через 2. Четыре сервиса заполняют остров, три, два или один — стоят по центру, ширина ячейки та же.
- **Сервис:** аватар → 8 → подпись.
  - аватар — скруглённый квадрат, радиус 16, фон `background-neutral-1`. Собран внутри компонента, не на `Avatar`: радиус 16 по гайду «Сервисы» важнее радиуса 12 у квадратного `Avatar` medium — так решили;
  - иконка — Fancy (`medium/…`) 34, цвет `background-accent-2`. Имя без набора (`phone-arrow-right`) берётся из Fancy, как во всех аватарах; если в Fancy такой нет — обычный поиск. Можно своя графика (`image`);
  - подпись — UI XS: iOS `ios-ui-xs` 12/14, Android `android-ui-xs` 12/14, `text-primary`, по центру. Остров с двухстрочной подписью — 132.
- **Последний сервис** обычно «Все сервисы» с иконкой `medium/more`.

## Подпись
- Подписи всегда в 2 строки. Перенос можно задать явно: `'Найти\nбанкомат'`.
- Edge case: одно длинное слово — одна строка с фейдом справа («Безопаснос…»).
- Больше 2 строк не бывает: лишнее уходит в фейд.

## Цвет аватара
- Базовые сервисы — фон `background-neutral-1`, иконка `background-accent-2`.
- Другие цвета согласуются с продуктом по его бренд-гайду. Правило: фон — 10 % от цвета иконки. В коде: `color` — цвет иконки, фон считается сам (10 %); `background` — свой фон (токен или цвет).

## Адаптив
Аватар и подпись растут с шириной экрана:

| Экран | Остров | Ячейка | Аватар | Иконка |
|---|---|---|---|---|
| 360 (Android small) | 328 | 76 | 56 | 34 |
| 375 | 343 | 80 | 56 | 34 |
| 430 (iPhone Pro Max) | 398 | 84 | 64 | 39 |

- Ячейка — четверть острова без полей, от 76 до 84.
- Аватар — от 56 до 64, растёт линейно на экранах от 375 до 430; иконка — вместе с аватаром.

## Нажатие
- Сервис сжимается до 0.95, 100 мс, `productive-standard` — на iOS и на Android.
- В гайде для Android — риппл со скруглением 4. В WebView рипплов нет (раздел «WebView»), поэтому нажатие как на iOS.

## Скелетон
Весь остров — плашка `service-skeleton` того же размера. Скелетон меняется на контент кросс-фейдом: скрытие скелетона и появление контента стартуют одновременно, `duration-moderate`, `productive-standard`.

## API
```js
h(TaigaUI.ServiceBar, {
  system: 'ios',                 // 'ios' (по умолчанию) или 'android'
  items: [
    { label: 'Безопасность', icon: 'medium/shield', onClick: open },
    { label: 'Найти\nбанкомат', icon: 'medium/atm' },
    { label: 'Пригласить друга', icon: 'medium/user-plus', color: '#9a5cf0' },   // фон — 10 % от цвета иконки
    { label: 'Все\nсервисы', icon: 'medium/more', href: '/services' },
  ],
  skeleton: loading,
})
```
Пропсы: `items` (до 4: `label`, `icon` — имя или элемент, `image`, `color`, `background`, `onClick`, `href`, `ariaLabel`), `system`, `skeleton`, `label` (подпись списка для озвучки), `className`, `style`.

## Пробелы
- **Длительность нажатия 100 мс** — не токен (между `duration-fastest` 75 и `duration-fast` 150). Взято как в гайде.
- **Тень** в макете 0 5 20 12 %, ближайший токен `shadow-small` — 10 %.
- **Промежуточные размеры** между 375 и 430 в гайде не заданы — считаются линейно.
- **Фон 10 % от цвета иконки** считается через `color-mix` (iOS 16.2+, Chrome 111+). На старых WebView передавайте `background` явно.
- **Десктоп** в гайде не описан.
