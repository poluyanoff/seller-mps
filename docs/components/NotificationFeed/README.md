# NotificationFeed (`tui-notification-feed`)

Лента пушей на десктопе: все уведомления в одном окне со скроллом. По Figma «TUI Web. Demo & Guides» → Notification Feed и разделу «Размеры» в Notification Push. Пункт ленты устроен как `NotificationPush`.

## Построение
Секции: закреплённые → новые → просмотренные → «Все уведомления» (необязательно). Крестик — один на ленту.

- **Контейнер:** ширина **360**, как у пуша: фон `background-elevation-2`, радиус **24**, тень `tui-shadow-medium`. Высота по контенту, но не больше **600**, дальше скролл внутри. Скроллбар — как у `Dropdown`: бегунок 4, `background-neutral-3`.
- **Пункт:** поля **24** по бокам и **20** сверху и снизу. Между пунктами нет ни отступа, ни разделителя: соседние тексты разделяет 20 + 20.
  - Внутри — как у пуша: шапка иконка 20 + «Тип • Время» → 12 → заголовок до 2 строк → 4 → текст, вместе до 4 строк → 12 → действия (`Button` S + `Button` S `flat` или одна `Link`).
  - Картинки в пункте нет.
- **Разделитель секции:** поля 24 по бокам и 6 сверху и снизу, линии `border-normal` слева и справа, по центру подпись `body-s` 13/20 `text-tertiary` через 10. Перед новыми — «Новые», если выше есть закреплённые; перед просмотренными — «Просмотренные», если выше есть закреплённые, новые или блок «Нет новых уведомлений».
- **Блок «Нет новых уведомлений»:** высота **120**, по центру иконка `bell-filled` 24 `text-tertiary` в 32 от верха → 8 → текст `body-m` 15/24 `text-secondary`.
- **«Все уведомления»:** высота **56**, кликабельна вся зона. Сверху разделитель `border-normal` с полями 16, по центру текст `ui-m` 15/20 `text-action` (наведение — `text-action-hover`).
- **Крестик:** `ButtonClose` x-small `default`, в 12 от угла ленты. Не скроллится вместе с пунктами.

## Секции
- **Закреплённые** (`status: 'pinned'`) — требуют скорейшего действия где-то вне уведомления, например предоставить документы по запросу. Всегда сверху, их может быть несколько. Пропадают, только когда действие выполнено. По нажатию ведут туда, где его выполнить; ссылку текстом показывать необязательно.
- **Новые** (`status: 'new'`, по умолчанию) — отдельная секция. После закрытия ленты отмечаются как просмотренные: продукт меняет им `status` на `seen`.
- **Просмотренные** (`status: 'seen'`).
- Нет ни закреплённых, ни новых — сверху блок «Нет новых уведомлений», под ним «Просмотренные». Уведомлений не было вообще — только блок.

## Правила
- Что показывать в ленте, настраивает продукт: например, последние 20 или за последние две недели. Показываются все: закреплённые, новые, просмотренные.
- «Все уведомления» ведёт в центр уведомлений.
- Картинка в ленте не показывается.

## Поведение
- Пункт кликабелен целиком (`onClick` у пункта), как пуш. Действия нажимаются отдельно.
- Тема ленты не зависит от темы интерфейса (`theme`), как у пуша.
- **Плавающая лента** (`floating`) — поверх страницы, в том же углу, что и пуш (решение команды): **32** справа и снизу, растёт вверх по контенту до **600**. Выше **104** от верха окна (40 под навигацией шапки 64) не поднимается.
- **Пока плавающая лента открыта, пуши не всплывают:** новое уведомление сразу появляется в ленте в «Новых» (его добавляет продукт). Показанный пуш при открытии ленты уходит — он уже есть в ленте.
- **Анимация** — как у пуша: выезжает справа (slide-in micro, `duration-moderate`, `productive-entrance`), при `open: false` уезжает вправо (slide-out micro, 200 мс, `productive-exit`).

## API
```js
h(TaigaUI.NotificationFeed, {
  floating: true, open: open,
  items: [
    { id: 1, status: 'pinned', icon: 'fixed-color/alert-negative', time: '12:56', title: 'Предоставьте документы', text: 'Банк запросил договор с перевозчиком', onClick: openRequest },
    { id: 2, status: 'new', icon: 'medium/doc', time: '12:40', title: 'Новый транспортный документ', text: 'Накладная № 4 от ООО «Лунный свет»',
      actions: [{ label: 'К документу', onClick: openDoc }], onClick: openDoc },
    { id: 3, status: 'seen', icon: 'medium/doc', time: 'Вчера', text: 'Груз по накладной № 3 доставлен' }
  ],
  all: { onClick: openCenter },
  onClose: close   // здесь новые отмечаем просмотренными
})
```
- `items` — пункты: те же поля, что у `NotificationPush`, кроме картинки, темы и крестика; `id` — ключ; `status` — `pinned` · `new` (по умолчанию) · `seen`.
- `maxHeight` — число в px или CSS, по умолчанию 600.
- `all` — `{ label, onClick, href, target }`, подпись по умолчанию «Все уведомления».
- `newLabel`, `seenLabel`, `emptyLabel` — подписи секций и пустого блока; по умолчанию «Новые», «Просмотренные», «Нет новых уведомлений».
- `floating`, `open` (по умолчанию true), `top` — выше какой отметки от верха окна лента не поднимается (по умолчанию 104), `inline` — плавающая лента внутри родителя для макетов.
- `theme`, `label` (подпись для озвучки), `onClose`, `closeLabel`.

## Отличия от Figma
- Те же, что у `NotificationPush`: `Button` S вместо кнопки 36, новые токены вместо старых, `text-action` у иконки.
- Разделители: в Figma `Base/base-04` #DDDFE0 и #D9D9D9 — в ДС `border-normal`.
- Тексты в Figma на английском (New, Seen, No new notifications, View all) — в ДС русские (решение команды).
- Скроллбар: в Figma 4 в 8 от края — взят скроллбар `Dropdown` (бегунок 4 в 4 от края).

## Пробелы
- **Боковые поля пункта** — 24, а у пуша 20. В гайде сказано, что отступы одинаковые; взяли значения из макета ленты.
- **Тёмная лента** в Figma не показана: работает на тех же токенах, что тёмный пуш.
- **Hover и pressed** у пункта — заведём отдельно, как у пуша.
- **Откуда открывается лента** (кнопка в шапке) не показано. Положение — по макету «Транспортные документы».
- На странице Notification Feed есть выключенный блок с двумя лентами и курсором — не учитываем.
