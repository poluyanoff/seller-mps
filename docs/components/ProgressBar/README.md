# ProgressBar (`tui-progress-bar`)

Линейный прогресс по гайду tui-progress-bar v1.0.2. Готов на всех платформах.

**Где использовать:** в навбарах, карточках, шагах сценария — везде, где нужно показать долю выполненного.

## Стили и размеры
- **Толщина** (`thickness`) — 12, 8 или 4. Одинаковая на десктопе, iOS и Android.
- **Трек** — `component-progress-bar`, заполнение — `status-info`. Решение команды: цвет заполнения у всех прогрессов один. В Figma у бара `background-accent-2`.
- **Форма края заполнения** (`cap`):
  - `round` (по умолчанию) — скруглённый;
  - `square` — прямой.

  У трека края скруглены всегда.

## Поведение
- **Анимация** (`animated`) — если прогресс меняется на экране: `productive-standard`, `duration-moderate`.
- **Минимальное заполнение** — заполненная часть не короче толщины бара.
- **Максимальное заполнение** — меньше 100 % → до края остаётся не меньше толщины бара.
- **Без заполнения** — при 0 бар не показывается. `showEmpty` включает пустой трек.

## Кастомизация
- `color` — цвет заполнения:
  - строка;
  - токен `tui-…`;
  - функция `(value) => color`;
  - пороги `[{ from, color }]` — динамическая смена цвета.
- `trackColor` — цвет трека.
- **Градиент** — массив цветов в `color`. Градиент растягивается на всю ширину бара, а не только на заполненную часть. На трек градиент не ставим.

## Сегменты (`segments`)
- Составной бар, число сегментов не ограничено. Каждый сегмент ведёт себя как одиночный бар.
- `value` — число заполненных шагов. Дробная часть (или `stepValue` 0…1) — прогресс внутри текущего шага.
- Между сегментами 8. С `cap: 'square'` — 2: разделитель-полоска, скругления только у краёв всего бара. Свой отступ — `segmentGap`.

## Лейблы (`labels`)
- С любой из 4 сторон в любых комбинациях: `{ topLeft, topRight, bottomLeft, bottomRight }`.
- Строка лейблов отстоит от бара на 8.
- Текст по умолчанию: UI S (iOS UI S / Android UI S), `text-primary`. Можно передать свой узел с другим стилем и цветом.
- Текст не шире бара, длинный уходит в фейд. Два лейбла в строке — каждый не шире 50 %.
- Сегментированный бар тоже может быть с лейблами.

## Доступность
- При увеличенном шрифте бар не растёт.
- По умолчанию не озвучивается (`aria-hidden`). С `label` или `ariaLabel` получает `role="progressbar"` и значения.
- Идёт загрузка — `loading` (`aria-busy`). Лейблы озвучиваются слева направо и сверху вниз.

## API
```js
h(TaigaUI.ProgressBar, { value: 48 })
h(TaigaUI.ProgressBar, { thickness: 4, value: v, animated: true, color: [{ from: 0, color: 'tui-status-negative' }, { from: 75, color: 'tui-status-positive' }] })
h(TaigaUI.ProgressBar, { segments: 6, value: 2.4, labels: { topLeft: 'Шаг 3 из 6', topRight: 'Документы' } })
h(TaigaUI.ProgressBar, { value: 30, label: 'Лимит', labels: { topLeft: '1\u00a0000\u00a0000\u00a0₽ в месяц', bottomLeft: '300\u00a0000\u00a0₽ потрачено', bottomRight: 'Осталось 700\u00a0000\u00a0₽' } })
```
Пропсы:
- `value`, `max` (по умолчанию 100);
- `thickness` — 12, 8 (по умолчанию) или 4;
- `cap` — `round` или `square`;
- `animated`, `showEmpty`, `color`, `trackColor`;
- `segments`, `stepValue`, `segmentGap`, `labels`;
- `platform`, `system`;
- `label` / `ariaLabel`, `loading`, `className`, `style`.

## Пробелы
- **Толщина по умолчанию** в гайде не задана. Взяли 8.
- **Скругления в сегментах square.** Сегменты в виде полоски в Figma нарисованы только картинкой. Скругления только у краёв всего бара — наша трактовка.
- **Десктопный стиль лейблов.** В компоненте Figma только iOS UI S. На десктопе взяли UI S 13/16.
