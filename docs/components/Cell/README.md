# Cell (`tui-cell`)

Ячейка списка: левая часть (аватар или другой компонент), текстовый блок и правая часть (значение или accessory). По гайду `tui-cell`. Связанные ячейки для шагов (`connected`) — в карточке «Cell connected».

## Построение
- **Left content** — опционально, по умолчанию аватар (`tui-avatar`); можно заменить любым компонентом (миниатюра карты, прогресс-бар) и поменять выравнивание.
- **Content**: Caption (над основным) · **Title** (обязателен) · Description; напротив них **Value** и **Value description**. Value не сочетается с accessory. В любую строку можно добавить бейджи.
- **Accessory** — правая часть ячейки с контролом или действием: тоггл, чекбокс, кнопка S, шеврон (типы — ниже). Элементы по центру, между ними **16**.

**Инициалы** (`avatarText`) — аватар `tui-avatar`: фон `neutral-4`, буквы `text-primary-on-dark`; L 40, M 32, S 24, на мобилке 40. Номера шагов в связанных ячейках (`connected`) — кружок `accent-2` / `neutral`.

**Аватар.** `avatarTone`: **`accent-icon` (по умолчанию)** — Fancy-иконка (`tui-ic-medium`, в ячейке S — `tui-ic-small`, если такая есть) цветом `tui-text-action` в нейтральном круге; `accent-2` — иконка белым в синем круге; `neutral` — серым в нейтральном. Синяя иконка в нейтральном круге — для всех списков (проекты, счета, операции, разделы): иконка выразительная, круг спокойный. **Исключение — ориджинейшены:** внутри полноэкранного `Dialog` ячейка без `avatarTone` ставит `accent-2` сама, по гайду ориджинейшена. `neutral` и `accent-2` вне ориджинейшенов — только по требованию. **Во flat-карточке** (`CardLarge appearance: 'flat'`) ячейки по умолчанию без аватара: `avatar` не передаём, если его не требуют; требуют — `avatars: true` у карточки, иначе `TaigaUI.check()` даёт `flat-avatar`. **Иконка в аватаре по умолчанию Fancy** при любом тоне: имя без набора (`briefcase`) ищется сначала в Fancy (`medium`, в ячейке S — `small`), если его там нет — в Pragmatic. В ячейке S Fancy Medium не уменьшаем: нет иконки в Fancy Small — Pragmatic Small. Имя с набором (`medium/coffee`, `medium-pragmatic/bell`) не меняется.

**Логотип банка в аватаре** — белый знак на фирменном фоне: `avatarBank: 't-bank'` или `avatar: 'medium/logo-sber'` + `avatarBackground` (токен или цвет) + `avatarColor` (по умолчанию белый `text-primary-on-accent-2`). Цвета сторонних банков передаёт продукт («вне ДС»).

**Типы** по правой части: Text (value), Switch (тоггл), Disclosure (текст + шеврон), Action (текстовое действие / ссылка), Checkbox, Button (кнопка S), Checkicon (галочка), а также бейдж-нотификация и хинт.

**Популярные комбинации** (Figma, «Превью вариантов»; карточка «Cell · варианты»). Каждый тип собирается с аватаром или без, с description или caption:
| тип | iOS / Android | Desktop L | Desktop M / S |
|---|---|---|---|
| Text | `right` + `rightDescription` | так же | так же |
| Switch — `control="toggle"` | системный тоггл: iOS 51×31 (выкл. `neutral-3`, вкл. `accent-2`, бегунок 27), Android 40×24 | 48×24, бегунок 16 | 32×16, бегунок 12 |
| Disclosure — `disclosure="Текст"` | текст `ios-ui-l` `text-secondary` + шеврон `service/chevron-right` 7×16, между ними 8 | текст `ui-m` `text-tertiary` + шеврон `small-pragmatic/chevron-right` 16, между ними 2 | текст `ui-s`, остальное как у L |
| Checkbox — `control="checkbox"` | круг 22 (на iOS и на Android) | 24, радиус 8 | 16, радиус 4 |

Десктопные тоггл и чекбокс берутся из `tui-switches`:
- **Выключен:** `neutral-2`, на ховере `neutral-2-hover`. У тоггла справа кольцо `neutral-4`: 12 у L, 8 у M/S.
- **Включён:** цвет `accent-1` (жёлтый, по умолчанию) или `accent-2` (`controlAppearance="accent"`); внутри галочка.
- **На экранах ориджинейшена** (внутри полноэкранного `Dialog`) по правилам ориджинейшена: радио, чекбокс и тоггл — синие (`accent`), у ячейки с аватаром (иконкой или инициалами `avatarText`) радио и чекбокс — справа. Задавать ничего не нужно; явные `controlAppearance` и `controlPosition` сильнее. То же для отдельных `Checkbox`, `Radio` и `Toggle`.
- **Частичный выбор** у чекбокса: `checked="indeterminate"`, иконка `indeterminate`.
- Отступ слева от правой части — 16.

## Превью продукта (`image`)
Паттерн ориджинейшена «Карточки с иллюстрацией» — разводящая страница с продуктами.
- Слева превью продукта **100 × 64**, радиус 10, вместо аватара. Это растровый рендер продукта (свой у каждого продукта, даёт продукт). `Illustration` сюда не ставим.
- Заголовок: десктоп `heading-6`, iOS `ios-heading-s-bold`, Android `android-heading-s-bold` (`system: 'android'`). Описание: `body-m` / `ios-body-s` / `android-body-s` **основным цветом**. Между ними 4.
- Заголовок и описание обязательны. Длина: на десктопе по 1 строке, на мобилке вместе до 3 строк.
- Ячейка всегда L, без контрола, value и шеврона.
- Каждый вариант — отдельная `CardLarge appearance: 'elevated'` с `onClick`, одна ячейка внутри. Отступы карточки дают нужное: десктоп 24 со всех сторон (высота 112), мобилка 20 по бокам и 20 сверху и снизу до превью (высота 104). Между карточками 24 на десктопе и 20 на мобилке.
- Пробел: превью для ночной темы в гайде нет. Фон превью — часть растра.

```js
h(TaigaUI.CardLarge, { appearance: 'elevated', onClick: pick },
  h(TaigaUI.Cell, { image: 'img/rko.png', title: 'Зарегистрировать ИП', description: 'Бесплатно и без госпошлин' }))
```

## Размеры и высота
Десктоп — 3 размера: **L** (большие и средние карточки, большие дропдауны), **M** (средние и маленькие карточки), **S** (маленькие карточки и дропдауны). Мобилка — один размер.

| режим | L: высота / отступ аватара / отступ текста | M | S | Mobile: высота / отступы |
|---|---|---|---|---|
| default | 56 / 8 / 8 | 44 / 6 / 6 | 36 / 6 / 3 | 56 / 8 |
| compact | 40 / 8 / 8 | 36 / 4 / 4 | 28 / 4 / 3 | 48 / 4 |
| spacious | 80 / 20 / 20 | 64 / 16 / 16 | 44 / 10 / 6 | 80 / 20 |

- Высота — минимальная: контент упирается в отступы, дальше ячейка растёт.
- **Compact** заметен с одной строкой без аватара (дропдауны, служебные списки). **Spacious** — большие нагруженные списки, например лента операций.
- Max-height блока accessory = высота режима (spacious — 80); минимальная высота accessory на мобилке — 40.
- Шрифты: десктоп L `ui-m` / `ui-s`, M и S `ui-s` / `ui-2xs`; мобилка `ios-ui-l` 17/20 / `ios-ui-s` 13/16, между ними 4. Аватар: L и мобилка 40 (отступ до текста 16), M 32 (12), S 24 (8).

**Какой размер ставить на десктопе.** Списки сущностей (счета, контрагенты, банки, проекты) в карточках `CardLarge` и в диалогах — **L** по умолчанию: так во всех десктопных шаблонах TUI Templates (`template-dialog-cell-list` в диалогах M и L, `template-cell-list-with-search`). M и S — только для плотных второстепенных строк; в шаблонах таких примеров нет, такое использование помечаем «вне шаблонов».

**Размер по умолчанию в коде — L** (решение команды): ячейка без `size` на десктопе — L везде, в карточке, в диалоге и вне их. M и S — только явным `size: 'm'` / `'s'`, для плотных второстепенных строк. На мобилке размер один.

## Боковые отступы (контекст)
- **Отдельно стоящие** (списки, попапы): **16**. На десктопе у неинтерактивной ячейки можно убрать (`inset="none"`).
- **Интерактивные вне карточки на десктопе** (выбор, переход, ховер) — `inset="bleed"`: отступ **12** и выход за край колонки на **12**. Аватар, текст и контрол стоят по линии контента, ховер и подсветка выбранной выступают на 12 с каждой стороны. Свой отрицательный margin не нужен. На мобилке `bleed` работает как обычная ячейка (ховера нет).
- **В карточке**: ячейки упираются в края карточки, внутренний отступ **20** на мобилке и **24** на десктопе (`inset="card"`); между ячейками +4 (задаёт карточка). В интерактивных карточках на десктопе — уменьшенный отступ (так сделано в CardLarge).
- **Внутри CardLarge `inset` не задаём**: ячейка сама узнаёт, что стоит в карточке, и встаёт по правилам cell-list (на 8 от краёв, текст по линии заголовка карточки), даже в обёртке или под кастомным блоком. `inset="none"` внутри карточки — только когда ячейка сознательно не должна тянуться к краям.
- **Внутри Dialog на десктопе `inset` не задаём** (решение команды, 25.10.2026): кликабельная ячейка (`onClick` или `control`, в том числе `disabled`) в обычном и полноэкранном `Dialog` встаёт как `bleed` сама — аватар и текст по линии заголовка, ховер и подсветка выбранной выступают на 12. Некликабельная остаётся с отступом 16; чтобы текст встал по линии заголовка — `inset="none"`. `CardLarge` внутри диалога — правила карточки, свой контент `Dropdown` — правила дропдауна, мобильный диалог — как раньше. Явный `inset` важнее.
- **В дропдауне** (десктоп): отступы уменьшены, высота compact, у ховера скругление по размеру ячейки.

## Поведение
- **Десктоп.** Интерактивные ячейки (переход или управление) — ховер на всю площадь `neutral-1`, `duration-fast`, `productive-standard`; можно скруглить. Неинтерактивные — без эффектов. Быстрые действия по ховеру (кнопки S / XS), хинт по ховеру.
- **Мобилка.** Ховера нет: в темах `ios-*` и `android-*` он выключен, даже если у ячейки не указан `platform="mobile"`. Нажатие заливает всю ячейку: iOS — алгоритм (в Figma `neutral-1`), Android — системный ripple. Хинт нажимается отдельно, ячейка при этом не подсвечивается. Свайп-действия — `tui-swipe-actions`. Тоггл и чекбокс — с хаптиком.
- **Текст.** Строки можно ограничить; одна строка — по центру, много — к верху. Обрезка: приоритет у правой части, левая не уже 30 %, дальше фейдится и правая (правила — в «Сложные лейблы и фейд»).
- **Лимит строк** (решение команды, 29.10.2026). По умолчанию заголовок, описание и value description — **до 2 строк каждый**, дальше последняя строка уходит в фейд справа. **Value (сумма) не обрезается никогда.** Фейд появляется, только когда текст не влез. Длинное название не переносим на 3–4 строки: ячейка в списке должна читаться с одного взгляда.
  - `titleLines` / `descriptionLines` меняют лимит заголовка и описания: `1` — одна строка, `0` — без лимита.
  - **Лента операций по дням** (решение команды, 30.10.2026): каждый день — своя `CardLarge`, день — ее заголовок («Сегодня», «Вчера», «28 октября»), операции дня — ячейки внутри. Заголовок над карточкой (`Header`) не ставим.
  - **Лента операций** — `titleLines: 1`, `descriptionLines: 1`: название контрагента и категория в одну строку с фейдом. В описании — категория или назначение («Супермаркеты», «Оплата по договору»), а не тип операции («Поступления», «Списания»): тип уже видно по знаку и цвету суммы (решение команды, 29.10.2026).
  - **Две строки, когда смысл не влезает в одну** — например, задачи налогового календаря: лимит по умолчанию не меняем.
  - **Value description — до 2 строк даже при `descriptionLines: 1`**: там важная информация (счет списания, карта), ее нельзя терять.
  - **Превью продукта** (`image`) — свое правило: заголовок и описание вместе до 3 строк. Лимит по умолчанию не ставится, соблюдайте длину текста.
- **Disabled**: интерактивные элементы — disabled, остальное — 50 % прозрачности.
- **Скелетон** — `skeleton`: аватар закрыт кругом его размера, заголовок, описание и value — плашками в строку (радиус 4, ширина усреднённая: заголовок 56 %, описание 36 %, своя — `skeletonWidth`). Контрол, шеврон и accessory не показываются, ячейка не нажимается. Передавайте те же `avatar`, `description`, `right`, что придут с данными, — форма скелетона совпадёт с ячейкой. Пульсация общая со всеми скелетонами экрана. Гайда скелетона ячейки нет — сделано по разделу «Загрузка».
- **Чувствительный режим** — маска на любой текстовой строке.
- Анимация появления элементов и смены текста — `duration-fast`, `productive-standard`.

## Выбор в ячейке
| | Десктоп | Мобилка |
|---|---|---|
| `control="radio"` | радио слева (24 у L, 16 у M и S; выбранное — `accent-1` с точкой), выбранная ячейка подсвечена `neutral-1` | круг 22 справа: iOS — выбранный `accent-2` с белой галочкой; Android — кольцо и точка `accent-2` |
| `control="checkbox"` | чекбокс справа (24 радиус 8, у M и S — 16 радиус 4), выбранный — `accent-1` | тот же круг 22 справа (системный чекбокс iOS) |
| `control="check"` | галочка `text-action` у выбранного | то же |
| `control="toggle"` | тоггл справа (L 48×24, M/S 32×16) | системный тоггл iOS 51×31 |

Ячейка с контролом получает роль radio / checkbox / switch и управляется клавишами Enter и пробел. Контролы — те же, что в разделе «Чекбоксы, радиокнопки, тогглы»: мобильная система задаётся `system` (`ios` · `ios26` · `android`) или темой `android-*`, ошибка — `controlError`.

## API в коде
```js
h(TaigaUI.Cell, { size: 'l', title: 'Дебетовая карта', description: 'Black · •• 4417', avatar: 'cards', right: '12\u00a0500\u00a0₽', rightDescription: 'Доступно', onClick: open })
h(TaigaUI.Cell, { platform: 'mobile', title: 'Да', control: 'radio', checked: true, onClick: pick })
h(TaigaUI.Cell, { size: 'm', title: 'Уведомления', avatar: 'bell', control: 'toggle', checked: on, onClick: flip })
h(TaigaUI.Cell, { platform: 'mobile', title: 'Лимиты', disclosure: 'Настроить', onClick: open })
h(TaigaUI.Cell, { size: 'l', title: 'ЖК Северный', description: 'Смета 7,2 млн ₽', avatar: 'briefcase', avatarTone: 'accent-icon', right: '3\u00a0840\u00a0000\u00a0₽', onClick: open })
h(TaigaUI.Cell, { platform: 'mobile', height: 'spacious', title: 'Кофейня', description: 'Рестораны', avatar: 'medium/coffee', right: '−320\u00a0₽' })
```
Пропсы: `size` (l · m · s), `platform`, `height` (default · compact · spacious), `inset` (card · none · bleed), `caption`, `title`, `description`, `right` (value) + `rightTone`, `rightDescription`, `avatar` (без него аватара нет) + `avatarTone` (accent-icon — по умолчанию · accent-2 · neutral), `image` + `imageAlt` (превью продукта 100 × 64), `accessory`, `disclosure`, `control` + `checked` + `controlPosition` + `controlAppearance` + `highlight`, `disabled`, `onClick`.
