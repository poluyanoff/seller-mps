# ImageViewer — просмотр изображений

Полноэкранный просмотр картинок: образцы документов по ссылке «Посмотреть образцы», превью загруженных фото. Собран по макетам «Origination → Паспортные данные → Фото или сканы паспорта → Нажали «Посмотреть образцы»».

## Построение
- **Фон** — затемнение `service-backdrop` с размытием 32, картинка по центру, вписана в экран с полями 64 (мобилка — 64 сверху и снизу, 16 по бокам).
- **Плашки управления** — высота 32, радиус 30, фон `background-neutral-1-on-dark`, текст Body S 13 и иконки 16 `text-primary-on-dark`. От краёв 16.
  - **десктоп:** имя файла слева сверху, навигация «‹ 1 / 2 ›» по центру сверху, крестик 32 справа сверху, масштаб «+ / −» справа по центру;
  - **мобилка:** навигация слева сверху, крестик справа сверху, масштаб справа по центру, без имени файла.
- Одна картинка — без навигации.

## Поведение
- Закрытие: крестик, Esc, клик по фону.
- Навигация: стрелки на плашке и ← / → на клавиатуре, по кругу.
- Масштаб от 1 до 3 с шагом 0.5; увеличенную картинку можно двигать. При смене картинки масштаб сбрасывается.
- Появление — прозрачность, `duration-fast`.

## API
```js
h(TaigaUI.ImageViewer, { open, onClose: close, items: [{ src: spread, name: 'Пример разворота.jpg' }, { src: reg, name: 'Пример регистрации.jpg' }] })
```
Пропсы: `open`, `onClose`, `items` (`{ src, name, alt }`), `index` / `defaultIndex` / `onIndexChange`, `zoom={false}` — без масштаба, `platform`, `label`, `closeLabel`, `inline`, `container`, `className`.

## Пробелы
- **Цвета в макете без токенов.** Фон глухой серый, плашки `#686868` 96 % из старой библиотеки. Взяли ближайшие токены: `service-backdrop` с размытием и `background-neutral-1-on-dark`.
- **Анимации** появления, листания и масштаба в макетах нет: появление — `duration-fast`, остальное без анимации.
- **Свайп** между картинками на мобилке не описан и не собран.
