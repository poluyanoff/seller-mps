# Chip и ChipGroup (`tui-chip`, `tui-chip-group`)

Чип — параметр, тег или вариант выбора; группа чипов показывает список тегов или даёт выбрать один или несколько вариантов. Источники — гайды `tui-chip` (v1.3.4, отдельный чип, готов на всех платформах) и `tui-chip-group` (v1.0.3).

## Размеры
Размеры и контент фиксированные. Ширина по контенту, но её можно зафиксировать (`width`): контент встаёт по центру, длинный текст уходит в фейд.

| | высота | поле | у текста ещё | текст | радиус square | иконка | картинка |
|---|---|---|---|---|---|---|---|
| Desktop medium | 44 | 10 | 6 | `UI M` | 8 | 24 | 24 |
| Desktop small | 32 | 8, с картинкой 4 | 2 | `UI S` | 8 | 16 | 24 |
| Desktop x-small | 24 | 4 | 2 | `UI S` | 4 | 16 | нет |
| Desktop xx-small | 16 | 2 | 2 | `UI XS` | 4 | 12 | нет |
| Mobile medium | 36 | 10, с картинкой 6 | 4 | `UI S Bold` (iOS, Android) | пилюля | 16 | 24 |
| Mobile small | 30 | 7, с картинкой 3 | 4 | `UI S Bold` | пилюля | 16 | 24 |

- Размеры меньше small используются внутри других компонентов, например в полях ввода.
- На десктопе две формы: `square` (по умолчанию) и `rounded` (пилюля). Форма задаётся на всю группу. На мобилке чип всегда пилюля.
- Внутри группы все чипы одного размера и формы.

## Состав
- **Слева** — иконка или картинка (аватар 24, круглая или квадратная — `imageShape`).
- **Только иконка** (сортировка, все фильтры): текст не передаём, подпись для скринридера — `ariaLabel` (в `ChipGroup` — `ariaLabel` у пункта). Пустая строка в `label` считается отсутствием текста, поля под лейбл не появляются. Чип без `ariaLabel` `TaigaUI.check()` отмечает как `label`.
- **Текст**, можно **два лейбла** (`secondLabel`) через 4 во всех размерах. Приоритет у правого. Левый сжимается первым, но не меньше 30 % ширины; дальше в фейд уходят оба.
- **Бейдж** (`badge`) — всегда после текста, без текста не используется. Например, число выбранного в фильтре. Справа дополнительное поле: 4 на десктопе, 2 на мобилке. Стиль бейджа можно менять (`badgeAppearance`); по умолчанию на десктопе `dark-text`, на мобилке `light-text`.
- **Справа:**
  - `onClose` — крестик с отдельным действием, например удалить. Область нажатия больше иконки. На десктопе есть наведение и нажатие, на мобилке нажатие визуально не показываем;
  - `dropdown` — стрелка выпадашки;
  - `iconRight` — своя иконка.
  - Отступ от контента до правой иконки одинаковый для любой иконки.
- **Иконки:** на десктопе `text-tertiary`, на мобилке и в `accent` — цвет текста.

## Апиренсы и состояния
- **`neutral`** — для обычных фонов: фон `neutral-1`, наведение `neutral-1-hover`, нажатие `neutral-1-pressed`.
- **`accent`** — в группе или самостоятельно, когда нужно усилить акцент на выборе: фон `accent-2`, текст `text-primary-on-dark`, наведение и нажатие `accent-2-hover` / `-pressed`.
- **`floating`** — для пёстрого фона, например карты: `elevation-1` с тенью `shadow-small`; наведение — `shadow-small-hover`, нажатие — фон `neutral-1-opaque`.
- **`whiteblock`** — фон `base`, обводка `border-normal`, наведение `neutral-1-opaque`. Только десктоп.
- **`whiteblock-selected`** — обводка 2 `border-selected`, наведение `neutral-1-opaque`. В паре с `whiteblock`, только десктоп.
- **Наведение** — только на десктопе (десктопная тема и мышь). В темах `ios-*` и `android-*` его нет, даже без `platform="mobile"`; остаётся нажатие. На iOS цвет нажатия — токен `-pressed`. На Android в нативе риппл, в вебе и WebView — как на iOS, токен `-pressed`.
- **Выбор (selected)** — это смена апиренса: `neutral` → `accent`, `whiteblock` → `whiteblock-selected`.
- **Чип с дропдауном** (`dropdown`, например «Период» с календарём): `selected` — когда значение отличается от умолчания, а не пока открыт дропдаун. Подробно — «Фильтры → Чипсы на выдаче».
- **Disabled** — прозрачность 50 % на всех платформах. Так решила команда: в гайде tui-chip на мобилке вместо этого текст `text-tertiary`.
- **Фокус** с клавиатуры — только десктоп: обводка 2 `border-focus`. Где её не видно — `border-focus-on-dark`.
- **Неинтерактивный чип** (без `onClick`): на десктопе текст можно выделить и скопировать, курсор текстовый; на мобилке ничего не происходит. Для неинтерактивных меток лучше `Badge`: чип задуман интерактивным.
- **Скелетон** — `skeleton`. Ширину подбираем по правилам tui-skeleton.
- В одной группе чипы могут быть разных апиренсов, например категории трат с суммами.

## Анимация
- **Смена апиренса** — fade, `productive-standard`, `duration-fast` (150 мс). Нажатие — без анимации (0 мс).
- **Появление:** scale 0.9 → 1, opacity 0 → 1, `productive-entrance`, `duration-moderate`.
- **Скрытие:** scale 1 → 0.9, opacity → 0, `productive-standard`, `duration-fast` (класс `tui-chip--disappear`).
- **Перемещение в группе.** При появлении нового чипа тот, что не поместился, уходит по диагонали в начало следующего ряда (`productive-entrance`, `moderate`). При скрытии — в обратном порядке (`productive-exit`, `fast`).
- **Нажатие уменьшением** (`pressEffect: 'scale'`) — вместо смены заливки scale 0.95, `duration-fast`, `productive-standard`.

## Кастомизация
- Цвета фона, текста, иконок и бейджа (`background`, `color`, `badgeAppearance`). Наведение и нажатие тогда задаём вручную.
- Начертание текста.
- Форма картинки.
- Максимальная длина (`maxWidth`) — дальше фейд.
- Бейдж-индикатор поверх чипа — через `BadgedContent`.

## Группа
**Лейаут:**
- **Мобилка, горизонтальный** — один ряд, между чипами 8. Не помещается — горизонтальный скролл. Поля 16 ряд несет сам (решение команды, 29.10.2026): первый чип на 16 от края экрана, при прокрутке чипы уходят в край. Обертку с `padding` вокруг не ставим; в стопке `PageLayout`, мобильном `Dialog` и шторке поля экрана компенсируются сами, в карточке — правила карточки.
- **Мобилка, вертикальный** — несколько рядов, отступы 8 по горизонтали и вертикали, можно выровнять по центру.
- **Десктоп** — несколько рядов, отступы 4.
- **Ширина чипа:** по умолчанию максимум 300 (можно менять), длинный текст уходит в фейд, не помещается в строку — переносим. Длинные лейблы не рекомендуются. В фильтрах ширина своя, 184 — см. «Фильтры и сортировка».

**Типы:**
- **Список (list)** — параметры, теги, связанные элементы; чипы кликабельные или нет.
  - Если чипов много, часть прячется за чипом **«Ещё N»** с шевроном справа (по умолчанию видно 2 строки).
  - Список только разворачивается, обратно не сворачивается.
  - Появление — scale 0.9 → 1 и opacity, `productive-entrance`, `moderate`; скрытие — `productive-exit`, `fast`.
- **Единичный выбор (single)** — заранее выбран один вариант или ни одного. Выбор другого снимает предыдущий; повторное нажатие выбор не снимает.
- **Множественный выбор (multiple)** — предвыбора нет; повторное нажатие снимает выбор.
- **Авто-скролл (мобилка):**
  - нажали на чип у правого края или частично скрытый — ряд сдвигается, чтобы чип оказался посередине экрана;
  - последний чип прижимается к правому краю;
  - анимация `productive-standard`, `fast`.

## Правила
- **Не используем чипы для навигации** — для неё `tui-segmented`. **И вместо кнопок** — для действий `tui-button` S.
- **Текст** — коротко, 1–2 слова: «Популярные товары», а не «Категория: популярные товары».
- **Даты** — общепринятые сокращения и среднее тире: «17 апр – 17 мая».
- **Отступы в мобильных макетах:**
  - в Figma у группы 8 сверху и снизу;
  - после поля поиска — 20;
  - в параметрах фильтра от названия параметра 8, до следующей группы 16;
  - в карточке до заголовка 16, по бокам 20.

## Доступность
- **Крупный шрифт:** до AX1 на iOS и 150 % на Android. Чипы растут по своим правилам; горизонтальный лейаут не меняется, вертикальный переносит чипы. С кнопкой «Ещё» число строк остаётся тем же.
- **Озвучка отдельного чипа:**
  - интерактивный чип — «Лейбл, Кнопка» + подсказка по кейсу;
  - с суммой — «Медицина, 5 962 рублей, Кнопка»;
  - без текста лейбл задаём в коде («Добавить фильтр»);
  - с крестиком — доп. действие «очистить выбор»;
  - выбираемый — на iOS «Флажок, Выбрано / Не выбрано»;
  - неинтерактивный — просто текст.
- **Озвучка:**
  - группа — список, можно задать название, оно звучит при первом фокусе;
  - каждый чип: «Label, 2 из 6»;
  - неинтерактивный чип — просто текст;
  - интерактивная группа — трейт «Элемент регулировки»;
  - у «Ещё» своя подпись («Показать еще 5 элементов»).
- В коде:
  - single — `radiogroup` и `radio` с `aria-checked`;
  - multiple — `group` и кнопки с `aria-pressed`;
  - list — `list` и `listitem`.

## API в коде
```js
h(TaigaUI.Chip, { size: 's', icon: 'small-pragmatic/star', onClick: fn }, 'Избранное')
h(TaigaUI.Chip, { size: 's', appearance: 'whiteblock', selected: true, onClick: fn }, 'Выбран')
h(TaigaUI.Chip, { size: 's', badge: 2, dropdown: true, onClick: fn }, 'Категории')
h(TaigaUI.Chip, { size: 's', onClick: fn, onClose: remove }, '3–13 апр')
h(TaigaUI.Chip, { size: 's', secondLabel: '5\u00a0962\u00a0₽', maxWidth: 200, onClick: fn }, 'Медицина')
h(TaigaUI.ChipGroup, { size: 's', items: tags, label: 'Удобства' })                         // список, «Ещё N» после 2 строк
h(TaigaUI.ChipGroup, { platform: 'mobile', mode: 'single', defaultValue: 0, items: ['Кино', 'Театры'] })
h(TaigaUI.ChipGroup, { size: 's', mode: 'multiple', value: v, onChange: setV, items: options })
```
Пропсы:
- `Chip`:
  - `size` (m · s · xs · xxs), `platform`, `system`, `appearance` (neutral · accent · whiteblock · whiteblock-selected · floating), `shape` (square · rounded);
  - `selected`, `disabled`, `skeleton`, `interactive`;
  - `icon`, `image`, `imageShape`, `iconRight`, `dropdown`, `onClose`, `closeLabel`, `badge`, `badgeAppearance`, `secondLabel`;
  - `maxWidth`, `width`, `pressEffect: 'scale'`, `background`, `color`, `onClick`, `children` / `label`.
- `ChipGroup`: `items` (строки или `{label, value, icon, iconRight, appearance, disabled, onClick}`), `mode` (list · single · multiple), `value` / `defaultValue` / `onChange`, `layout` (wrap · scroll; на мобилке по умолчанию scroll), `align` (center), `maxRows` (0 — без «Ещё»), `moreText`, `label`, `maxChipWidth`, а также `size`, `shape`, `appearance`, `platform`.

## Пробелы
- Скейл иконки при увеличенных шрифтах (×1.25 в AX1 / 150 %) не собран.
- Sensitive mode (пиксельная маска на тексте) не собран.
- Радиус квадратной картинки (6) подобран по макету.
