# ChatHints (`hints-list`)

Подсказки-ответы над панелью ввода чата: «Переводы», «Кэшбэк», «Позвать специалиста». Нажатие отправляет подсказку как сообщение или открывает сценарий. По Figma «TMSG. Library» → hints. Обычно передаются в [`ChatInput`](../ChatInput/README.md) через `hints`, отдельно — когда подсказки стоят не над панелью.

## Построение
Ряд с переносом, прижат вправо (к исходящим), между подсказками 8.
- Мобилка: поля 12. Подсказка — обводка 1,25 `text-action`, радиус 12, поля 12 / 8, текст Body L `text-action`; нажатие — подложка `background-neutral-1`.
- Десктоп: поля 10 по бокам, 12 сверху, 4 снизу. Подсказка — высота от 32, поля 10 / 8, обводка 1 `text-action`, радиус 8, текст UI S `text-action`; наведение — фон `background-neutral-1`.

## Тексты
Короткая фраза от лица пользователя, 1–3 слова, без точки: «Кредит наличными», «Позвать специалиста».

## API
```js
h(TaigaUI.ChatHints, { platform: 'mobile', items: ['Переводы', 'Кэшбэк', 'Лимиты'], onSelect: function (item, index) { … } })
```
- `items` — строки или `{ label, onClick }`, `onSelect`, `platform`, `system`, `ariaLabel`, `className`, `style`.

## Состояния
- **Загрузка** — `loading`: вместо подсказок плашки скелетона той же высоты, без обводки, фон `service-skeleton` (TMSG hint / Loading). Число — сколько плашек, по умолчанию три.
- **Назад** — обычная подсказка с текстом «⬅️ Назад» (так в TMSG), отдельного вида нет.

## Пробелы
- Подложка нажатия на мобилке в TMSG не показана — взяли `background-neutral-1`.
