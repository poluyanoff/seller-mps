# Textarea (`tui-textarea` / `tui-textfield [multiline]`)

Многострочное поле. Наследует `Input`: размеры L / M / S и мобильный, лейбл, подсказки, ошибка, disabled, read-only. Правила — в разделе «Формы и поля ввода».

## Высота
- **Авторост** на одну строку — по умолчанию; на мобилке единственный режим. `rows` — минимум строк (десктоп по умолчанию 3, мобилка 1).
- **Максимальная высота** (`maxRows`) или **фиксированная** (`height`) — только десктоп: дальше скролл внутри текста, лейбл и счётчик на месте. Скролла лучше избегать: высоту подбираем так, чтобы последняя строка не обрезалась.
- **Ручной ресайз** (`resize: 'vertical' | 'both'`) — только десктоп.

## Счётчик
- `maxLength` + `counter`: внутри поля справа снизу (десктоп, справочно) или `counter: 'outside'` — под полем, когда лимит влияет на результат. На мобилке всегда под полем.
- По умолчанию сверх лимита вводить можно: поле в ошибке «Максимум N символов — нужно удалить K», счётчик красный, лишние символы в тексте — `text-negative`. `limitInput` — запретить ввод сверх лимита.
- Счётчик и ресайз вместе — счётчик выносим наружу.
- Лимит задаём так, чтобы большинство его не заметило.

## Правила
- Справа — одна иконка: крестик по умолчанию выключен (`cleaner` — включить).
- Мобилка: accessories выровнены по центру, область нажатия по высоте 56.

## API
```js
h(TaigaUI.Textarea, { label: 'Комментарий', size: 'l', maxLength: 300, counter: true, hint: 'Увидит только получатель' })
h(TaigaUI.Textarea, { label: 'Описание', size: 'm', maxRows: 6, resize: 'vertical' })
h(TaigaUI.Textarea, { platform: 'mobile', label: 'Комментарий к переводу', maxLength: 140, counter: true })
```

## Пробелы
- Отступ счётчика внутри поля и положение иконки справа у многострочного поля в гайде не размечены: счётчик — `ui-2xs` под текстом справа, иконка — у первой строки.
