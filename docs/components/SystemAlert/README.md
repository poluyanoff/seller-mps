# SystemAlert

Имитация системного алерта iOS и Android для мобильных прототипов. В WebView подтверждения и ошибки, где нужно действие пользователя, — нативные системные алерты (`webview.md`), а шторки в модальном WebView не используем. Чтобы прототип выглядел как живой экран, рисуем алерт этим компонентом (решение команды, 29.10.2026).

- **Только для прототипов.** В коде продукта для WebView — нативный алерт платформы, не этот компонент.
- **Вид — по гайдам платформ** (Apple HIG, Material 3): в Figma TUI системного алерта нет, цвета системные, не токены ДС. Тема ночи — по `data-theme` `*-night`.
- **Когда:** подтверждение выхода из заявки с заполненными шагами (`origination.md`), подтверждение необратимого действия, ошибка, после которой нужно действие. Десктоп и PWA — `Dialog`.
- **iOS:** ширина 270, радиус 14, заголовок 17 Semibold, текст 13. Две кнопки — в ряд, три и больше — столбиком. `cancel` — жирная, `destructive` — красная.
- **Android:** Material 3: радиус 28, поля 24, заголовок 24, текст 14, текстовые кнопки справа.
- **Где открывается:** портал в рамку прототипа (`[data-tui-portal]`, есть в мобильном стартере), иначе в `body`. `inline` — на месте.
- **Тексты** — по `copy.md`: заголовок — вопрос или факт («Выйти из заявки?»), кнопки — глаголом, отмена — «Отмена».

```js
h(TaigaUI.SystemAlert, { open: ask, system: 'ios', title: 'Выйти из заявки?', message: 'Введенные данные не сохранятся',
  actions: [{ label: 'Отмена', style: 'cancel' }, { label: 'Выйти', style: 'destructive', onClick: exit }],
  onClose: function () { setAsk(false); } })
```

Пропсы: `open`, `system` (ios · android), `title`, `message`, `actions` (`label`, `style`: default · cancel · destructive, `onClick`), `onClose`, `inline`, `container`, `className`.
