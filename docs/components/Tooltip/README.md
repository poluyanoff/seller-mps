# Tooltip (`tui-tooltip`)

Короткая подсказка с «хвостом», указывающим на триггер. Источник — гайд `tui-tooltip` (v1.3.1); спецификации у мобилки и десктопа разные. Готов на всех платформах.

**Когда:** назначение элемента неочевидно, а исправить это нельзя: кнопка без подписи, заблокированный элемент. Текст — короткое пояснение на пару предложений, без списков. Не сокращается — даём ссылку на страницу, попап или шторку.

## Стили (`appearance`)
- `default` — фон `tui-component-tooltip`, текст `text-primary-on-opposite`. На десктопе днём тёмный, ночью светлый; на iOS токен синий.
- `floating` — фон `elevation-3`, текст `text-primary`, тень `shadow-small`. Днём белый, ночью тёмно-серый.

## Построение
| | Десктоп | Мобилка (iOS / Android) |
|---|---|---|
| отступы | 12 / 16 | 12 / 16 |
| радиус | 12 | 8 |
| текст | `Body S` 13/20 | `Body M` (iOS 15, Android 14) |
| хвост | 12×4, от края минимум 16 (у floating 8) | 24×8, от края минимум 9 |
| иконка слева (опц.) | 16, отступ до текста 8 | 20 |
| кнопка (опц.) | S `glass-on-dark` под текстом, между ними 8 | S, между ними 12 |
| макс. ширина | 300 | ширина экрана − 32, но не больше 400 |

- Ширина по умолчанию — по контенту до максимума. Строки можно переносить вручную или фиксировать ширину.
- В контент можно вставлять ссылки. На десктопе допустима сложная вёрстка.

## Хвост
- `position` — сторона, с которой хвост, как в Figma; 12 вариантов: `top-left`, `top`, `top-right`, `right-top`, `right`, `right-bottom`, `bottom-right`, `bottom`, `bottom-left`, `left-bottom`, `left`, `left-top`. Пример: `bottom` — хвост снизу по центру, тултип над триггером.
- Хвост стоит по центру или на минимальном расстоянии от края.
- Положение можно задать вручную (`tailOffset`) или вести за триггером («умное» позиционирование, так работает `TooltipHost`).
- Отступ до контента в хвост уже вшит, поэтому тултип с хвостом ставим вплотную. Без хвоста отступ 8.

## Расположение
- По умолчанию сверху от триггера, если нет места — снизу.
- Десктоп: отступ до триггера 4.
- От краёв вьюпорта минимум 8: тултип не упирается в край экрана.

## Поведение
**Десктоп:**
- появляется при наведении, нажатии или фокусе по Tab;
- скрывается при потере ховера или фокуса и через 100 ms после начала скролла;
- при наведении на сам тултип не скрывается.

**Мобилка:**
- появляется по нажатию на триггер (обычно кнопка хинта);
- скрывается по повторному нажатию, по тапу вне тултипа и через 100 ms после начала скролла;
- сам тултип на нажатие не реагирует.

**Онбординг:** тултип может появиться сам после загрузки экрана.
Подсказка с заголовком, картинкой и кнопками — `PopoverCard` (раздел «Обучение пользователя»).

**Анимация:**
- появление — opacity 0→1, scale 0.5→1, `duration-moderate`, `expressive-standard`;
- скрытие — обратно за `duration-fast` (на мобилке `expressive-exit`);
- можно отключить (`animated: false`), если тултипы быстро сменяют друг друга, например в графиках.

## Тексты
- В тултипе только второстепенное пояснение. То, без чего пользователь не решит задачу, — в тексте экрана, не в тултипе.
- Коротко, без последней точки. Общие правила текстов и коды — раздел «Тексты интерфейса» (`copy.md`): TT1, PR4.

## Доступность
- **Крупный шрифт:** до AX1 на iOS и 150 % на Android. Отступы не меняются, вложенные компоненты — по своим правилам.
- **Озвучка:**
  - Тултип не фокусируется отдельно. В родительском компоненте — дополнительное действие «Открыть подсказку», после него фокус переходит на тултип.
  - Закрытие — двойной тап или жест Z, фокус возвращается на родителя; в коде это настраивается вручную.
  - Кнопки и ссылки тултипа уходят в дополнительные действия.
  - Тултип, который появился сам, не озвучивается. Важную информацию передаём через родителя (например, в value).
- В коде у триггера `aria-describedby`, у тултипа `role="tooltip"`.

## API в коде
```js
// пузырь сам по себе
h(TaigaUI.Tooltip, { position: 'bottom-left', icon: 'small-pragmatic/sparkle', action: { label: 'Понятно', onClick: ok } }, 'Новый раздел')
// триггер + поведение: десктоп — hover / focus, мобилка — tap; сверху, нет места — снизу; хвост указывает на центр триггера
h(TaigaUI.TooltipHost, { content: 'Покупка произойдет по лучшей доступной цене' }, hintButton)
h(TaigaUI.TooltipHost, { platform: 'mobile', content: 'Понадобится для перевода' }, hintButton)
```
Пропсы:
- `Tooltip`: `position`, `appearance` (default · floating), `platform`, `system`, `icon`, `action` (`{label, onClick, appearance}` или элемент), `text` / `children`, `width`, `maxWidth`, `tailOffset`, `tail` (false — без хвоста).
- `TooltipHost`: `content`, `side` (top · bottom), `open` / `defaultOpen` / `onOpenChange`, `animated`, а также `platform`, `appearance`, `icon`, `action`, `width`, `maxWidth`.

Интерактивное содержимое (например, CopyTooltip) использует `role: 'dialog'` и `label` для доступного имени. По умолчанию роль остаётся `tooltip`.
