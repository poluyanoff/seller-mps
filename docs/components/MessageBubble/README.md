# MessageBubble (`tui-message-bubble`)

Баббл инлайнового комментария или сообщения: комментарий к переводу в ленте операций, реплика в переписке. По гайду Figma `tui-message-bubble` v1.0.1.

## Вид (`appearance`)
| вид | фон | текст | где |
|---|---|---|---|
| `accent` (по умолчанию) | `background-accent-2` | `text-primary-on-dark` | исходящие сообщения |
| `neutral-1` | `background-neutral-1` | `text-primary` | входящие сообщения |

## Построение
Одинаково на всех платформах и во всех вариантах:
- поля 10 по бокам, 8 сверху и снизу;
- радиус 14;
- минимальная высота 36.

Текст: десктоп — UI M (`tui-ui-m`), мобилка — Body L (`tui-ios-body-l` / `tui-android-body-l`, `system`). В любой позиции текст выровнен по левому краю.

## Позиция (`position`)
- `left` (по умолчанию) — прижат к левому краю, справа поле 16.
- `right` — прижат к правому краю, слева поле 16.

Вместе с полем экрана 16 получается 16 от «своего» края и 32 от противоположного, как в гайде. Свои поля вокруг баббла не добавляй.

## Ширина и строки
- По умолчанию ширина по контенту, длинный текст переносится на сколько угодно строк.
- `maxWidth` — максимальная ширина. Текст встаёт в одну строку, хвост уходит в фейд.
- `lines: 1` — одна строка с фейдом на всю доступную ширину.

## Ссылка в тексте
Внутрь можно поставить `Link`: цвет ссылки берётся из текста баббла, ссылка подчёркнута.
```js
h(TaigaUI.MessageBubble, null, 'Все актуальные гайды в этом ', h(TaigaUI.Link, { href: '#' }, 'проекте'))
```

## Свой цвет
`background` и `color` — имя токена без `--tui-` или `var(...)`. Только токены, никаких `#hex`.
```js
h(TaigaUI.MessageBubble, { background: 'status-positive', color: 'text-primary' }, 'А я цветной')
```

## API
```js
h(TaigaUI.MessageBubble, { appearance: 'neutral-1' }, 'Ни в чем себе не отказывай')
h(TaigaUI.MessageBubble, { platform: 'mobile', position: 'right' }, 'За скайрим')
```
- `appearance`, `position`, `platform` (`desktop` / `mobile`), `system` (`ios` / `android`), `children` / `text`, `maxWidth`, `lines`, `background`, `color`, `className`, `style`.

## Примеры использования
Внутри ячеек: под `Cell` операции с комментарием. Входящий комментарий — `neutral-1`, `left`; исходящий — `accent`, `right`. Баббл ставь под ячейкой и выравнивай по тексту ячейки, а не по аватару.

## Доступность
- Увеличенные шрифты: правила нативных платформ действуют и в мобильном вебе. iOS — до AX1, Android — до 150 %. Баббл растёт вместе с текстом; при `lines: 1` текст остаётся в одну строку с фейдом.
- Озвучка: баббл отдельно не фокусируется. Текст озвучивается в строке родительского компонента (например, `Cell`).

## Пробелы
- Радиус: в тексте гайда «одинаковые на всех платформах» и выноска 14, но у десктопного варианта в Figma-компоненте радиус 12. Взяли 14.
- Межстрочный интервал на мобилке: в Figma строка `normal` (около 20), а Body L в ДС — 24. Взяли 20, чтобы однострочный баббл был 36.
- Отступ между бабблами и от баббла до ячейки в гайде не задан.
- Ночная тема в гайде не показана: цвета берутся из токенов темы.
- Состояний (hover, pressed, выделение) у баббла нет: он не интерактивный.
- В гайде отмечено «Компонент разработан не везде»: на каких платформах есть в коде продукта, проверяйте перед использованием.
