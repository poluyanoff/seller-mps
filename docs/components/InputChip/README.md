# InputChip (`tui-input-chip`)

Поле с чипами — только десктоп. Наследует `Input` (L / M / S, подсказки, ошибка). Правила — в разделе «Формы и поля ввода».

- **Лейбл — только снаружи.**
- **Создание чипа:** Enter или разделитель (`separators`, по умолчанию запятая; можно пробел, точку с запятой, свой символ). Вставка текста с разделителями создаёт несколько чипов. Маска — `mask(value)`.
- **Редактирование:** двойной клик по чипу, Enter — сохранить, Esc — отменить. Пустой — чип удаляется.
- **Переполнение:** поле растёт по высоте. Фиксированную высоту не используем — чипы обрезаются.
- **Длинный чип:** до 32 символов (`maxChipLength`), дальше многоточие, полный текст в тултипе.
- **Ошибки:** общая (`error` — поле красное, текст снизу) или на конкретном чипе (`validate(value) → текст ошибки`: чип красный, текст в тултипе).
- **Клавиатура:** Enter — сохранить чип или редактировать выбранный; Backspace — выбрать последний чип, второй раз — удалить; ← / → — переход между чипами; Esc — отмена.
- **Мультиселект** (`items`): шеврон и список с чекбоксами (`DropdownList`, через 4 от поля, до 400), выбранное — чипами. `allowCustom` — разрешить свои значения.

## API
```js
h(TaigaUI.InputChip, { label: 'Получатели', value, onChange, separators: [',', ';', ' '], placeholder: 'Почта через запятую', validate: function (v) { return /@/.test(v) ? null : 'Нужна почта'; } })
h(TaigaUI.InputChip, { label: 'Каналы', size: 'm', items: [{ label: 'СМС', value: 'sms' }, { label: 'Пуш', value: 'push' }], value, onChange })
```

## Пробелы
- Размер чипа внутри поля в гайде не указан: взяты `Chip` XS (L и M) и XXS (S), между чипами 4.
- Кнопка удаления на чипе (крестик `service/cross` 16 / 12) и вид чипа с ошибкой (`status-negative-pale` + `text-negative`) — по аналогии, в гайде без значений.

`accessory` — правый аксессуар рядом с полем, например кнопка копирования в [InputCopy](../InputCopy/README.md). Существующий шеврон мультиселекта сохраняется.
