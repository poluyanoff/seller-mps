# CopyTooltip (`tui-copy-tooltip`)

Подсказка с одной или двумя кнопками копирования параметров объекта. Например, отдельные кнопки для ИНН и КПП. Только **Desktop**, темы `desktop-day` и `desktop-night`.

## Варианты

- `default`: фон `component-tooltip`, текст `text-primary-on-opposite`.
- `floating`: фон `background-elevation-3`, текст `text-primary`, тень из Tooltip; ночью тень отключается.

Состав: Tooltip, отступы 6, кнопки Button S, между кнопками промежуток 12 с разделителем 1 px. Стандартные геометрия и хвост Tooltip. Для default используются контрастные состояния кнопок; floating использует `flat-grayscale`.

После успешного копирования — тост «Скопировано» (решение команды, 30.10.2026); с `toast: false` нажатая кнопка получает подпись «Скопировано» и цветную иконку успеха. Ширина подсказки меняется под содержимое. Нажатие второй кнопки возвращает первую к исходному виду. При уходе курсора или фокуса подтверждение сбрасывается. Ошибка меняет подпись на «Повторить» и озвучивается скринридером.

## API

```js
// Сам пузырь для размещения в своей композиции
h(TaigaUI.CopyTooltip, {
  appearance: 'floating',
  position: 'bottom', // сторона хвоста, как у Tooltip
  actions: [
    { label: 'Скопировать ИНН', value: '7707083893' },
    { label: 'Скопировать КПП', value: '773601001' }
  ]
})

// Подсказка над доступным по Tab триггером
h(TaigaUI.CopyTooltip, {
  actions: [{ label: 'Скопировать ИНН', value: '7707083893' }]
}, h(TaigaUI.Button, { appearance: 'secondary' }, 'Реквизиты'))
```

- `actions`: один или два объекта `{ label, value, disabled? }`. Остальные элементы не отображаются.
- `copyProcessor(value)`: преобразование строки перед записью, общее для обеих кнопок.
- `value`, `label`: короткая запись одного действия вместо `actions`; подпись по умолчанию «Скопировать».
- `children`: фокусируемый триггер. С ним подсказка открывается при наведении, фокусе или нажатии. Tab или ArrowDown с триггера переводят фокус на первую кнопку; Escape закрывает и возвращает фокус на триггер.
- `open`, `defaultOpen`, `onOpenChange(open)`: управление открытием, если есть `children`.
- `disabled`: отключает копирование, с триггером скрывает подсказку.
- `onCopy(value, index)`, `onCopyError(error, value, index)`: результат с индексом действия 0 или 1.
- `className`, `style`: корневая обёртка.

Без `children` пузырь всегда виден. С `children` портал сохраняет тему триггера, выбирает верх или низ по доступному месту, закрывается при уходе курсора или фокуса (100 мс для перехода через зазор), по Escape, нажатию вне, прокрутке и изменению размера окна. Интерактивный пузырь имеет роль `dialog` с именем «Копирование».

Clipboard API и резервное копирование работают как в [Copy](../Copy/README.md). Подтверждение CopyTooltip держится до ухода курсора или фокуса; двухсекундный таймер относится к Copy.
