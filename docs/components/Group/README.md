# Group (`tui-group`)

Сервисный компонент по гайду tui-group v1.0.1. Объединяет два и более компонента одного или разных типов в горизонтальный или вертикальный стек.

**Когда:**
- группировать связанные действия — сплит-кнопка «Действие + ещё»;
- смыслово объединить элементы — поле, селект и кнопка в одной строке;
- сэкономить место, когда однородных элементов много — группа радио- или чекбокс-блоков.

## Правила
- **Расположение:** горизонтальное (`horizontal`, по умолчанию) или вертикальное (`vertical`).
- **Отступ между элементами — 2** для вложенных элементов любого размера: L, M, S, XS.
- **Без отступов** (`collapsed`) — если у вложенных компонентов есть обводка. Обводки соседей совмещаются в одну линию.
- **Скругления** остаются только на внешних углах крайних элементов. Внутренние углы прямые.
- **Ширина:** по умолчанию элементы делят ширину группы поровну (`fill`). Можно по контенту (`width="hug"`) или задать размер отдельному элементу.
- **Высота** — минимальная, от вложенных компонентов. Десктоп: L 56, M 44, S 32 (в гайде tui-group у S указано 36 — считаем опечаткой, у всех контролов S высота 32). Мобилка: по своим элементам, например кнопки S — 30. Элементы в горизонтальной группе выравниваются по низу, поэтому поле S с лейблом над ним и кнопка S стоят на одной линии.

## Как собирают в Figma
- Группа радио- или чекбокс-блоков — `tui-radio-block [group]` и `tui-checkbox-block [group]`. В коде — `RadioBlockGroup` и `CheckboxBlockGroup`: они собраны на `Group` `collapsed`.
- Группа кнопок — `tui-button-split`.
- Вручную: autolayout с именем `tui-group`, затем:
  - задать отступ 2;
  - оставить скругления только на внешних углах крайних элементов;
  - у средних элементов с обводкой убрать обводку слева или справа;
  - настроить ресайзинг.

## API
```js
// Сплит-кнопка
h(TaigaUI.Group, { width: 'hug' },
  h(TaigaUI.Button, { size: 'm', icon: 'star' }, 'Оплатить'),
  h(TaigaUI.Button, { size: 'm', icon: 'chevron-down', ariaLabel: 'Еще' }))
// Поле + селект + кнопка
h(TaigaUI.Group, null, h(TaigaUI.Input, { size: 'm', label: 'Сумма' }), h(TaigaUI.Select, { size: 'm', label: 'Валюта', options }), h(TaigaUI.Button, { size: 'm', style: { flex: 'none' } }, 'Найти'))
// С обводкой — без отступов
h(TaigaUI.Group, { collapsed: true, width: 'hug' }, h(TaigaUI.Button, { appearance: 'outline' }, 'Один'), h(TaigaUI.Button, { appearance: 'outline' }, 'Два'))
```
- Пропсы: `orientation` (`horizontal` · `vertical`), `collapsed`, `width` (`fill` · `hug`), `gap` — своё значение отступа, `label` (подпись группы для озвучки), `className`, `style`.
- Скругления снимаются у самих элементов, у полей `Input` / `Select` и у кнопок внутри обёрток.

## Пробелы
- Компонента `tui-button-split` в ДС нет. Сплит-кнопку собираем из `Button` в `Group`.
