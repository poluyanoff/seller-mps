# CalendarDropdown (`tui-calendar-dropdown`)

Календарь внутри выпадашки по гайду tui-calendar v1.1.0, только десктоп. Сам календарь и его пропсы описаны в [`Calendar`](../Calendar/README.md).

## Построение
- **Контейнер:**
  - фон `background-elevation-1`;
  - радиус 12;
  - обводка `border-normal`;
  - тень `shadow-small`.
- **Календарь** (обязательно) — поля 8.
- **Саджесты** (`suggests`, необязательно):
  - колонка справа от календаря, ширина по контенту, минимум 180;
  - поля 8, между пунктами 2, разделитель слева `border-normal-opaque`;
  - пункты — `tui-dropdown [item]` L на основе `tui-cell`: состояния наведения и нажатия наследуются, выбранный пункт с галочкой.
- **Футер** (необязательно):
  - поля 16, разделитель сверху;
  - по умолчанию справа кнопки S «Сбросить» (secondary) и «Готово» (primary);
  - слева можно поставить свой контент (`footerStart`), например чекбокс;
  - весь футер можно заменить своим (`footer`).

## Поведение
- Выбор в календаре и саджесты меняют черновик. Саджест переключает календарь на месяц начала периода.
- «Готово» отдаёт черновик в `onApply`, «Сбросить» очищает выбор и вызывает `onReset`.
- Открытие и закрытие — снаружи: например, в `Dropdown` с `content` или в своём поповере.

## API
```js
h(TaigaUI.CalendarDropdown, {
  mode: 'range',
  suggests: [{ label: 'Прошлая неделя', value: ['2026-01-05', '2026-01-11'] }, { label: 'Прошлый месяц', value: ['2025-12-01', '2025-12-31'] }],
  onApply: (range) => …, onReset: () => …
})
```
Пропсы:
- всё из `Calendar`, кроме `platform`; `mode` по умолчанию `range`;
- `suggests` — `{ label, value, onClick? }`;
- `footer` — `false` (без футера) или свой узел;
- `footerStart`;
- `applyLabel`, `resetLabel`, `onApply(value)`, `onReset()`;
- `label`, `suggestsLabel`.

## Пробелы
- На мобилке календарь в выпадашке не показываем: календарь открывается в модальном фуллскрине (`Dialog fullscreen`) или шторке.
- Пресет `default` в Figma содержит в футере чекбокс и ссылку. В тексте гайда футер по умолчанию — кнопки подтверждения и сброса. Взяли кнопки, чекбокс — через `footerStart`.
