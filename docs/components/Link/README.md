# Link (`tui-link`)

Ссылка и компактная кнопка-ссылка по гайду tui-link (v1.1.0). Состав: иконка слева (необязательно) → текст с подчёркиванием (обязательно) → иконка справа (необязательно).

> В ДС синяя ссылка (`default`) — без подчёркивания ни в покое, ни при наведении (решение команды), подробнее — в «Поведении».

## Когда что
- **Гиперссылка** — `href`, рендерится `<a>`. Переход на другую страницу или якорь, обычно в тексте.
- **Кнопка-ссылка** — без `href`, рендерится `<button>`. Запуск действия или отправка данных, обычно внутри других компонентов для компактного размещения («Скачать файл»).
- **Псевдоссылка** — `pseudo`, всегда `<button>`, штриховое подчёркивание. Открывает диалог, контекстное меню, разворачивает элемент («Изменить адрес»). Подходит как кнопка быстрого заполнения поля (например, «сейчас» под полем даты).
- **Нужна большая область нажатия или подсветка фона** — не ссылка, а `Button` `flat`. У ссылки кликабельна только сама надпись.

## Размеры (десктоп)
Высота фиксирована, ширина по контенту. Иконки во всех размерах — 16.

| `size` | текст | высота | иконка ↔ текст |
|---|---|---|---|
| `x-large` (по умолчанию) | UI L 17/24 (`tui-ui-l`) | 24 | 6 |
| `large` | Body M 15/24 (`tui-body-m`) | 24 | 6 |
| `medium` | Body S 13/20 (`tui-body-s`) | 20 | 4 |
| `small` | UI XS 11/13 (`tui-ui-2xs`), +1 сверху | 16 | 4 |

Подчёркивание — 1 px у нижнего края надписи (у `large` — на 1 выше); у псевдоссылки штрих 2/2.

## Стили текста (`textStyle`)
| стиль | текст · hover | подчёркивание · hover |
|---|---|---|
| `default` | `text-action` · `text-action-hover` | `service-underline` · `service-underline-hover` |
| `text-primary` | `text-primary` · без изменений | `service-underline-grayscale` · `-grayscale-hover` |
| `text-secondary` | `text-secondary` · `text-primary` | `service-underline-grayscale` · `-grayscale-hover` |
| `text-primary-on-light` (не зависит от темы) | `text-primary-on-light` · без изменений | `-grayscale-on-light` · `-on-light-hover` |
| `text-primary-on-dark` (не зависит от темы) | `text-primary-on-dark` · без изменений | `-grayscale-on-dark` · `-on-dark-hover` |

Подчёркивание `text-primary` — только у ссылки в абзаце (`inline`), отдельно стоящая черная ссылка без линии (см. «Поведение»).

Иконки красятся цветом текста. Анимация смены цвета — `duration-fastest`, `productive-standard`.

## Поведение
- Курсор — pointer. Фокус по Tab: рамка 1 `border-focus` (на тёмном — `border-focus-on-dark`), радиус 2, на 2 px шире ссылки.
- **Без подчёркивания** (`underline={false}`) — когда интерактивность очевидна из контекста, например пункты навигационного меню. Hover остаётся прежним: появляется подчёркивание hover.
- **Синяя ссылка (`default`) — без подчёркивания** (решение команды): линии нет ни в покое, ни при наведении и нажатии; на десктопе при наведении меняется только цвет (`text-action-hover`). Так везде — в тексте, в шапке карточки и заголовка, отдельно стоящая. У псевдоссылки штрих остаётся: он показывает, что откроется диалог или меню. Серые и монохромные стили (`text-primary`, `text-secondary`, `on-light`, `on-dark`) — с подчёркиванием, как в таблице выше; лигал — `text-secondary`. `underline` для синей ссылки подчёркивание не возвращает.
- **Исключение — черная ссылка (`text-primary`) без подчёркивания** (решение команды, 27.10.2026): у отдельно стоящей ссылки линии нет ни в покое, ни при наведении и нажатии. Например, список статей в карточке «Полезное». Внутри абзаца (`inline`) подчёркивание остаётся, иначе ссылку не отличить от текста.
- **Ссылка в шапке карточки и заголовка** (`accessory` у `CardLarge` и `Header`) — без подчёркивания в любом стиле, в том числе при наведении. Компоненты делают это сами.
- **Ссылка в тексте шапки** — отдельная ссылка в `caption`, `title`, `subtitle` или `description` у `Header` (и `PageHeader`) и в заголовке `CardLarge`, например «Реквизиты для обмена ›» под заголовком страницы: тоже без подчёркивания ни в покое, ни при наведении и нажатии (решение команды, 25.10.2026). Ссылка внутри абзаца (`inline`) остаётся по правилам текста.
- **Посещённые** (`visited`) — по умолчанию выключены. Включаем, если рядом много ссылок, и только на нейтральных фонах (белом или сером): текст `service-link-visited` (`-on-light-visited`, `-on-dark-visited`), при наведении подчёркивание того же цвета.

## В тексте и на мобилке
- **В лигале** (`legal` у `Dialog`, `FloatingContainer`, `OnboardingFlow`, `ProductPage`) ссылка ведет себя как `inline` сама: шрифт и размер текста лигала. Передавать ничего не нужно (решение команды, 29.10.2026).
- `inline` — ссылка внутри абзаца: берёт шрифт абзаца, переносится по строкам, подчёркивание через `text-decoration`. В тексте — только ссылки без иконок.
- **Ссылка другим стилем текста** (например, Body L рядом со списком Body L): размеров в гайде только четыре — x-large, large, medium, small. Нужен другой стиль — ставим `inline`-ссылку в абзац этого стиля: `h('p', { className: 'tui-body-l' }, h(Link, { inline: true }, 'Посмотреть образцы'))`. Это штатный способ, не обход.
- **Мобилка** (`platform="mobile"`, `system: 'ios' | 'android'`) — ссылка только внутри текста, размер шрифта меняется вместе с текстом. Состояние — нажатие, а не hover:
  - `default` — без подчёркивания, при нажатии `text-action-pressed`;
  - `text-primary` / `text-secondary` — при нажатии `text-primary-pressed` / `text-secondary-pressed`, подчёркивание `-grayscale-pressed`;
  - `on-light` / `on-dark` — `text-primary-on-light-pressed` / `-on-dark-pressed`.
  - Отступ подчёркивания: iOS — авто, Android — 20 % кегля.
- **Ссылка-ячейка** на мобилке — `tui-button [cell]`. **Ссылка в заголовке карточки или ячейке** — `tui-button [link]`, уже встроена в карточки и ячейки. `Link` для этого не используем.

## Тексты
- Если ссылка запускает сценарий, текст отвечает на вопрос «Что сделать?»: «Создать…».
- Текст понятен без контекста: без «тут», «здесь».
- Знаки препинания в ссылку не входят, предлоги и кавычки — входят.
- Длина 1–3 слова, чтобы было удобно нажимать.
- В текстовом блоке монохромная ссылка — только цвета текста (в первичном тексте — `text-primary`, а не `text-secondary`).
- Несколько ссылок в строке — отступ не меньше 20.
- Общие правила текстов и коды — раздел «Тексты интерфейса» (`copy.md`): TP8, лигал — TT2.

## Доступность
- Увеличение шрифтов: ссылка в тексте растёт вместе с текстом; ссылка внутри другого компонента — по правилам компонента.
- Озвучка: ссылка читается как часть текста, переход — через дополнительные действия скринридера. На Android к озвучке может добавляться форматирование текста — это настройка пользователя.

## API
```js
h(TaigaUI.Link, {
  children: 'Подробности', // или label
  href, target, rel, download, onClick,
  size: 'x-large' | 'large' | 'medium' | 'small',
  textStyle: 'default' | 'text-primary' | 'text-secondary' | 'text-primary-on-light' | 'text-primary-on-dark',
  iconLeft, iconRight,   // имя иконки (16; без набора — small-pragmatic) или элемент
  pseudo, underline: true, visited: false,
  inline, platform: 'mobile', system: 'ios' | 'android',
  state: 'hover' | 'pressed' | 'visited' | 'visited-hover' | 'focus', // только для превью и макетов
  as, className, style
})
```

## Пробелы
- На десктопе нажатое состояние не описано: используется вид hover.
- Отступ подчёркивания в тексте на десктопе (`inline`) — 4 px, подобран по положению линии в компоненте; в гайде для текста не указан.
- Посещённая ссылка без наведения: в гайде не видно, меняется ли подчёркивание. Оставили обычное подчёркивание стиля. У отдельной (не `inline`) ссылки подчёркивание при наведении на посещённую не перекрашивается: браузеры не дают менять `:visited` у вложенных элементов.
- Disabled в гайде нет.
- `tui-button [cell]` и `[link]` упоминаются в ДС, но отдельной реализации в бандле у них нет.
- На Android Compose подчёркивание всегда цвета текста. В вебе (WebView) берём токены подчёркивания, как на иллюстрациях гайда.
