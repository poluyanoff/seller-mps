# Toggle / Switch (`tui-switch`)

Тоггл по гайду tui-switch v1.3.0: включает параметр сразу, без кнопки «Сохранить». `TaigaUI.Switch` — то же самое.

## Десктоп
- **Large** — 48×24, кноб 16, кольцо «выкл.» 12, галочка 24. Для элементов форм L и M.
- **Small** — 32×16, кноб 12, кольцо 8, галочка 14. Для элементов форм S.
- **Фон:**
  - выкл. — `neutral-2` (наведение и нажатие — `-hover` и `-pressed`);
  - вкл. — `accent-1` с галочкой `primary-on-accent-1`;
  - accent — `accent-2`.
- **Кноб** белый в обеих темах.
- **Disabled** — 56 %. Ошибки у тоггла нет.
- **Анимация** (150 мс, easeInOutSine):
  - кноб едет вправо;
  - кольцо уходит вправо на 16 и гаснет;
  - галочка приезжает слева из −16 и растёт.
- **Лейбл** — как у чекбокса: Medium — 12 и `body-m`, Small — 8 и `body-s`. Тоггл выровнен по верху.

## Мобилка
Только внутри других компонентов (`Cell`, `Header`).
- **iOS 18** — 51×31, кноб 27: выкл. `neutral-3`, вкл. `accent-2`, 200 мс, при удержании кноб тянется.
- **iOS 26** (`system="ios26"`) — 64×28, кноб-капсула 39×24.
- **Android** (`system="android"` или тема `android-*`) — 40×24:
  - трек 34×14, кноб 20;
  - вкл. — трек `accent-2` 50 %, кноб `accent-2`;
  - без эффекта нажатия.

В WebView на iOS — системный контрол (Safari 17.4+). Этот вид — фолбэк для браузеров, где системного нет.

```js
h(TaigaUI.Toggle, { label: 'Автопополнение', description: 'Каждый день в 21:00', checked: on, onChange: setOn })
h(TaigaUI.Cell, { platform: 'mobile', system: 'ios26', title: 'Уведомления', control: 'toggle', checked: on, onClick: flip })
```
Пропсы:
- `checked`, `onChange`, `defaultChecked` — состояние;
- `size` — `m` или `s`;
- текст: `label`, `description`, `hint`;
- `disabled`;
- `appearance` — `primary` или `accent`;
- `platform`, `system` — `ios`, `ios26` или `android`.

## Тексты
- Подпись — глаголом, однозначно, без отрицаний и без «Включить»: «Получать уведомления», не «Не присылать уведомления» и не «Включить уведомления».
