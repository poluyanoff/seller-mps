# ActionBar (`tui-actions-bar`)

Бар массовых действий с выбранными элементами: строками таблицы, карточками, документами. Появляется, когда выбран хотя бы один элемент, и прячется, когда выбор сняли. По Figma «Action Bar» (Beaver, DPDS-1897), гайд v1.0.0.

## Когда использовать
- В листинге или таблице выбрали несколько элементов, и с ними можно сделать одно действие сразу: подписать, отправить, скачать, удалить.
- Не используйте для действий со страницей или с одним объектом — это кнопки в шапке, карточке или строке таблицы.

## Десктоп

### Размеры
| | small | large |
|---|---|---|
| Где | нагруженные служебные интерфейсы | клиентские сервисы (по умолчанию) |
| Высота | 48 | 68 |
| Радиус | 12 | 16 |
| Поля: слева / справа / сверху и снизу | 20 / 12 / 8 | 24 / 12 / 12 |
| Счетчик | `body-s-bold` 13/20 | `body-m-bold` 15/24 |
| «Выбрать все» | `Link` medium, pseudo | `Link` large, pseudo |
| Кнопки | `Button` S | `Button` M |
| Иконки кнопок | `small-pragmatic` 16 | `medium` 24 |
| Меню «Еще» | `Dropdown` S | `Dropdown` M |
| От низа экрана (`floating`) | 8 | 16 |

### Построение
Лейаут один, блоки местами не меняем.
- **Start:** счетчик → 16 → «Выбрать все» → 40 → кнопки действий через 8 → «Еще».
- **End:** «Удалить» → 8 → крестик. От Start до End — не меньше 40.
- Фон — `component-action-bar`, тень `shadow-medium` (ночью ее нет, как у всех теней ДС). Текст, иконки и ссылка — `on-dark`.
- Кнопки — `secondary-grayscale-on-dark`, крестик — `flat-grayscale-on-dark`. Состояния (наведение, фокус, загрузка, неактивная) — от `Button`.
- **Обводка** (`border`) — 1 px `border-darkmode-only`: днем прозрачная, ночью отделяет бар от фона. Только для ночных листингов с карточками в обводке, в остальных листингах — без нее.

### Элементы
- **Счетчик** — обязателен: пользователь должен однозначно понимать, сколько выбрано. «Выбрано 4» (`count`) или «Выбрано 4 из 120» (`count` + `total`). Свой текст — `counter`.
- **«Выбрать все»** — псевдоссылка, необязательна (`onSelectAll`). Выбирает все элементы таблицы. После нажатия неактивна (`allSelected`, `text-tertiary-on-dark`), но не пропадает — остальные элементы бара не сдвигаются.
- **Кнопки действий** — необязательны, до 6. Набор и порядок определяет продуктовая команда. Можно одну `primary`. Кнопка со своим меню — `items`, справа шеврон.
- **«Удалить»** — необязательна (`onDelete`).
- **Крестик** — «Закрыть бар и снять выделение», обязателен (`onClose`).

### Поведение
- **Ширина.** На экранах до 1280 бар тянется по 12-колоночной сетке контентной области с полями 24. Шире — по центру, не больше 1184.
- **Расположение** (`floating`). Внизу контентной области по центру сетки — не по центру экрана, а правее боковой навигации. От низа: large — 16, small — 8. Бар прилипает к низу при прокрутке; если контента мало — стоит сразу под ним. Можно выровнять по левому краю таблицы: поля 24 и ширина до 1184 сохраняются, правый край не выходит за экран.
- **«Еще».** Когда кнопкам не хватает места, они уходят в меню «Еще» справа налево. Если не помещается даже одна кнопка рядом с «Еще», она сжимается с многоточием, но не уже самой «Еще» — иначе тоже уходит в меню. Кнопка со своим меню внутри «Еще» становится каскадом. `maxVisible` — сколько кнопок показывать максимум, остальные сразу в «Еще».
- **Появление и скрытие** (`visible`) — снизу, как у `FloatingContainer`: появление `duration-slow` + `expressive-entrance`, скрытие 200 мс `productive-exit`.

## Мобилка (`platform: 'mobile'`)
Большинство экранов — WebView, бар собран на тех же `Button` и проверяется `TaigaUI.check()`.

### Построение
Сверху вниз: список действий (только в развернутом состоянии) → main. Блоки местами не меняем.
- Контейнер: поля 6, радиус 20, фон `component-action-bar`, без тени.
- **Main** — высота 64, поля 10, между элементами 8: счетчик и до 2 кнопок `Button` M (44, радиус 12, `secondary-grayscale-on-dark`). В main кнопка — только иконка; подпись рядом — `showLabel`.
- **2 строки** — если в строку не помещается (длинная подпись, кнопки нельзя сократить до иконки): счетчик, через 12 кнопки на всю ширину, кнопки с подписью делят ее поровну. По умолчанию выбирается по месту, принудительно — `lines`.
- Высота: свернутый в 1 строку — 76, в 2 строки — 108 (iOS и Android, у счетчика строка 20).

### Состояния
- **Свернутый** — в main основное действие.
- **Развернутый** — если действий больше двух: в main первое действие и «Еще», остальные — в списке над main (через 10). «Еще» разворачивает бар, ее иконка меняется на крестик, который сворачивает.
- Список: пункты 44 без подложки (`Button` M `flat-grayscale-on-dark`, иконка 24 + подпись), между пунктами 4. Группы — дивайдер `{ type: 'separator' }`: строка 13, линия 1 `background-neutral-1-on-dark`.
- Всего действий — до 6.

### Расположение (`floating`)
Как `FloatingContainer` со своим контентом: бока 16, снизу 24 + safe area, появление снизу. В прототипе в рамке телефона — `position: 'absolute'`.

## Тексты
- Счетчик — «Выбрано 4», «Выбрано 4 из 120». Склонение по существительному («Выбрано 4 документа») — через `counter`.
- «Выбрать все», «Еще», «Удалить» — без «ё». Подписи кнопок — глаголом, коротко: «Подписать», «Скачать», «В архив».
- Без точек в конце.

## Решения команды и отличия от Figma
- **Фон — новый токен `tui-component-action-bar`, #414141 во всех темах.** В Figma фон бара и меню «Еще» задан цветом без токена. Бар темный и днем, и ночью, поэтому все на нем — `on-dark`.
- **Меню «Еще» — темное, как в Figma**, это отличие от обычного `Dropdown` (`elevation-1`). Внутри бара токены меню переключены на `on-dark`; размеры, отступы, наведение и каскад — от `Dropdown` M и S. В Figma у меню паддинг 4, айтем S 32 и своя тень с цветом без переменной — берем значения `Dropdown`: M — паддинг 6, пункт 36; S — 4, пункт 28; тень `shadow-small`.
- **iOS — по правилам ДС.** В Figma только Android. Размеры такие же, счетчик `ios-body-m-bold` 15/20, крестик — `service/close-ios`. Не сверено с Figma.
- **Мобильный бар — как `FloatingContainer`**, без крестика «Сбросить»: на мобилке его в гайде нет, выбор снимается на экране.
- **Крестик на десктопе при наведении — `background-neutral-1-on-dark`.** У `flat-grayscale-on-dark` в `Button` наведения нет; взяли по аналогии с `flat` (`neutral-1`).
- **Счетчик на мобилке — строка 20** (`android-body-m-bold` 14/20), в Figma 14/100 %. Бар в 2 строки — 108 вместо 104.
- **Blur `blur-tabbar` на мобилке не переносим**: фон непрозрачный, размытие под ним не видно.

## Пробелы
- Анимация в гайде не показана — появление взято у `FloatingContainer`, разворачивание на мобилке — без анимации.
- Не сказано, входит ли «Еще» в лимит 6 кнопок. Считаем, что нет: 6 — это действия.
- Порог, когда кнопки уходят в «Еще», в гайде «≤1280» и «<1280». В коде — по фактической ширине.
- Максимальная ширина кнопки до обрезки и минимальная ширина бара не указаны. Минимум сжатой кнопки — ширина «Еще» — решение в коде, в гайде его нет.
- На мобилке не показаны: нажатие, неактивные и загрузка у пунктов списка, деструктивный пункт, сворачивается ли список после действия (в коде — нет, этим управляет экран через `expanded`).
- Кнопки со своим меню (`items`) на мобилке не описаны и не поддерживаются.

## API
```js
// Десктоп, клиентский сервис
h(TaigaUI.ActionBar, {
  count: selected.length, total: rows.length,
  onSelectAll: selectAll, allSelected: selected.length === rows.length,
  actions: [
    { label: 'Подписать', icon: 'pencil', appearance: 'primary', onClick: sign },
    { label: 'Отправить', icon: 'share', onClick: send },
    { label: 'Скачать', icon: 'arrow-down', items: [{ label: 'PDF', onClick: pdf }, { label: 'Excel', onClick: xls }] }
  ],
  onDelete: remove, onClose: clearSelection,
  floating: true, visible: selected.length > 0
})

// Служебный интерфейс
h(TaigaUI.ActionBar, { size: 'small', count: 12, actions: [...], onClose: clearSelection, floating: true })

// Мобилка
h(TaigaUI.ActionBar, { platform: 'mobile', system: 'android', count: 4, floating: true, visible: selected.length > 0, actions: [
  { label: 'Подписать', icon: 'pencil', onClick: sign },
  { label: 'Отправить', icon: 'share' }, { label: 'Скачать', icon: 'arrow-down' },
  { type: 'separator' },
  { label: 'Удалить', icon: 'trash' }
] })
```
- **Общие:** `platform`, `count`, `total`, `countLabel` («Выбрано»), `counter`, `actions` (`{ label, icon, onClick, appearance, disabled, loading, items, showLabel }`), `floating`, `visible`, `label` (подпись панели для озвучки), `className`, `style`.
- **Иконки:** имя без набора — `small-pragmatic` у small, `medium` у large и на мобилке; с набором (`service/…`) — как есть.
- **Десктоп:** `size` (small · large), `onSelectAll`, `allSelected`, `selectAllLabel`, `maxVisible`, `moreLabel` («Еще»), `onDelete`, `deleteLabel` («Удалить»), `onClose`, `closeLabel` («Сбросить»), `border`. Пункты `items` и меню «Еще» — `{ label, icon, onClick, disabled, items }`.
- **Мобилка:** `system` (ios · android), `expanded`, `defaultExpanded`, `onExpandedChange`, `lines` (1 · 2 · auto), `moreLabel`, `collapseLabel` («Свернуть»), `position` и `homeIndicator` — для `FloatingContainer`. «Выбрать все», «Удалить» в End и крестик на мобилке не показываются — «Удалить» передавайте действием.
