# ProgressCircle (`tui-progress-circle`)

Круговой прогресс по гайду tui-progress-circle v1.1.0. Готов на всех платформах.

**Где использовать:** в ячейках и карточках — лимиты, накопления, загрузка.

## Варианты и размеры
- **Размер** (`size`): 128, 96, 80 (по умолчанию), 64, 56, 40, 32. Можно задать свой, но тогда контент внутри делаем кастомным.
- **Толщина линии** (`thickness`): 2, 4 (по умолчанию), 6, 8, 12. Подходит к любому размеру. На маленьких размерах берём тонкую линию, чтобы контенту не было тесно.
- **Контент:**
  - `icon` — иконка в половину размера: 128 → 64, 80 → 40, 32 → 16. Пропорции одинаковые на всех платформах;
  - `content: 'text'` — процент или `text`;
  - без контента;
  - свой контент — `children`. Зазор до линии не меньше 2.
- **Текст по размерам:**

| Размер | Десктоп | iOS / Android |
|---|---|---|
| 128 | Heading 4 28/32 | 24 |
| 96 | Heading 6 20/24 | 18 |
| 80 | Body M Bold 15/24 | 14 |
| 64 | UI S Bold 13/16 | 10 |
| 56 | UI XS Bold 11/13 | 10 |
| 40 | 9/16 | 9 |
| 32 | 7/16 | — |

- **Цвета:**
  - линия — `status-info` на всех платформах. Это решение команды: в Figma на десктопе `background-accent-2`;
  - трек: десктоп — `component-progress-bar`, мобилка — `background-neutral-2`.
- **Открытый круг** (`open`) — арка 270° с разрывом снизу.
- **Скелетон** — `skeleton`.

## Кастомизация
- **Направление** — `startAngle` (в градусах от 3 часов по часовой) и `counterClockwise`, любая начальная точка.
- **Цвет:**
  - `color` — любой сплошной цвет, градиент (массив цветов) или пороги `[{ from, color }]` для динамической смены;
  - `trackColor` — цвет трека.

## Анимация
Смена значения и цвета: `productive-standard`, `duration-fast`.

## Доступность
- При увеличенном шрифте текст внутри не растёт.
- По умолчанию не озвучивается. С `label` или `ariaLabel` получает `role="progressbar"` и процент.
- Идёт загрузка — `loading` (`aria-busy`). По окончании продукт сообщает «Загрузка завершена», например через `aria-live`.

## API
```js
h(TaigaUI.ProgressCircle, { size: 80, value: 64, content: 'text' })
h(TaigaUI.ProgressCircle, { size: 56, value: 40, icon: 'medium/star', open: true })
h(TaigaUI.ProgressCircle, { size: 128, thickness: 6, value: 50, label: 'Потрачено' }, h('div', null, '100\u00a0₽', h('br'), 'из 200\u00a0₽'))
```
Пропсы:
- `value`, `max`;
- `size`, `thickness`;
- `content` (`text` · `none`), `text`, `icon`, `children`;
- `open`, `startAngle`, `counterClockwise`;
- `color`, `trackColor`;
- `skeleton`;
- `platform`, `system`;
- `label` / `ariaLabel`, `loading`.

## Пробелы
- **Мобильный текст.** В Figma заданы только кегли. Начертание (SF Pro 600 / Roboto 500) и межстрочный — наша трактовка.
- **Текст 40 и 32 на десктопе** — без стиля в Figma: 9/16 и 7/16, начертание взяли Medium.
- **`component-progress-bar`** — временный компонентный токен, пока не вышли токены 2.0.
