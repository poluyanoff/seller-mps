# InputPhone

Поле телефона РФ. Наследует `Input`. Правила — «Поля с маской» в разделе «Формы и поля ввода».

- Без фокуса — только лейбл «Телефон».
- В фокусе предзаполнен код **+7**: он не стирается, это часть значения, а не префикс.
- Маска без скобок: **+7 921 123-45-67**; этот же номер — плейсхолдер.
- При вставке «8 900…» или «+7 900…» код отрезается → +7 900….
- Ввод в середину сдвигает цифры вправо, каретка не прыгает.
- Значение — `+7XXXXXXXXXX` или пустая строка; `onChange(value, complete)`, где `complete` — набраны все 10 цифр.

```js
h(TaigaUI.InputPhone, { size: 'l', value, onChange: function (v, complete) {} })
h(TaigaUI.InputPhone, { platform: 'mobile', error: 'Нужен номер, чтобы курьер мог связаться с вами' })
```

## Пробелы
- Только российские номера; выбор кода страны не описан.
