# List (`tui-list-item [bulleted]`, `tui-list-item [numbered]`)

Маркированный и нумерованный списки текста по гайду tui-list v1.1.0. Используются в карточках, шторках и контенте страницы, например «Как проверить контрагента». Список некликабельный: текст можно выделить системными средствами.

## Построение пункта
Маркер (буллет или номер) → **12** → текст.
- **Поля пункта:** 8 сверху и снизу, 16 по бокам. У вложенного пункта слева **36** (токены `tui-list-item [h-spacing]`).
- **Между пунктами** дополнительных отступов нет.
- **Текст** — только наборные стили, цвет `text-primary`. Длина не ограничена, маркер остаётся прижатым к первой строке.

| `size` | Десктоп | iOS | Android |
|---|---|---|---|
| `l` (Body L) | `body-l` 17/28 | `ios-ui-l` 17/20 | `android-ui-l` 16/19 |
| `m` (Body M, по умолчанию) | `body-m` 15/24 | `ios-ui-m` 15/18 | `android-ui-m` 14/16 |
| `s` (UI S) | `body-s` 13/20 | `ios-ui-s` 13/16 | `android-ui-s` 13/15 |

На мобилке — группа UI, а не Body: по карте миграции Foundations старый мобильный Body переезжает на UI, у нового Body интерлиньяж больше и вёрстка списков поедет.

## Маркированный
- **Буллет:**
  - круг **6**, цвет `status-info`;
  - стоит по центру высоты заглавной буквы первой строки;
  - его размер и отступы не зависят от размера текста.
- **Контейнер буллета:** на десктопе фиксированной ширины, буллет в нём по центру: L — 14, M — 12, S — 12. На мобилке контейнер шириной 6.

## С галочками
`type: 'check'` — список возможностей, например в карточках тарифов. В Figma такого маркера нет, в продуктах его ставят кастомом.
- **Маркер** — иконка `small-pragmatic/check` 16 цветом `text-action` (`markerColor` меняет цвет), по центру первой строки.
- **Контейнер маркера** — 16, до текста 12. Пункт как у остальных списков: 8 сверху и снизу.

## Нумерованный
- **Номер** набран тем же стилем, что и текст, стоит на одной базовой линии с ним и выравнивается по правому краю контейнера.
- **Ширина контейнера номера** зависит от числа разрядов (токены `tui-list-item [digit-width]`) и одинакова во всём списке. Появился новый разряд — увеличиваются контейнеры всех пунктов.

  | разрядов | Десктоп L / M / S | Мобилка L / M / S |
  |---|---|---|
  | 1 | 14 / 12 / 12 | 14 / 12 / 12 |
  | 2 | 23 / 22 / 18 | 24 / 20 / 19 |
  | 3 | 33 / 30 / 25 | 34 / 30 / 26 |
  | 4 | 44 / 40 / 33 | 44 / 40 / 34 |

- **Вложенные номера** — «1.1.», «1.1.1.»; разрядов берём на 1 больше на каждый уровень вложенности. Компонент считает это сам.

## Список
- Отступ слева фиксированный: 16, у вложенных — 36.
- **На экране мобилки** эти 16 и есть поле экрана: маркер стоит на линии заголовка (примеры гайда «В контенте», «В шторках»). В мобильном `PageLayout`, мобильном `Dialog` и шторке с `inset` список сам компенсирует поля контейнера и встаёт от края до края, как `Cell`; свой боковой `padding` вокруг него не добавляем. `inset={false}` — список без своих полей, встаёт в поле контейнера.
- **В карточке** (`CardLarge`) маркер стоит на линии заголовка карточки: свои поля списка уходят в поля карточки, специально задавать ничего не нужно.
- Если маркированный и нумерованный списки стоят рядом, пункты выравниваем между собой. На десктопе контейнер буллета и контейнер однозначного номера совпадают. На мобилке задайте маркированному списку `markerWidth`, равный ширине номера.
- Заголовок списка — отдельный `Header`.

## Кастомизация
- Цвет буллета или номера можно поменять (`markerColor`: токен или цвет).
- В тексте допустимы ссылки (`Link inline` или `<a>`).

## Доступность
- **Увеличение шрифтов:** до AX1 на iOS и 150 % на Android, отступы не меняются.
- **Озвучка:** маркированный пункт — только текст, нумерованный — номер и текст («Один. Ты»). Ссылки из текста выносим в дополнительные действия.
- **Android XML:** по умолчанию фокус встаёт на весь список. Чтобы пункты фокусировались отдельно, каждому нужен свой TextView.
- **В вебе** — семантика `ul` / `ol` и `li`.

## API
```js
h(TaigaUI.List, { items: ['Проверьте адрес регистрации', 'Запросите копии документов'] })
h(TaigaUI.List, { type: 'numbered', size: 'l', start: 7, items: ['Eurasia', 'Africa'] })
h(TaigaUI.List, { type: 'numbered', items: [{ content: 'Пункт', items: ['Вложенный', 'Вложенный'] }] })
h(TaigaUI.List, { platform: 'mobile', system: 'android', size: 's', markerColor: 'tui-text-positive', items: [...] })
h(TaigaUI.List, { type: 'check', inset: false, items: ['Консультации налоговых экспертов в чате', 'Расчет и оплата налогов'] })
```
Пропсы:
- `type` (`bulleted` · `numbered` · `check`), `size` (`l` · `m` · `s`), `platform`, `system`;
- `items` — строки, элементы или `{ content, items, number }`;
- `start`, `markerColor`, `markerWidth`, `inset={false}` — без боковых полей, например внутри карточки со своими отступами;
- `label`, `className`, `style`.
