# Copy (`tui-copy`)

Копирует значение нажатием на текст. Для номера счёта, ИНН и других реквизитов, которые нужно перенести в другое приложение. Компонент — кнопка, доступная по Tab; Enter и пробел копируют значение.

Только **Desktop**, темы `desktop-day` и `desktop-night`. Мобильный вариант в переданном гайде не описан.

## Вид и поведение

- В обычном состоянии виден текст. При наведении и фокусе текст получает `text-primary-hover`, край затухает, поверх появляется Pragmatic-иконка `copy` цвета `text-tertiary`. Ширина текста при наведении не меняется. Длинный текст по умолчанию переносится; `truncate: true` обрезает его в одну строку с многоточием. В буфер попадает полный текст.
- После успешного копирования — тост «Скопировано» (`showToast`) (решение команды, 30.10.2026). Подсказки у текста нет.
- `toast: false` — старое поведение: floating-подсказка «Скопировано» с `fixed-color/check-circle-positive` на 2 секунды; закрывается при уходе курсора или фокуса, по Escape, нажатию вне, прокрутке или изменении размера окна.
- Подсказка центрируется над значением; у верхней границы окна открывается снизу. Портал сохраняет тему триггера и не обрезается карточками с `overflow`.
- Ошибка буфера не считается успехом: показывается «Не получилось скопировать. Попробуйте снова», вызывается `onCopyError`. Результат озвучивается скринридером.
- Основной способ — Clipboard API. Если API отсутствует, используется `execCommand('copy')` с восстановлением фокуса и выделения. При отказе Clipboard API резервный способ не вызывается.

## Размеры

`size`: `m` / `l` для иконки с наследованием шрифта родителя, либо `ui-l`, `ui-m`, `ui-s`, `ui-xs`, `heading-1`…`heading-6`, `body-xl`, `body-l`, `body-m` (по умолчанию), `body-s`, `body-xs`, `body-2xs`.

Используется актуальная типографика репозитория, а не прежние значения шрифтов в Figma. Для обычного Body XL добавлен класс `tui-body-xl` (19/28); `body-2xs` соответствует существующему `tui-legacy-body-2xs`. Размер иконки, ширина фейда и смещение 2 px вниз взяты из схемы построения.

## API

```js
h(TaigaUI.Copy, { value: '40702810900001234567' })
h(TaigaUI.Copy, { value: '7707083893', size: 'heading-5' })
h(TaigaUI.Copy, { value: 'ИНН 7707083893, КПП 773601001' }, 'Реквизиты')
```

- `value`: строка или число для буфера. Сохраняйте номера с ведущими нулями строкой.
- `children` / `label`: отображаемый текст. Если `value` не задан, копируется строковый или числовой текст. Для React-элементов без `value` читается полный текст отрисованного содержимого, без разметки и внешних пробелов. Явное `value` имеет приоритет и сохраняет пробелы.
- `ariaLabel`: доступное имя вместо «Скопировать: значение».
- `copyProcessor(value)`: синхронная функция преобразования строки перед записью. Пример: `function (value) { return value.replace(/ /g, ''); }`. Пробелы, добавленные обработчиком, сохраняются. Ошибка обработчика вызывает `onCopyError`.
- `truncate`: обрезать текст вместо переноса.
- `textStyle`: типографика отдельно от размера иконки, включая `inherit`.
- `disabled`: недоступное состояние, без копирования и подтверждения.
- `onCopy(value, index)`: только после успеха, `index` равен 0.
- `onCopyError(error, value, index)`: ошибка копирования.
- `className`, `style`: оформление корневой обёртки; ширину можно ограничить через `style.maxWidth`.
- `state: 'normal' | 'hover'`: только для статичного превью, не запускает копирование.

Текст и кнопки внутри Copy не вкладывают. Для отдельных действий используйте `CopyTooltip`, для редактируемого поля — [InputCopy](../InputCopy/README.md), для отдельной кнопки — [ButtonCopy](../ButtonCopy/README.md).
