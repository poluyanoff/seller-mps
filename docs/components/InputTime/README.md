# InputTime (`tui-input-time`)

Поле времени с маской и списком саджестов, только десктоп. Наследует `Input`, список — `DropdownList`. Правила — «Поля с маской → Время» в разделе «Формы и поля ввода».

## Построение
- Базовое поле `Input`, лейбл — существительное («Время погрузки»).
- **Маска ЧЧ:ММ** (`seconds` — ЧЧ:ММ:СС), формат 24 часа. Двоеточие ставится само, остаток маски виден по мере ввода серым (`text-tertiary`).
- **Список саджестов** — `DropdownList` размера поля во всю ширину, через **4** под полем, до **400** по высоте, дальше скролл (как у списков полей).

## Поведение
- Больше 23 часов и 59 минут ввести нельзя. Неподходящая первая цифра заменяется на 0: 9999 → 09:09.
- При потере фокуса нули дописываются: 9 → 09:00, 09:3 → 09:30.
- Саджесты: интервал по умолчанию час (`step` в минутах), диапазон `min` / `max`, исключённые интервалы `exclude`. Список открывается в фокусе и фильтруется по набранным цифрам; выбор подставляет время и закрывает список.
- Клавиатура: ↓ — открыть список или перейти в него, Enter — подтвердить ввод, Esc — закрыть.
- **Ошибка при потере фокуса:** вне диапазона — «Не раньше 06:00» / «Не позже 22:00», исключённое время — «Это время недоступно». Свой текст (`error`) важнее встроенного.

## API
```js
h(TaigaUI.InputTime, { size: 'l', label: 'Время погрузки', value: '09:00', onChange: function (v) {}, min: '06:00', max: '22:00' })
h(TaigaUI.InputTime, { size: 'm', label: 'Время', step: 30, exclude: [['13:00', '14:00']] })
```
Пропсы:
- поле — как у `Input`: `size`, `label`, `labelOutside`, `hint`, `error`, `disabled`, `readOnly`, `cleaner`, `accessory`;
- `value` / `defaultValue` — `'ЧЧ:ММ'` (`'ЧЧ:ММ:СС'`), `onChange(value | null)`;
- `seconds`, `step` (мин, по умолчанию 60), `min`, `max`, `exclude` — время или `[от, до]`;
- `suggestions={false}` — без списка, `openOnFocus={false}` — список только по ↓, `maxHeight`.

## Пробелы
- Формат 12 часов (AM/PM) не сделан.
- Мобильной версии нет: в гайде поле времени описано только для десктопа.
