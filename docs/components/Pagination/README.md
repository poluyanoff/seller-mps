# Pagination (`tui-pagination`)

Пагинация списков и таблиц: «Показать еще» (по умолчанию) или постраничная с пейджером. Какой способ когда, размеры, поведение и расположение — в разделе «Пагинация». Компонент десктопный.

## Когда какой
- **`type: 'more'`** (по умолчанию) — к конкретной странице возвращаться не нужно, массовых действий нет.
- **`type: 'paging'`** — есть выбор объектов и массовые действия, переходы внутрь карточек с возвратом или нужно быстро перейти к нужной странице.
- Данных мало (таблица до 100, карточки до 50) — пагинация не нужна, грузим всё сразу.

## «Показать еще»
```js
h(TaigaUI.Pagination, { shown: 50, total: 1000, onMore: loadMore, size: 's' })
```
- Кнопка `Button` secondary S 32 или XS 24, текст «Показать еще».
- Через 12 — «Просмотрено 50 из 1000», `ui-s`, `text-secondary`. `counterPosition: 'left'` — счетчик слева от кнопки, `counter: false` — без счетчика.
- Когда `shown ≥ total`, кнопка скрывается.
- Остальные пропсы: `align: 'right'`, `loading`, `label`, `counterLabel`.

## Постраничная
```js
h(TaigaUI.Pagination, { type: 'paging', total: 999, page, onPageChange: setPage, pageSize, onPageSizeChange: (n, p) => { setPageSize(n); setPage(p); } })
```
- Пейджер: стрелки, номера, «…». Пункт S 32 (поля 12) или XS 24 (поля 8), между пунктами 4. Текущая — `background-accent-1`, радиус 8 в S, круг в XS.
- Через 0 — `Button` flat «1 – 50 на странице» с `Dropdown` S: варианты из `pageSizes` (до 3), выбранный — галочкой. `pageSizes: false` — без выбора.
- Через 8 — счетчик «999 элементов», `ui-s`, `text-secondary`. Формы слова — `counterForms`, `counter: false` — без счетчика.
- `counterPosition: 'left'` — счетчик и размер страницы слева, зеркально.
- Одна страница — компонент ничего не рисует.
- Без `page` и `pageSize` работает сам (`defaultPage`, `defaultPageSize`).
- Скролл при переключении (вперед — к началу контента, назад — к концу) делает листинг. В `FilterTable` он уже есть.

**Размер страницы:** таблицы — 50 · 75 · 100 (по умолчанию), карточки — 20–50 (`pageSizes: [20, 50]`).

## В FilterTable
- Если в `tableProps` есть `selectable`, `FilterTable` сам ставит постраничную пагинацию. Задать явно — `pagination: 'more' | 'paging'`.
- Место пейджера — `pagingPosition`: `bottom` (по умолчанию), `top` — в End фильтров при закрепленном фильтре, `both` — сверху и снизу для длинных списков. В End размер страницы стоит слева от пейджера, как в гайде.
- Счетчик «N элементов» не дублирует «Результат: N»: он есть, только если `result: false`.

## Пробелы
Состояния пункта (hover, focus, disabled) в гайде не показаны — сделаны как у `Button` flat. Размеры кнопки «на странице» в XS и минимальная ширина пункта не заданы. Подробно — раздел «Пагинация», «Пробелы».
