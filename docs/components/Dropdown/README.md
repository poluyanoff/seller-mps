# Dropdown (`tui-dropdown`)

Выпадающий список и контейнер для меню по гайду tui-dropdown v1.1.1. На десктопе это поповер рядом с хостом. На мобилке то же меню показывают по-другому (см. ниже).

**Когда использовать.** Если вариантов **4 и больше**. Для 2–3 вариантов подойдут радио, чекбоксы или тоггл.

**Хост** — элемент, из которого выпадает список:
- кнопка;
- пункт меню;
- поле ввода (селект, комбобокс);
- элемент фильтра;
- вкладка.

## Размеры
Размер выпадашки совпадает с размером хоста: поле или кнопка L → L. Другой размер допустим, если так требует контекст.

| | Large | Medium | Small |
|---|---|---|---|
| Паддинг контейнера | 8 | 6 | 4 |
| Радиус | 12 | 8 | 8 |
| Между пунктами | 2 | 0 | 0 |
| Пункт (`tui-cell` compact) | 40, отступы 8 | 36, отступы 6 | 28, отступы 6 |

**Контейнер:**
- фон `background-elevation-1`, обводка 1 `border-normal`, тень `shadow-small`;
- ширина — по самому длинному пункту, **не меньше 128**;
- в поле ввода — на всю ширину поля, у кнопки может быть шире или уже хоста.

## Позиционирование и анимация
- **Направление.** Выпадает вниз с выравниванием по левому краю, **4** от хоста. Если не помещается во вьюпорт, разворачивается туда, где есть место, по вертикали и по горизонтали.
- **Появление.** Сдвиг 8 и прозрачность 0 → 1, `duration-fastest`, `productive-standard`, без задержки. Скрытие — так же в обратную сторону.
- **Изменение высоты** (саджесты, «ничего не найдено») — `duration-fastest`.

## Пункты
Пункты построены на `tui-cell` и `tui-header`, поэтому в них работает всё, что умеет ячейка: описание, аватар, иконка, значение справа, бейджи, перенос или обрезка длинного текста.
- **Ховер** — `background-neutral-1`, радиус **4** на всех размерах, `duration-fastest`.
- **Фокус с клавиатуры** — рамка 2 `border-focus`.
- **Единичный выбор** — галочка справа: 24 у L, 16 у M и S.
- **Множественный выбор** — чекбокс слева (у пунктов с аватаром можно справа).
- **Заголовки** (`{ type: 'header' }`) — для секций с названием. Длинный заголовок переносится.
- **Разделители** (`{ type: 'separator' }`) — линия `border-normal` в полосе 16, для секций без заголовка.
- **«Выбрать все»:**
  - **В группе** — действие в заголовке группы, при выборе подпись меняется на «Сбросить».
  - **Без групп** — пункт вверху списка: при прокрутке не закрепляется, подпись не меняется. Если часть пунктов уже выбрана, он довыбирает остальные.
- **Поиск внутри** — только если хост не поле ввода. Если хост — поле ввода, ищем через само поле.
- **Ничего не найдено** — текст «Ничего не найдено», высота подстраивается под него.
- **Прокрутка.** Если задана `maxHeight`, лишние пункты уходят под скролл. Контент при скролле упирается в край контейнера. Скроллбар отстоит на 8 сверху и на 4 справа на всех размерах. Высоту больше нужной не задаём.
- **Закреплённые элементы** — поиск сверху, кнопка снизу (`footer`). Под ними фон, чтобы список не просвечивал.
- **Дозагрузка** — по кнопке «Показать еще» или автоматически.
  - Лоадер — по центру.
  - Ошибка — «Не загрузилось. Обновить».
- **Вложенное меню** — пункт с `items`:
  - помечается шевроном и раскрывается через **500 мс**;
  - выпадает вправо и вниз от родительского пункта, той же ширины, с той же анимацией;
  - если не помещается, выпадает в другую сторону.
- **Другой контент** — выпадашка остаётся контейнером, в неё можно положить календарь или свой блок (`content`). Готовый календарь с саджестами и футером — [`CalendarDropdown`](../CalendarDropdown/README.md).

## Мобилка
Тот же контейнер меню показывается по-другому. В коде — `platform="mobile"`: `Dropdown` открывает `BottomSheet` со списком.
- **шторка** `tui-bottomsheet` — для простых меню:
  - заголовок наследуется от хоста;
  - по бокам 16, между ячейками отступов нет;
  - ячейки крупнее, чем на десктопе, даже если там размер S;
  - если ячеек много — шторка на всю высоту со скроллом;
- **инлайновый фуллскрин** — для комбобоксов и автокомплита:
  - хост поднимается к верху вьюпорта, список растягивается до низа;
  - от края до контента ячейки — 28;
  - анимация `duration-fast`;
- **модальный фуллскрин** — для сложного содержимого вроде календаря. Анимации — как у `tui-dialog`.

Нажатая ячейка подсвечивается `neutral-1` целиком, до края.

**В коде (шторка):**
- заголовок шторки — текст хоста (или `title`);
- ячейки мобильные `tui-cell` (56), по бокам 16, без отступов между ними; выбор — галочка 24 справа, мультивыбор — чекбокс слева;
- единичный выбор закрывает шторку (`closeOnSelect={false}` — оставить открытой);
- мультивыбор: шторка остаётся открытой, `applyLabel` добавляет кнопку применения внизу (как в шторке фильтра);
- поиск (`search`) — мобильное поле, закреплено сверху;
- подменю раскрываются группой с заголовком-родителем: вложенных поповеров на мобилке нет;
- пропсы шторки — `sheet` (`height`, `snapPoints`…).

**Пока не собраны:** инлайновый фуллскрин для комбобоксов и автокомплита и модальный фуллскрин (календарь — через `Dialog fullscreen`).

## API
```js
h(TaigaUI.Dropdown, { items: ['Наличными', 'Картой онлайн', 'СБП', 'T-Pay'], value: pay, onChange: setPay, size: 'l' }, h(TaigaUI.Button, { appearance: 'secondary' }, 'Способ оплаты'))
h(TaigaUI.Dropdown, { menu: true, size: 'm', items: [{ label: 'Копировать как', items: ['CSS', 'SVG', 'PNG'] }, { type: 'separator' }, 'Удалить'] }, hostButton)
h(TaigaUI.Dropdown, { platform: 'mobile', items: ['Наличными', 'Картой онлайн', 'СБП'], value: pay, onChange: setPay }, 'Способ оплаты') // шторка
h(TaigaUI.DropdownList, { multiple: true, value: v, onChange: setV, items: [{ type: 'header', label: 'Сокольническая линия', selectAll: true }, 'Черкизовская', 'Сокольники'] })
```
**Dropdown** (хост и выпадашка). Первый ребёнок — хост: клик по нему открывает и закрывает список. Если передать текст, хостом станет secondary-кнопка с шевроном.
- `open`, `defaultOpen`, `onOpenChange` — открыт ли список;
- `width` — `'auto'` (по содержимому, от 128), `'host'` (по ширине хоста) или число;
- `align` — `'start'` или `'end'`;
- `closeOnSelect` — закрывать ли после выбора; список закрывается и по клику снаружи, и по Esc;
- `content` — свой контент вместо списка.

**DropdownList** (сам список):
- `size` — `l`, `m` или `s`;
- `items` — строки, пункты `{ label, value?, description?, avatar?, caption?, right?, items?, disabled?, onClick? }`, `{ type: 'header', label, selectAll? }` или `{ type: 'separator' }`;
- выбор: `value`, `defaultValue`, `onChange`, `multiple`, `checkboxPosition` (`'right'` для пунктов с аватаром), `selectAll`;
- `menu` — роли меню вместо списка выбора;
- `search` — `{ value, onChange, placeholder }`;
- `emptyText`, `loading`, `error`, `onRetry`, `onMore`, `moreLabel`;
- `maxHeight`, `footer`, `width`.

Клавиатура: стрелки, Home и End, Enter и пробел, стрелка вправо или влево — во вложенное меню и обратно.
