# Карточный вид списка

Не всегда для отображения объектов подходит таблица. Альтернатива — карточки: широкие в список или узкие плиткой. По Figma «Card list view» (Beaver), десктоп. В коде — `TaigaUI.CardList` и `TaigaUI.ListCard` (карточка «ListCard»).

## Какой вид выбрать

**Широкие карточки** (`ListCard`):
- решения и действия принимают по каждому объекту отдельно, а не выборкой;
- для решения нужно видеть много данных по объекту сразу, а число карточек на экране менее важно;
- у объекта длинное название или важно показать описание;
- у объекта есть вложенные элементы: группа или дополнительная информация.

**Узкие карточки (плитка):**
- решения и действия — по каждому объекту отдельно;
- информацию можно показать графикой, и это помогает работать со списком: график, иллюстрация, иконка, аватар;
- карточек и данных в них немного.

В ДС плитки пока нет: в гайде только критерии, без макета.

**Таблица** (`Table`, шаблон `FilterTable`):
- объекты сравнивают между собой;
- важно, сколько объектов видно на экране;
- сравнивают по 1–2 признакам в колонке;
- нужна сортировка — в плитках с ней работать сложнее.

**Вид выбирает пользователь** — если разные роли работают со списком по-разному: одним важна полнота информации по объекту, другим графика, третьим сравнение. Переключатель вида в гайде не показан.

## Построение
- Список стоит в стандартной сетке контента и подчиняется общим правилам построения страницы.
- Фон области списка — `background-base-alt`: карточки белые и без тени. Страница — `PageLayout` со `style: { background: 'var(--tui-background-base-alt)' }`.
- Карточки — во всю ширину контентной области, между ними 16.

## Сочетание с паттернами
- Сверху — заголовок раздела с вкладками (Subheader), под ним фильтры `FilterBuilder` по гайду «Табличные листинги». Фильтр должен соответствовать содержимому: не фильтруйте по данным, которых не видно в карточках.
- Под списком — `Pagination` («Показать еще»). Есть выбор карточек и массовые действия — постраничная `Pagination type: 'paging'`, на странице 20–50 карточек (раздел «Пагинация»).
- Множественный выбор — чекбокс в карточке (`selectable`), массовые действия — `ActionBar` small (`floating`).
- Внутри карточки — `Table` S, ссылки со счетчиком («+1»), `Pagination`.

## Сворачивание и группировка
- **Много подробностей** — убираем часть в разворачивающийся блок (`collapsible`). Маркера группы нет.
- **Группа объектов с общим признаком** (`group`): признак группировки четко определен, группа по умолчанию свернута, кнопка «3 инцидента ▾» разворачивает ее. Свернутую группу отмечает «стопка» под карточкой. В развернутом виде объекты группы — внутри карточки на подложке.

Подробности, размеры и пробелы — в README компонента `ListCard`.
