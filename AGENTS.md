# Прототип на Taiga UI · Т-Банк

Перед работой прочитай docs/README.md и README используемых компонентов в docs/components/.
Создавай экраны в screens/. Используй React.createElement и компоненты T из screens/runtime.js.
Не копируй бандлы и не изменяй node_modules. Тема — в `index.html`: desktop-day, у проекта, созданного с `--mobile`, — ios-day и экран в рамке телефона; не смешивай платформы.
Используй PageLayout, CardLarge, Cell, Button и другие готовые компоненты. Цвета — только токены, текст — классы типографики ДС. Не создавай свои аналоги компонентов.
Не переписывай компоненты ДС своим CSS (`.my-card .tui-cell { … }`): настраивай их только пропсами, а если пропса нет — скажи пользователю, что в ДС этого нет. check() ловит такие правила (override).
Перед сдачей открой страницу и вызови window.TaigaUI.check({ log: false }). Исправь все нарушения; результат должен быть пустым массивом.
Тексты пиши и проверяй перед сдачей по docs/copy.md: роль строки по компоненту, правила этой роли, правим только нарушения. check() ловит механические нарушения текстов (правило copy), смысл проверяй сам.
Проверка версии включена в npm run dev; результат появляется на стартовой странице и в терминале. Пользователь может обновить библиотеку кнопкой на стартовой странице. Ошибка сети не означает актуальную версию. Не отключай проверку и не обновляй пакет без запроса пользователя.
