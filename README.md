# Прототип на Taiga UI

Нужны Node.js 20+, npm и Git. Зависимости уже установлены генератором. Если проект создан с `--no-install` или получен из Git, сначала выполните `npm install` (при наличии lock-файла — `npm ci`).

```sh
npm run dev
```

Откройте адрес из терминала. Измените `screens/main.js` и обновите страницу. Компоненты, шрифты и токены подключены через `screens/runtime.js`. Проверка ДС включена: нажмите плашку внизу слева или выполните `TaigaUI.check({ log: false })` в консоли браузера.

Правила библиотеки — в `docs/README.md`, описание каждого компонента — в `docs/components/<компонент>/README.md`. Тема по умолчанию — `desktop-day` в `index.html`.

## Проверка версии

При запуске и каждые 15 минут сервер проверяет `package.json` в текущей основной ветке репозитория библиотеки. Результат виден на стартовой странице и в терминале: версия актуальна, доступно обновление, установлена более новая версия или проверка недоступна. Архив, ещё не попавший в основную ветку, может оказаться новее источника.

Используется доступ Git на вашем компьютере: для закрытого репозитория заранее настройте SSH или HTTPS credential helper. Проверка не требует npm-реестра и не передаёт доступы браузеру. Без сети проект запускается, но актуальность версии неизвестна. На статическом хостинге фоновой проверки нет.

`library.config.json` задаёт адрес репозитория, Git ref (по умолчанию `HEAD`) и интервал. Для разовой проверки:

```sh
npm run library:check
```

На стартовой странице нажмите «Обновить до …». Локальный сервер загрузит библиотеку из настроенного Git-источника, соберёт архив в vendor/ и установит его. При ошибке установки восстановит прежние зависимости. После успеха страница перезагрузится. Сохраните новый архив, package.json и package-lock.json в Git. Документация в docs/ остаётся снимком на момент создания проекта.

Обновление также можно выполнить вручную. Получите свежую библиотеку и соберите архив командой `npm pack` в её репозитории. Скопируйте архив в `vendor/` проекта и установите:

```sh
npm install ./vendor/<новый-архив>.tgz
```

Перезапустите сервер. Сохраните новый архив, `package.json` и `package-lock.json` в Git проекта. Документация в `docs/` — снимок на момент создания; при обновлении сверяйтесь с README новой версии библиотеки.

## Сборка

```sh
npm run build
```

Готовые файлы — в `dist/`. Сервер разработки доступен только на этом компьютере. При изменении `index.html` перезапустите его. Архив библиотеки и шрифты предназначены для внутреннего использования.
